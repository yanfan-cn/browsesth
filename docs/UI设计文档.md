## 1. 设计总览 Overview

### 1.1 产品 UI 定位

极简阅读器风格浏览器 App，延续 Legado with MD3 简洁清爽的原生 App 风格。

- 主色调低饱和，专注阅读体验
- 界面尽量减少多余装饰
- 明确区分 **App 原生 UI** 与 **网页内容区域**（当前主路径为捆绑 Chromium / Aloha，非仅系统 WebView）
- 原则上不使用阴影；新 UI 一律无阴影，存量逐步删除

> **重要红线：** 广告只渲染在 App 原生 UI 区域，**绝对不能渲染在网页内容区域内部**。

### 1.2 设计原则

1. **阅读优先**：保证文字可读性；所有页面均支持同步浅色 / 深色模式切换
2. **层级清晰**：原生控件与网页区域边界明确
3. **操作轻量化**：高频操作按钮就近放置
4. **文案约束**：所有 UI 文案规避漫画 / 小说资源、图源、下载等敏感词汇
5. **适配**：支持手机竖屏、横屏，适配不同尺寸屏幕（手机多为 19.5:9 或 20:9）；支持平板电脑横屏、竖屏（多为 16:10 或 3:2）

### 1.3 设计规范

#### 色彩规范

| Token | 值 |
| --- | --- |
| Primary 主色 | `#243B5A`（可自行替换） |
| 背景 · 浅色模式 | 跟随 App `ColorScheme.background`（与「我的」一致；SPEC-067） |
| 背景 · 暗色模式 | `#121212` |

#### 字体规范

| 用途 | 规格 |
| --- | --- |
| 默认字体 | 系统无衬线字体（Roboto） |
| 标题 | 18sp，Medium |
| 正文 | 16sp，Regular |
| 辅助小字 | 14sp，Regular |
| 提示文字 | 12sp |

#### 间距与圆角

- 基础间距单位：8dp
- 卡片圆角：24dp
- 按钮圆角：12dp
- 页面边距：左右 16dp
- 内间距、外间距和元素间距等其他间距均用 **4 的倍数**
- 按钮控件尺寸：大 44dp、中 36dp、小 28dp
- 标题栏 / 顶栏高度固定为 **54dp**
- 输入框高度：大 44dp、小 32dp
- 原则上均不使用阴影

#### 图标

- **默认图标库**：无特别要求时，功能图标一律使用 Google **Material Symbols**（Outlined 可变字体）；禁止继续使用旧版 Material Icons，禁止使用 SF Symbols / Miuix 图标。
- 轴参数（全 App 统一，不得按页微调）：**Weight 400**、**Grade 0**、**Optical Size 24px**。
- FILL：未选中 / 默认 **0**（空心）；选中 / 当前项 **1**（实心）。主页等真正「当前页」底栏仍可用 FILL 表达选中。
- 图标显示尺寸：从 12–48 之间以 4 的倍数选择合理尺寸（显示边长；光学尺寸轴仍为 24）。
- 图标内间距：24 → 内间距 2；小于 24 → 内间距 1；大于 24 → 内间距 3 或 4。
- 图标须在所属控件内**居中**显示（几何居中 + FontMetrics 垂直居中）。
- 按功能选择符号（示例：搜索 `search`、**返回 `arrow_back_ios_new`（Arrow Back iOS New）**、**浏览器前进 `arrow_forward_ios`（Arrow Forward iOS）**、刷新 `refresh`、书签 `bookmark`、历史 `history`、标签 `tabs`、阅读 `menu_book`、关闭 `close`、设置 `settings`）。
- **返回键**：软件内所有导航返回键统一使用 **Arrow Back iOS New**（`arrow_back_ios_new`），不得使用 `arrow_back` 作为返回键。
- **浏览器前进键**：统一使用 **Arrow Forward iOS**（`arrow_forward_ios`）。
- 网站 favicon、书籍封面、启动图不是功能图标，不适用本套 Symbols。

## 2. 页面路由与页面清单

页面流转：

```text
启动页 → 首页（NTP 空主页 / 浏览器会话页） ↔ 阅读视图页 ↔ 设置页
```

页面列表：

1. Splash 启动页
2. BrowserNtpPage 浏览器空主页（NTP，无会话时）
3. BrowserPage 浏览器会话页（网页容器）
4. ReadViewPage 阅读视图页面（提取网页正文的纯净阅读页）
5. BookmarksPage 书签页面
6. HistoryPage 浏览历史页面
7. SettingsPage 设置页面
8. PrivacyPage 隐私政策页
9. OpenSourcePage 开源声明页面

## 3. 逐页面 UI 详情

### 3.1 BrowserNtpPage 浏览器空主页（NTP）

> 与 SPEC-007 / SPEC-040 及现实现对齐；打开 URL 后进入 BrowserPage（会话壳），返回可回 NTP。  
> 视觉签名：**双行搜索胶囊**（参考 `D:\cursor\UI参考图1.jpg` 气质，无阴影、巡页色板）。

布局要点：

1. Logo：从图标提取的「巡页」字图（居中）；浅色近黑，深色/无痕为 #F6F1EA。**开启每日壁纸且非无痕时不显示 Logo**
2. **顶栏**：左右内边距 16dp。左上自定义按键仍在顶栏；菜单整体在顶栏下方，玻璃更不透明、模糊更强，开关缩小。可开关：每日壁纸、阅读列表卡、快捷书签
3. **右上角（手机）**：历史 / 书签 / **标签计数**（正圆内为全部标签数量，含 0 与大于 9 的真实数字；点按进标签页；长按：新建标签页、关闭所有标签页）
4. **双行搜索胶囊**（单容器）：
   - 第一行：搜索引擎图标（百度 / 必应 / 谷歌 / 搜狗 / 抖音 / 360）+ 输入框
   - 第二行：左侧「AI 模式」（占位）、「无痕浏览」（Cookie / 历史隔离）；右侧扫码、搜索键；扫码与搜索间距 ≥4dp；左右不贴胶囊边
   - 搜索键：无输入为空心（FILL 0）；有输入为实心（FILL 1）
   - 引擎选择卡：对齐胶囊第二行；宽为原 70%（140dp）；图标圆形 **32dp**；玻璃加强可读
5. **快捷书签**：无卡片背景；圆形站图标 + 站名；手机图标距屏幕左右 20dp；站名按背景黑/白切换并加阴影；深色/无痕图标圆底为深色；自动 favicon（失败字母占位）；手机一行 4、平板一行 6；末位「添加」；长按编辑 / 删除
6. **阅读列表卡**：标题「阅读列表」在左上角；无「最近在读」；横滑封面（可在自定义中隐藏）；点击进入书籍详情 / 阅读
7. 不做探索发现卡、不做登录账号卡
8. 主题：跟随 App 浅 / 深；设置中可覆盖「跟随 / 浅 / 深」；每日壁纸可在自定义中开关（手机与平板均可用）
9. **平板**：NTP 内容区居中宽 **55%**；快捷书签一行 6；**不加**手机 NTP 的 70dp 内容下移
10. **手机**：除顶栏外，NTP 内容相对顶栏再下移 70dp
11. 底栏：默认悬浮；表面样式由外观「表面样式」全局控制（15+ 默认液态玻璃；低于 15 默认填充；全版本无「半透明」选项；13+ 可选手动开液态玻璃；顶栏按钮样式随表面样式，设置中不单独切换）

视觉参考：`D:\cursor\UI参考图1.jpg`（浅）、`D:\cursor\UI参考图2.jpg`（深）。

### 3.2 BrowserPage 浏览器会话页【核心页面】

布局从上到下：

1. **顶部工具栏（AppBar）**
   - 左侧：返回按钮
   - 中间：地址栏（输入 URL，可点击跳转）
   - 右侧：刷新按钮
2. **网页容器**（占据大部分屏幕）
   - 承载第三方网页内容，网页本身不受 App UI 控制
3. **底部操作栏**（固定在网页容器下方，App 原生控件）
   - 悬浮样式；外观对齐主页悬浮底栏（半透明 / 圆角 / 图标）；不对网页内容做液态玻璃采样
   - 按钮从左至右：后退、前进、工具箱、**标签计数**（正圆+全部标签数量；点按进标签页；长按：新建、关闭全部、添加书签）
   - 标签页：顶栏无「标签页」标题；常规/无痕分段控件居中且宽为页宽 50%；「+」距右缘 16dp、按当前分段新建；切无痕不进入隔离；网格为网页快照；左右滑关闭；底部居中 icon「全部关闭」（同返回/新建样式）只关当前分段；进出约 240ms 成对淡入淡出+轻缩放；平板全屏复用同套 UI 且不保留浏览器顶栏（SPEC-071）
   - 长按标签计数：可读浮层菜单（无阴影、Material Symbols）；主页=新建/关闭全部；底栏另加添加书签（SPEC-071）
   - **选中效果**：默认**无任何键处于选中态**；仅在指尖按下某一键时呈现选中/按压效果，松手后恢复未选中（与主页「当前页」持久选中不同）
   - 阅读视图为独立的蓝色圆形按键，置于最右侧

工具箱弹窗选项：

- 添加书签
- 查看历史
- 书签列表
- 复制链接
- 转发网页（系统分享标题 + 链接；SPEC-058）
- 下载（当前页交系统下载；网页触发下载同；SPEC-058）
- 点选屏蔽
- 开启 / 关闭广告拦截
- 设置

主页搜索框与浏览地址栏：输入时可匹配本地书签与历史（书签优先），点选直接打开（SPEC-058）。

交互：

- 点击【阅读视图】：自动判断小说 / 漫画；不准时弹出选择；进入对应 Legado 阅读器
- 广告拦截开关实时生效，不需要刷新页面也可切换
- 网页滚动时，底栏可自动隐藏（设置里可选）
- 进出历史 / 书签 / 设置不得自动刷新网页；仅手动点刷新

### 3.3 ReadViewPage 阅读视图页面

目标：仿 Safari 阅读视图，**完全脱离原网页 UI**，App 原生渲染正文；默认阅读内容全屏显示。

布局：

1. **顶栏（与漫画阅读器对齐，浏览器临时书）**：透明悬浮；左返回胶囊、中标题胶囊（书名/章节）、右合并操作（或精简「⋯」）
2. 正文阅读区域（App 原生 Text / 图片组件，不是网页容器）
   - 纯文字 + 图片（提取自网页 DOM；同章可续载分页）
3. 无网页广告
4. 悬浮式底栏：从 UI 到功能都照搬原 Legado 小说 / 漫画阅读器（含上一章 / 下一章 / 目录）
5. 浏览器设置「进入阅读模式」：手动（默认）/ 自动识别 / 站点自动；无痕不自动

### 3.4 BookmarksPage 书签页

- 顶部标题：书签
- 列表卡片：每个书签卡片 = 网站图标 + 标题 + URL + 删除按钮
- 点击书签：直接在 BrowserPage 打开链接
- 右上角：新增书签按钮

### 3.5 HistoryPage 浏览历史页

- 列表展示：标题、URL、访问时间
- 点击条目打开网页；支持长按删除、清空全部历史

### 3.6 SettingsPage 设置页面（列表式）

分组列表：

1. **阅读设置组**
   - 阅读视图默认字体大小
   - 默认阅读主题（亮 / 暗 / 护眼）
2. **浏览器功能组**
   - 广告拦截【开关】
   - 网页背景（跟随 / 浅 / 深）——仅 Force Dark；壳色跟 App 外观（SPEC-059）
3. **广告设置组**
   - App 内广告展示【开关】
4. **关于组**
   - 隐私政策（跳转 PrivacyPage）
   - 开源声明（跳转 OpenSourcePage）
   - App 版本号

### 3.7 PrivacyPage 隐私政策页

- 原生页面，展示静态文本，支持上下滚动
- 返回按钮回到设置页

### 3.8 OpenSourcePage 开源声明页面

- 展示 GPL-3.0 协议，标注基于 **Legado with MD3** 项目二次开发
- 静态文本页面

## 4. 全局组件 Component

> 所有页面复用组件

1. **TopAppBar** 顶部导航栏：返回箭头（`arrow_back_ios_new`，控件内居中）+ 页面标题 + 菜单 icon

## 6. 交互与动效

- 页面切换：遵循 Material 3 expressive 规范，支持预见性返回手势；仅 Android 15+（API ≥ 35）启用，否则关闭

## 7. UI 红线（Agent 必须严格遵守）

1. ❌ 禁止在网页内容区域内部注入任何 App 广告、UI 元素
2. ❌ 网页内不能叠加自定义悬浮控件
3. ✅ 广告组件只能放在 App 原生页面区域：Splash、页面底部原生区域等
4. ✅ 网页区域只渲染第三方网页；App UI 与网页区域物理隔离
5. ❌ UI 文案不要出现：图源、书源、漫画下载、资源解析等敏感词
6. ✅ 所有控件、弹窗支持暗色模式
7. ✅ 新 UI 不使用阴影；存量阴影随相关改动逐步删除
