## 2. 一句话产品定义

Browsesth 是一款 **Android 内置浏览器阅读器**：用应用内捆绑的 Chromium 内核打开网页，用阅读视图净化小说页，用网页抽图 + 专用漫画阅读器阅读漫画，让用户少看广告与跳转页。

它不是书源聚合器，也不是 Cimoc 式硬编码图源客户端。

## 3. 已确认的产品原则

### 3.1 小说与漫画同等重要

- 主导航与阶段规划须同时覆盖两类体验；
- 不得只做小说阅读视图而把漫画无限期挂起（除非所有者书面调整阶段出口）。

### 3.2 取消书源 / 漫画源作为主路径

- 新产品不以「导入书源规则抓站」为卖点；
- 从 Legado 派生时，书源相关能力可过渡隐藏或删除，删除策略须单独 Spec，避免误删用户仍需的本地能力。

### 3.3 浏览器 + 阅读视图

- 内置浏览器：导航、历史、书签为最低集合；
- 阅读视图目标对标 Safari Reader 的「去噪读正文」，不承诺对所有站点 100% 成功；
- 失败时保留普通网页浏览。

### 3.4 漫画路径

- 从网页抽取图片列表，进入 **Legado 漫画阅读器能力**（分页/条漫等）；
- **不**整包嵌入 Cimoc（Java/Fresco/硬编码源）；
- 允许后续单独移植 Cimoc「白边裁剪」等纯算法。

### 3.5 捆绑 Chromium（经红色批准）

- **生效策略：** 应用内捆绑完整 Chromium 内核，**不**再以系统 WebView 为默认主路径。
- **落地方式（B2）：** 采用现成、可嵌入 Android App 的 Chromium 系 SDK/库；不在本决策中自建整棵 Chromium 编译树（B1）。具体 SDK 品牌在后续浏览器/内核 Spec 中选型。
- **版本策略（L1）：** 尽量跟随当时 Chromium/Chrome Stable；发版时升级内核。
- **ABI：** 仅 **arm64-v8a**（64 位 ARM）；不承诺 32 位或 x86。
- **体积：** 无上限（接受包体显著增大）。
- **选型硬条件（必须可验收）：**
  1. **广告资源拦截**（能拦截或等价阻断广告类网络请求）；
  2. **跳转中页跳过**（能识别/干预中间跳转页并进入目标页）。  
  候选 SDK 任一项不过关则换 SDK；不得用「已内置 Chromium」代替功能验收。阶段 C 实现依赖上述能力，选型阶段即须验证 API 可用。
- 宪章仍保留「默认不捆绑、捆绑须红色审批」原文；**本次即该审批结论**，后续 Spec 以本文为准引用内核边界。

### 3.6 合规与定位

- 软件提供本地浏览与抽取展示能力，不预置第三方小说/漫画内容；
- 用户自行访问站点须遵守当地法律与站点条款；产品说明须含免责声明（可参考 Legado 声明结构改写）。

## 4. 阶段出口（摘要）

详见宪章 §8.4。顺序建议：A 浏览器+小说阅读视图 → B 漫画抽图+阅读器 → C 净化增强（含广告资源拦截与跳转中页跳过）。
