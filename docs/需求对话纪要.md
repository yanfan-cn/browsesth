# 需求对话纪要（2026-09-30）

本文汇总立项前对话中的关键结论，细节以 `产品与开发决策基线.md` 与宪章为准。

## 背景调研

- 参考仓库：`legado-with-MD3`（Kotlin/Android，已有漫画阅读器与 WebView 工具页）、`Cimoc`（Java 漫画客户端，无真正网页净化浏览器）。
- Cimoc `BrowserFilter` 实为外链唤起，不是阅读视图；「减少页面广告」为应用内列表广告位。

## 产品意图

1. 基于 Legado 开发新软件；
2. 取消书源/漫画源解析主路径；
3. 内置浏览器 + 类 Safari 阅读视图，净化小说页广告与跳转干扰；
4. 漫画同等重要：网页抽图 + 专用漫画阅读器；
5. 漫画阅读器优先用 Legado，不整包用 Cimoc；
6. （已修订，见下节）原讨论曾默认不捆绑 Chromium；后经红色审批改为捆绑。

## 命名与仓库

- 2026-09-30：产品与仓库正式命名为 **browsesth**，远程 `https://github.com/yanfan-cn/browsesth`（私有）。
- 曾用工作名 ClearPage 仅作脚手架过渡，已废弃。

## 内核边界修订（2026-09-30）

- **红色批准（由当前操作者转述）：** 捆绑完整 Chromium；仅 arm64-v8a；无体积上限。
- **落地：** B2（现成可嵌入 Chromium 系 SDK/库）；**版本：** L1（尽量跟随 Stable）。
- **硬条件：** 广告资源拦截、跳转中页跳过须在 SDK 选型时可验收。
- 文档合同：`SPEC-001` / `docs/产品与开发决策基线.md` §3.5；宪章正文未改（仍写「捆绑须红色审批」）。
