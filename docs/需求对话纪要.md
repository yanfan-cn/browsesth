# 需求对话纪要（2026-09-30）

本文汇总立项前对话中的关键结论，细节以 `产品与开发决策基线.md` 与宪章为准。

## 背景调研

- 参考仓库：`legado-with-MD3`（Kotlin/Android，已有漫画阅读器与 WebView 工具页）、`Cimoc`（Java 漫画客户端，无真正网页净化浏览器）。
- Cimoc `BrowserFilter` 实为外链唤起，不是阅读视图；「减少页面广告」为应用内列表广告位。

## 产品意图

1. 基于 Legado 开发新软件；
2. 取消书源/漫画源解析主路径；
3. 内置浏览器 + 类 Safari 阅读视图，净化小说页广告与跳转干扰；
4. 漫画同等重要：网页抽图 + 专用漫画阅读器；
5. 漫画阅读器优先用 Legado，不整包用 Cimoc；
6. 关心系统 WebView 版本碎片化风险；默认不捆绑约百兆级 Chromium。
