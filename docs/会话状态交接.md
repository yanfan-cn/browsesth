### 0.B 8.4 闪退根因（勿再犯）

NTP 把 `layerBackdrop` 包在含 `browserControlLiquidGlass` 的同一树上，RenderThread `computeTransformImpl` 递归 **SIGSEGV**。正确做法：壁纸采样层与玻璃控件是兄弟节点；无壁纸时 `LocalTopBarBackdrop=null`，玻璃走本地 backdrop。

标签页缩略图用 host `draw` 到软件 Bitmap，**禁止**当液态玻璃采样源。后台标签无活网页，只显示离开时快照；失败则占位。

### 0.1 当前产品事实（勿回退）

1. **首次使用**：欢迎/隐私后进 NTP，不是 example.com。`MainIntent.createHomeIntent` → `ROUTE_MAIN`。
2. **地址栏**：未编辑时显示用户搜索/输入文字；提交后收键盘清焦点。平板 NTP 须用提交瞬间的文字。
3. **手机浏览壳**：会话中主 Pager 不可滑向书架；底栏四键只点按。NTP 可滑到书架。禁止采样 AwContents。
4. **NTP↔网页**：有网页只组合会话；NTP 用 `AnimatedVisibility`。禁止 `AnimatedContent` 同时挂两者。
5. **内核**：`CommandLine` 在 `loadLibrary` 前。Cookie/Eyeo **不要**冷启动、**不要** attach。UA `150.0.7871.46`；仅 arm64-v8a。
6. **平板**：无主底栏、无顶栏玻璃。浏览器主页不可左右滑切书架。从浏览器进阅读叠壳内留顶栏。**标签页**：平板全屏复用手机标签 UI，进入时藏浏览器顶栏。**设置**：左右双栏，默认右侧浏览器设置。**NTP**：内容 +70dp；竖屏宽约 75%、横屏约 55%；Logo↔搜索 24dp。**阅读**：无页眉；无顶 padding/正文顶左标题。
7. **功能图标**：Symbols Weight 400；浏览底栏默认无选中。引擎 logo **不是** Symbols。
8. **搜索引擎**：六引擎；默认仍谷歌；选择卡宽 140、图标圆 32dp、对齐搜索第二行。平板顶栏搜索圆角 **24dp**；引擎菜单在顶栏下。
9. **翻译**：浏览器内百度整页；不进阅读器。章节默认百度。微软未做。
10. **阅读**：网页有正文默认小说混排；几乎无字才漫画。**退出阅读不再询问放入书架**。混排/漫画可双击进全屏图廊。**浏览器临时小说**：`columnMode` 至少横屏双页（LANDSCAPE）；双页时关闭连续滚动。**默认**（SPEC-062）：字号 20、行距 0.3、翻页滑动；菜单设置仅顶栏/底栏；标题胶囊+精简顶栏固定开。
11. **NTP 玻璃**：采样源不得包含玻璃后代；圆形控件 `showShadow=false`。自定义/引擎菜单 `readableOverlay`。主页菜单可切跟随/浅/深（写 App `themeMode`）。
12. **展示名**：巡页。桌面默认图标为巡页图。不改 `applicationId` / prefs 键。
13. **标签**：数量显示真实数字（主页/底栏为正圆计数）；标签页顶栏「常规/无痕」分段筛选；「+」与「全部关闭」只作用于当前分段；关闭全部/关最后一个 → **0** 个标签；空表时打开网址会新建标签。
14. **快捷书签**：手机图标距屏幕左右 20dp；站名按背景黑/白+阴影；深色/无痕圆底深色。
15. **表面样式（SPEC-056/061）**：外观「填充 / 液态玻璃」（无半透明）；&lt;15 默认填充，15+ 默认液态玻璃；顶栏按钮样式随表面样式（设置中不可单独切换）；填充时阅读顶/底栏实色。
16. **状态栏图标**：浅色界面深色图标、深色界面浅色图标（`BaseComposeActivity.setLightStatusBar(!isDark)`；`themeChanged` 刷新）。
17. **阅读列表**：系统返回回到浏览器主页，不退出 App（`MainScreen` BackHandler）。
18. **浅色背景 / NTP（SPEC-067）**：NTP 非无痕页背景=`ColorScheme.background`，组件底=`surfaceContainerLow`（与「我的」选项行一致）；设计文档已改为跟随 App。订阅默认隐藏；外观无「更换图标」「模糊效果」入口（063）。
19. **浏览器下载（SPEC-064/066）**：工具箱「保存网页」= **HTML 快照**（非 MHTML）；「下载」= 下载列表页；文件与网页存档均在 `Download/XunYeBrowser`；自管下载可暂停/继续；进行中系统通知；底栏上方约 5s 下载提示条可进下载页；打开存档用 `loadDataWithBaseURL`。
20. **工具箱（SPEC-070）**：Edge 式置顶四项（书签/历史/下载/设置，强调色实心、**不可排**）+ 下方空心网格（含「新建无痕标签页」=`openNewTab(incognito=true)`）+「自定义顺序」仅拖下方项并持久化；高度约半屏；手机/平板同结构。旧列表式 ToolboxRow 已删。
