### 0.1 当前产品事实（勿回退）

1. **首次使用**  
   - 仍走欢迎/隐私。完成后进浏览器主页（NTP），**不是** example.com。  
   - `MainIntent.createHomeIntent` → `ROUTE_MAIN`。

2. **地址栏**  
   - 未编辑时显示用户搜索/输入文字，不显示网页 URL。  
   - 网页里提交搜索后必须收键盘并清焦点。

3. **手机浏览壳**  
   - 网页会话时：主 Pager **不可**滑向书架；网页底栏四键只点按，**无**按住左右滑。  
   - NTP（未打开网页）仍可左右滑主分页到书架。  
   - 顶栏返回/地址/刷新：液态玻璃；地址栏关闭拖动手势。  
   - 上 8dp + 下 `FloatingChromeBottomGap=8.dp` + `navigationBars`。  
   - **默认不**因滚动隐藏顶栏/底栏；浏览器设置「滚动时隐藏浏览栏」打开后才隐藏。  
   - **禁止采样 AwContents**。平板不加液态玻璃、无主界面悬浮底栏。

4. **NTP↔网页**  
   - 有网页时只组合会话（AwContents）；NTP 用 `AnimatedVisibility` 单独滑入滑出。  
   - 禁止用 `AnimatedContent` 同时挂 NTP 与会话（反复搜索会闪退）。

5. **内核**  
   - `CommandLine` 仍在 `loadLibrary` 前（SPEC-029）。  
   - Cookie/Eyeo 关闭延后到首次 `AwContents.attach`（SPEC-032）。  
   - 启动日志/CrashHandler 不得调用系统 `WebSettings.getDefaultUserAgent`。  
   - UA `150.0.7871.46`；仅 arm64-v8a。  
   - DrawFn 失败 → 本进程 SOFTWARE。

6. **平板**  
   - 无主底栏、无顶栏玻璃；功能条：标签/收藏/历史→书架→阅读→工具箱。  
   - 收藏/历史/工具箱右侧滑入；标签整页缩放。

### 0.3 真机待验（优先，对 7.1）

1. 欢迎完成后是 NTP，不是 example.com。  
2. 完全退出后再打开不闪退。  
3. 主页搜索几次、回主页再搜，不闪退。  
4. 网页地址栏搜索后键盘收起。  
5. 网页中滑底栏不进书架；四键可点。  
6. 默认滚动不藏栏；设置打开后才藏。  
7. 平板无底栏、无顶栏玻璃；书架可进可返回。  
8. 搜「苹果」：地址栏显示「苹果」；百度热卖对照。  
9. 进度条仅真正导航时出现。  
10. 漫画从详情/某一话进阅读：目录、上下章。
