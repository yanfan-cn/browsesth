### 0.B 闪退根因（勿再犯）

1. **NTP backdrop**：把 `layerBackdrop` 包在含 `browserControlLiquidGlass` 的同一树上 → RenderThread `computeTransformImpl` 递归 **SIGSEGV**。壁纸采样层与玻璃控件须为兄弟；无壁纸时 `LocalTopBarBackdrop=null`。
2. **标签页 + 液态玻璃（2026-10-08）**：有网页时开标签，`RenderThread` `SIGSEGV`，原因 `stack overflow` / `computeTransformImpl`（约 512 帧）。**仅液态玻璃模式**复现；填充模式相对安全。log：`_tabs_click_log.txt`、`_tabs_click_log_110.txt`。
3. **已证明无效/不足**：071 双侧 scale；075 恢复 0.88 scale+pause；076 临时 suppress 玻璃+pause；077 玻璃仅 fade、填充仍 scale——**11.0 仍闪**；078 仅 180ms fade——**11.1 仍闪**。
4. **当前策略（SPEC-079 / 11.2 真机已暂时解决）**：删标签**底部** ClearAll 玻璃键；标签页 `AppScaffold(disableLiquidGlass/disableContentSampling)`；顶栏返回/新建强制 Tonal；手机/平板标签路由 **Enter/Exit None**。手机关全部=长按计数菜单；**080 平板**标签页顶栏另有 Tonal「全部关闭」（非玻璃、非底部悬浮）。**勿恢复底部玻璃 ClearAll 或标签 Nav fade/scale。**
5. **缩略图**：host `draw` 到软件 Bitmap，**禁止**当液态玻璃采样源；后台标签只显示离开时快照。**081**：平板卡片比例跟屏幕宽高比。
6. **设置闪退（SPEC-081）**：平板设置一级液态玻璃返回同样会 `computeTransformImpl` 栈溢出 → 一级返回 **Tonal** + 设置页 `disableLiquidGlass`。**勿再让平板设置 L1 返回跟表面样式开玻璃。**

- 玻璃控件不得放进 `layerBackdrop` 子树。

- **禁止**用 bottom padding 随底栏显隐改 WebView 高度（073：固定预留即可）。
