# 内核胶水对照清单（系统 WebView 自动做了什么，巡页缺什么）

> SPEC-180 依据。来源：Bromium AAR 内官方胶水字节码证据 + Chromium 开源 `android_webview/glue` 实现。
> 巡页绕过 `android.webkit.WebView` 胶水层，直接驱动 `AwContents`；下表逐项对照。

## 铁证（字节码）

`com.android.webview.chromium.WebViewChromium.setWebChromeClient`：

```
22: ldc_w  "WebViewInstanceSetWebChromeClient"      （trace 记录）
47: invokevirtual org/chromium/android_webview/AwSettings.setFullscreenSupported:(Z)V
55: invokevirtual com/android/webview/chromium/SharedWebViewChromium.setWebChromeClient
69: invokevirtual com/android/webview/chromium/WebViewContentsClientAdapter.setWebChromeClient
```

即：**系统 WebView 在 `setWebChromeClient(非空)` 被调用的当口自动 `setFullscreenSupported(true)`**。

## 对照表

| # | 系统 WebView（胶水）自动做 | 巡页现状 | 影响 | 状态 |
| --- | --- | --- | --- | --- |
| 1 | 设 WebChromeClient 时 `AwSettings.setFullscreenSupported(true)` | 从未调用 → false | 网页 `document.fullscreenEnabled=false`，全屏键灰 | **缺口（灰键根因）**；1.7.6 曾单开但伴随挂载时序改动，播放即崩，需真实堆栈定性 |
| 2 | `AwContents` 构造自动建 `DefaultVideoPosterRequestHandler` 并把 URL 写进 `AwSettings.setDefaultVideoPosterUrl`；poster 请求走拦截链调 `client.getDefaultVideoPoster()` | 同机制已生效；1.7.5 起 poster 非空（16×16） | null 会让 poster 流异常/黑块 | 已覆盖 |
| 3 | `onShowCustomView`/`onHideCustomView` 由 `WebViewContentsClientAdapter` 当帧同步转调（UI 线程） | customViewShowHandler：1.7.5=decor.post 延迟一帧；1.7.6=同步（崩） | 全屏视图挂载/退出 | 待真实堆栈定责；同步本身是系统范式 |
| 4 | `getVideoLoadingProgressView`（默认 null 可） | 返回 null | 视频起播前加载视图 | 已覆盖 |
| 5 | JS alert/confirm/prompt、geolocation、permission 转发 | alert/confirm/prompt=cancel；geolocation 空；permission=deny | 网站要摄像头/麦克风会被拒（视频网站罕见） | 已覆盖（可留意） |
| 6 | `onReceivedTitle/Icon/HttpError/ConsoleMessage` 等转发 | 主要项已接 | 日志/标题/图标 | 已覆盖 |
| 7 | 胶水 `WebViewChromiumFactoryProvider` 进程级初始化（设置/cookie/ServiceWorker 等） | 由 Aloha `BromiumInitializer.initializeAll` 承担 | 进程环境 | 已由 Aloha 覆盖 |

## 修复顺序（单变量，每步真机）

1. **取回 1.7.6 真实崩溃堆栈**：装 1.7.7 后 `adb shell run-as com.browsesth.app` 从私有目录拉 CrashHandler 崩溃文件（2MB 那份就是视频闪退全貌）。
2. **只开 `setFullscreenSupported(true)`**（其余保持 1.7.5 回退态）→ 构建真机验证：全屏键点亮？播放正常？
3. 视步骤 2 结果处理挂载细节（全屏宿主、系统栏、退出路径）。
