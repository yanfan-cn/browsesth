# 液态玻璃与动画安全表（SPEC-100）

> 权威约束，配合 `docs/会话状态交接.md` §0.B。违反易致 RenderThread SIGSEGV。

## 红线（禁止）

| 场景 | 禁止 |
| --- | --- |
| 标签页进出 | fade / scale / graphicsLayer 盖住含玻璃或 AwContents 的树 |
| 标签页 UI | 底部悬浮玻璃「全部关闭」 |
| 平板设置 L1 | 液态玻璃返回键（须 Tonal + disableLiquidGlass） |
| 采样 | AwContents / 缩略图 Bitmap 作玻璃 backdrop |
| NTP | `layerBackdrop` 与 `browserControlLiquidGlass` 同子树嵌套 |

## 相对安全

| 手段 | 说明 |
| --- | --- |
| layout slide（改 offset） | 不建离屏层；Nav / NTP↔会话优先 |
| effects 弹簧（alpha/颜色） | 仅用于**无**玻璃后代、无 AwContents 的控件 |
| spatial 弹簧（offset） | 可用于位移；避免同时 scale 玻璃树 |
| 填充模式 scale | 仅 `ChromeSurfaceStyle.Filled` 可评估；玻璃模式默认不用 |

## Expressive 接入原则

1. 主题已 `MotionScheme.expressive()`；Material 组件可跟弹簧。
2. 自定义转场：有 AwContents → **只 slide**；无内核 → 可用 spring spatial/effects。
3. 玻璃模式转场中尽量减少同时存活的玻璃控件数量（进会话后卸 NTP）。
