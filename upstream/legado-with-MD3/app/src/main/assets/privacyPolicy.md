# 巡页 · 用户隐私与协议

* 巡页（Browsesth）是一款在设备本地运行的**内置浏览器阅读器**：使用应用内捆绑的 Chromium 内核浏览网页，并可用阅读视图阅读净化后的正文、用漫画阅读器阅读抽图后的内容。
* 用户自行打开的网站内容由**用户设备直接请求与展示**。本应用不设立用于托管用户阅读内容的自有内容服务器。
* 本应用**不主动收集**用户的浏览正文、书签明细、历史明细、下载文件内容或个人身份信息用于内容运营。
* 为提升稳定性与性能，本应用依赖 **Google Firebase Analytics** 与 **Firebase Performance Monitoring**，可能收集匿名化的使用统计、性能指标与基础设备信息；该类数据不包含网页正文。当前工程未集成 Crashlytics。
* 网络同步与备份采用 WebDAV 等协议时，由用户自行提供服务端；相关数据仅在用户主动启用时传输。
* 存储权限用于打开本地文件、保存下载 / 网页存档以及本地备份恢复。
* 其它部分权限可能由 Firebase 或系统能力所需；未授权则对应能力不可用。
* 本应用为开源软件衍生产品。用户因自行访问站点或使用第三方规则而产生的风险，由用户自行承担（详见免责声明）。
