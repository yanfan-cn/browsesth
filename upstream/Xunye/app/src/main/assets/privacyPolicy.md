# 巡页 · 用户隐私协议

* 用户自行打开的网站内容由用户设备直接请求与展示。本应用不设立用于托管用户阅读内容的自有内容服务器。
* 本应用不主动收集用户的浏览正文、书签明细、历史明细、下载文件内容或个人身份信息用于内容运营。
* 本应用不内嵌第三方统计 / 性能采集 SDK，不会向任何第三方上传匿名使用统计或性能指标。
* 网络同步与备份采用 WebDAV 等协议时，由用户自行提供服务端；相关数据仅在用户主动启用时传输。
* 为提供浏览、净读、漫画阅读、下载备份、朗读、局域网服务、扫码与应用更新等功能，巡页可能使用下列权限。我们按需申请，您可选择拒绝，仅影响对应功能。不同设备的提示方式可能不同。
  1. **网络相关**：互联网、网络/Wi‑Fi 状态、组播及（高版本）本地网络——用于上网、下载与局域网投屏/网页服务。
  2. **存储**：读写存储或「所有文件访问」——用于导入导出、备份与保存下载内容。
  3. **通知与后台**：通知、前台服务、唤醒锁及（可选）忽略电池优化——用于朗读、下载等持续任务及相应通知。
  4. **悬浮窗**：用于朗读等悬浮控制。
  5. **相机**：仅用于扫码。
  6. **电话状态**：用于来电时暂停朗读，不拨号、不读通话内容。
  7. **安装应用**：仅用于您主动安装更新包。
  8. **音频设置**：用于朗读与媒体播放。

  上述权限仅用于所声明功能。您可在系统设置中随时管理权限。
* 本应用的净读功能基于 Legado with MD3 开发；净视功能基于 ExoMedia 开发；浏览器内核源自 Aloha Core；本应用为开源、免费的产品，用户因自行访问站点或使用第三方规则而产生的风险，由用户自行承担（详见免责声明）。
