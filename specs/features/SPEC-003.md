## 3. 为什么做

用户需要以 Legado 为产品壳、以 Aloha 为内核的 Browsesth；启动即浏览器，书源非主路径。

## 4. 本次范围

要实现：

1. **主工程合并**：`upstream/legado-with-MD3` 成为可从仓库根构建的主 App（含 book/rhino 模块）。
2. **主浏览器换核**：浏览器主路径使用 Aloha `AwContents`，禁止该路径 inflate 系统 `android.webkit.WebView`。
3. **次要 WebView 桩掉**：RSS/字典/登录/后台 WebView/BottomWebView 等本轮不创建系统 WebView（占位或安全失败），避免双核冲突。
4. 保持：启动进浏览器；Explore 隐藏；历史或书签至少一种；仅 arm64-v8a。

本轮明确不做 / 暂缓：

- Slice V 小说阅读视图；
- 全部次要 WebView 换成 Aloha；
- 阶段 B 漫画；阶段 C 广告规则库产品化；
- 整包 Cimoc；改宪章。

## 5. 用户如何使用

1. 打开 App → **直接进入浏览器页** → 输入 HTTPS 地址打开网页（Aloha）。  
2. 前进/后退/刷新可用。  
3. 可保存书签或查看历史（至少一种）。  
4. 主导航不把书源作为主路径；次要 WebView 功能本轮不可用或有明确提示。

## 6. 产品规则

- 默认内核为已锁定 Aloha；仅 arm64-v8a 发布。
- 书源相关入口默认不可见或不可作为主路径。
- 不上传用户阅读正文到开发者服务器。
