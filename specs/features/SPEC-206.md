# SPEC-206：选择模式顶栏——折叠藏标题、全选切换、删反选、加删除

| Spec ID | SPEC-206 |
| 状态 | Implemented（源码；待装包验） |
| 基线 | SPEC-204 / SPEC-205 |
| 依据 | 操作者确认（2026-10-30）：「阅读模式」=「阅读列表」标题；删除反选图标；全选可切换；加删除 |

## 做

1. 选择模式且顶栏折叠时：主标题「阅读列表」不显示（空标题）；展开时仍显示。
2. 去掉选择模式顶栏「反选」（Refresh 图标）。
3. 「全选」改为切换：当前可见未全选 → 全选；已全选 → 清空选择。
4. 选择模式顶栏增加删除：有选中时可点；确认对话框（文案 `sure_del`）；若选中含本地书可勾选「删除源文件」；确认后删书并清选择（对齐阅读列表管理）。

## 不做

- 不改阅读列表管理页；不改其它编辑态按钮（下载/移分组/私密）。
- 本轮不 assemble（除非另说）。

## 验收

- AC-01：选择模式折叠顶栏无「阅读列表」字；展开可见。
- AC-02：无反选按钮。
- AC-03：全选再点可全不选。
- AC-04：删除键+确认可删选中书。
