## 2. 开工前需求确认

- 已调查事实：
  1. 工具箱（`BrowserToolboxBody`，手机横屏侧卡与竖屏底栏 bottom sheet 共用）：书签/历史/下载/设置为固定 Row（不随 4 列 LazyVerticalGrid 滚动）；内部上 inset `ToolboxContentTopInset = 12dp`。
  2. 净视胶囊 = `VideoPlayerPromptCapsule`（视频提示）：宽 = 屏宽 × widthFraction（手机默认 0.75、平板 0.45）；高 = 64dp（IconButton 最小 48dp + 上下 padding 8dp×2）。
  3. 手机横屏净读 FAB：蓝圆 20dp + 图标 16dp，与左侧标签徽章（20dp）名义同尺寸（SPEC-181 R2）；操作者仍指定放大蓝圆至 22dp、图标改 15dp。
- 操作者确认（2026-10-29）：宽度按字面比例（平板 0.45→0.315、手机横屏 0.75→0.375）；高度 64→56dp（按钮 48→44、上下留白 8→6）；FAB 蓝圆 22dp/图标 15dp。

### 红色问题判定

- 否：视觉/布局细节；工具箱四键从固定改滚动不减少任何功能入口。

## 3. 为什么做

- 横屏工具箱纵向空间紧张：上边框与固定行挤占滚动区。
- 净视胶囊横屏/平板占宽过大；高度偏高。
- 净读 FAB 观感偏小（操作者指定目标尺寸）。

## 4. 本次范围

1. `BrowserToolboxSheet.kt`：
   - `ToolboxContentTopInset` 12dp → 4dp（共用 body 的竖屏底栏 bottom sheet 上边距同步变小，属预期一致化）。
   - 删除固定四键 Row；四键作为网格前 4 个 item（key=`shortcut_*`）进入编辑态/普通态两个 4 列滚动网格；编辑态四键**不**套 ReorderableItem/拖拽 handle（顺序固定），普通态行为（onDismiss + 打开对应页）不变。网页背景区块维持钉在网格外顶部。
2. `BrowserSessionScreen.kt`（`VideoPlayerPromptCapsule`）：
   - 新增 `compact: Boolean = false`：按钮 `IconButton` 尺寸 48→44dp、Row 上下 padding 8→6dp（高 64→56dp）。
   - 平板调用点（top-end）：widthFraction 0.45 → 0.315，compact=true（同时保证多视频 5 键在 0.315 宽下不溢出）。
   - 手机调用点：`widthFraction = if (横屏) 0.375f else 0.75f`、`compact = 横屏`（竖屏不变）。
3. `BrowserSessionScreen.kt`（横屏净读 FAB）：蓝圆 20→22dp、书签图标 16→15dp。

明确不做：

- 净读胶囊（平板功能栏 SPEC-126「净读」胶囊）不动；净视胶囊竖屏宽度/位置不动；工具箱功能键集合与顺序存储不动（四键不进 order 列表）。

## 5. 用户如何使用

1. 手机横屏打开工具箱：上边距更小；书签/历史/下载/设置随网格一起滚动。
2. 平板/手机横屏出现净视胶囊时更窄更矮（56dp）；竖屏宽度不变。
3. 手机横屏净读 FAB 蓝圆 22dp、图标 15dp。

## 6. 产品规则

- 无产品行为变化；纯布局/尺寸调整。

## 7. 验收标准

- [ ] AC-01：手机横屏工具箱上边距明显变小；四键随网格滚动；功能不回归；编辑态其余键拖拽排序不回归。
- [ ] AC-02：平板净视胶囊宽度 ≈ 当前 70%（0.315 屏宽）、高 56dp；多视频 5 键不溢出不裁切。

- [ ] AC-04：手机横屏净读 FAB 蓝圆 22dp、图标 15dp；点击/长按菜单不回归。
