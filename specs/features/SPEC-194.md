## 2. 开工前需求确认

- 已调查事实：
  1. **warm=0 时滑动依旧掉帧 → 热邻居不是滑动元凶**（静态排查已穷尽的书架路径：书架代码与原版逐字节相同；预载只跑启动；滑动不触发 ViewModel 状态发射）。滑动元凶需真机 Perfetto 定位——本轮不盲改。
  2. warm=0 的实际代价被真机判定不可接受（切标签非常卡）→ 回调为 1（保留相邻页预组合，救回标签切换手感；滑动元凶另查）。
  3. 配色封面体系（SPEC-164/185）现状：八款 preset 齐全、`random_match` 默认开、网页书（WebArticleBookFactory）/本地书（LocalBook）创建时即分配；三个展示位（主页卡/阅读列表页/阅读记录两页）全部走 `CoilBookCover` → 空路径/默认标记/本地文件缺失时运行时兜底。
  4. **发现的实际缺口**：网络封面**加载失败**（URL 失效/断网/防盗链）时，现状回落默认书图标或文字占位，不走配色 → 已按指令补上失败回落。
- 操作者确认：回调 warm=1 与配色覆盖均为操作者直接指令。

### 红色问题判定

- 否：warm 数值为性能参数回调；配色回落为既有体系的覆盖面补全。

## 3. 为什么做

- warm=0 的代价（标签切换现组合）真机判定不可接受；warm=1 是折中（滑动元凶既然不是热邻居，回调不损失滑动优化预期）。
- 配色封面是指令重申的既有产品行为；加载失败回落是唯一未覆盖的真实场景（URL 失效的书此前永远显示灰底图标）。

## 4. 本次范围

1. `MainScreen` 主 pager `beyondViewportPageCount` 0→1。
2. `CoilBookCover`（内层 BookCoverImage）：网络封面加载失败 → 渲染配色封面（`GeneratedCoverFace`，自带书名绘制；seed 与既有兜底同源，同一本书恒定同款）。
3. 外层 `CoilBookCover`：失败时不再叠加文字占位（配色封面已含书名）。
4. 覆盖面自动达成：主页阅读列表卡 / 阅读列表页 / 阅读记录两页全部经 `CoilBookCover` 渲染。

明确不做：

- 滑动掉帧本轮不做任何未经验证的改动——**下一轮先加 Perfetto/帧耗时打点、真机抓取定位元凶后再改**（避免 1.8.x 式盲改循环）。

## 5. 用户如何使用

1. 切换标签页恢复 1.8.5 的手感（相邻页预组合）。
2. 封面 URL 失效/无图的书：主页卡、阅读列表、阅读记录、详情一律显示稳定分配的配色封面（同一本书恒定同款），不再出现灰底书图标。

## 6. 产品规则

- 网页/本地书籍无图可提取（创建时无图、路径缺失、**或加载失败**）→ 配色封面（八款，随机匹配默认开启，可在封面设置中调整）。
