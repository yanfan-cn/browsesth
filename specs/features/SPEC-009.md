## 3. 为什么做

用户无法阅读任何网页，且切页体验相对原版明显变差。须先恢复可见网页，再减轻主界面动画掉帧。

## 4. 本次范围

要实现：

1. AwContents 回退 SOFTWARE 图层 + 空 DrawFn（LOG-006 急救）。
2. Home 有浏览器会话时，不对 pager 内容做 hazeSource/layerBackdrop。
3. NTP（无会话）恢复邻页预热（beyondViewport≥1）；有会话仍为 0。
4. 主框加载错误以 Snackbar 可见提示。
5. 保留工作区 SPEC-008 会话外壳改动，与本修复一并交付。

明确不做：换核、硬件 DrawFn 再打磨（后续 Spec）、默认关闭液态玻璃产品决策（本轮仅隔离采样）、整 App UI 重做。
