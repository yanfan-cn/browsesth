## 需求

### R1 网页内点击地址栏全选
- 手机网页会话 omnibox 与平板功能栏 omnibox：点击获得焦点并显示当前网址时，文本**全选**（光标选择 0..length），可立即输入替换。
- 不改 NTP 搜索框（其常态为空输入）。

### R2 剪贴板链接候选
- 点击搜索框（手机 NTP）/ 地址栏（手机会话、平板）时读取系统剪贴板；内容为 `http(s)://` 且 host 非空的 URL 时，在候选栏（书签/历史建议面板顶部）显示「剪贴板链接」条目，点击直接打开该网址。
- 非 URL 内容不显示任何条目；退出焦点清除候选。
- Android 无独立剪贴板权限：焦点内读取即触发系统提示（12+ Toast / 13+ 允许粘贴对话框）；仅本地检测与展示，不上传。

### R3 平板回主页地址栏清空
- 平板回到浏览器主页（`showHome=true` 的 NTP 态）时，地址栏不再显示此前网页标题，显示为空 + 占位「搜索或输入网址」；回到网页会话时恢复标题显示。

### R4 滑层扩面（我的页卡顿/错乱跟进）
- 以下现有默认转场的页面统一纳入 `SlideOverlaySceneStrategy`（slide-only，下垫层保持组合）：
  阅读记录、阅读记录总览、AI 助手、高亮规则、书源管理/编辑/调试、RSS 源管理/编辑/调试、导入本地、导入远程、缓存管理、下载缓存管理、RSS 收藏、订阅规则、书籍人物详情/关系/列表、知识列表/详情、事件列表/详情。
- 例外不变：阅读器、漫画阅读器、网页会话（webViewEntryMetadata）、书籍详情、搜索、探索页（共享元素动画）、听书相关弹层页。
- 页面错乱不承诺本次根治：Diag145 栈日志已埋，若复现需 logcat 定位。

### R5 播放器下载修复（HLS 可播放文件）
- 现状：HLS（m3u8）直接下载播放列表文件（<1MB、后缀 .m3u8、无法播放）。
- 修复：嗅探 offer 为 HLS 时，解析播放列表 → master 多码率选最高 BANDWIDTH → 逐段下载 TS/MP4 分片合并为单文件：
  - 含 init 段（EXT-X-MAP）或 .mp4/.m4s 分片 → `.mp4`；否则 `.ts`；
  - 请求带 UA/Cookie/Referer（offer headers）；
  - 走现有下载列表（进度通知/暂停/删除不变）；HLS 暂停后恢复 = 从头重下（记录为已知边界）；
  - MP4 直链下载行为不变。
- 已知边界：合并文件绝大多数本地播放器可播，个别播放器对 fMP4 拼接兼容性有限，不承诺 100%。

### R6 重新播放修复
- 改用 ExoMedia 正式重播路径 `VideoView.restart()`（ENDED/IDLE 态内部会重新 prepare），返回 false（播放中暂停态）再退回 `seekTo(0)+start()`。
- 加 Diag146 日志记录重播路径与状态，供装机仍失败时定位。

## 验收标准

- AC-1 手机/平板网页会话点击地址栏 → 全选当前网址，可直接输入替换。
- AC-2 复制一条链接后点击 NTP 搜索框/会话地址栏 → 候选栏顶部出现「剪贴板链接」；点击打开该网址；剪贴板为非链接文本时无该条目。
- AC-3 平板打开网页后回主页 → 地址栏为空并显示「搜索或输入网址」占位；点缩略图回网页 → 地址栏恢复标题。
- AC-4 R4 列表页面进出均以滑入滑出呈现，下垫层不再整页重建；阅读器/搜索/书籍详情转场不变。
- AC-5 HLS 视频点「下载」→ 下载列表出现条目，完成后为单个 `.ts`/`.mp4` 文件，体积远大于 1MB（视片长），本地可播放；MP4 直链下载不变。
- AC-6 播放至结尾（或暂停中）点「重新播放」→ 从头开始且继续播放。
- AC-7 `:app:compileAppDebugKotlin` 通过；HLS 播放列表解析有 JVM 单测（master 选档/相对 URL 解析/分片收集/扩展名判定）。
- AC-8 assemble 本包 APK（巡页1.5.1-beta.apk），PATCH 进位 1.5.2。

- 不做 HLS 分片并发下载与断点续传（暂停恢复=重下）。
