## 3. 为什么做

阅读列表卡片进详情是高频路径，现行过渡被操作者判定为「极其生硬、严重掉帧」，退出同样差。同一处细节反复返工（SPEC-183 的整页滑入仍未解决观感）。本次改用「卡片长成详情页」的 fade-through 语言，并把转场期的重活错峰，同时修掉主页卡内滑动会误翻页的 bug。

## 4. 本次范围

要实现：

1. 阅读列表（书架）与浏览器主页「阅读列表」卡，点封面进/退详情使用同一套 fade-through 动画：不再整页位移、不再缩放底下页；封面持续 morph，正文与配色错峰出现。
2. 转场期重活错峰：背景图改小图放大（不用实时模糊）、配色首次直接落色不跑长动画、正文在页面稳定后短暂延迟淡入。
3. 主页「阅读列表」卡内滑动期间，外层主 Pager 始终不可滑；卡外翻页不变。

明确不做：

- 不改卡片布局/网格列数，不加「全部 ›」入口。
- 不动阅读器（ReadBook / 漫画）转场、浏览器会话转场、平板壳。
- 不改封面 sharedBounds 的 key 体系与圆角缓存。

## 5. 用户如何使用

1. 在阅读列表或主页卡片点某本书封面。
2. 封面从卡片位置平滑长大到详情页头部位置，详情页背景淡入，标题/作者随后淡入；不再整页从右侧滑入。
3. 页面稳定后正文分区块淡入，配色已是最终色，无中途整页变色。
4. 返回：正文淡出、封面缩回卡片原位、背景淡出。
5. 在主页「阅读列表」卡内左右滑封面列表：卡片内正常横滑，主页面不翻页；在卡外左右滑仍可翻到「阅读列表 / 我的」。

## 6. 产品规则

- 进入/退出详情的页面级转场只能是淡入淡出与封面 morph；不得对整页做水平位移或缩放。
- 主页卡片内的左右滑动（含快速轻扫、行首行尾）不得翻动外层主页面。不得靠按下时重组主 Pager 来实现。
- 系统不得因上述改动丢失封面 morph 的连续性（退场后封面必须回到触发卡片）。封面不得画在液态玻璃离屏层里面。

## 7. 重要状态与边界

| 情况 | 用户应该看到什么 | 数据/状态处理 |
| --- | --- | --- |
| 正常进入 | 封面 morph + 背景/头部淡入 | 无持久化 |
| 正常退出 | 反向，封面回卡片 | 无持久化 |
| 无封面（配色兜底封面） | 同样 morph，不闪成默认图 | 沿用 SPEC-185 兜底 |
| 封面加载失败 | 显示兜底，动画不中断 | 沿用现有 onNetworkCoverLoadError |
| 快速连点/中途返回 | 动画可被打断并回到一致状态 | 由 Compose 转场状态机处理 |
| 卡内横滑，含滑到行首行尾后的快速轻扫 | 封面列表自己滚动，主页面不翻页 | 剩余水平位移和水平速度在卡片内吃掉 |
