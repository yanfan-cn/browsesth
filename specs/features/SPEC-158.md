# SPEC-158 主页预置壁纸 / 菜单切换 / 相册添加

状态：已确认（2026-10-21 操作者「你做的六张图都要。默认是下白、上浅蓝那一张。其他确认，然后构建app」）
日期：2026-10-21
关联：SPEC-018（每日壁纸）、SPEC-049（主页自定义菜单）

## 背景

每日壁纸关闭时，浏览器主页只有纯色底。操作者要一组清新简约的预置背景，能适配手机和平板不同宽高比，并在左上角主页菜单里切换；也要从系统相册添加自己的图。

## 需求

- **R1 六张内置，默认浅蓝渐变**  
  内置且不可删除：下白上浅蓝、下白上浅绿、下白上浅粉（用渐变绘制，不裁切）、晨纸、薄雾、窗纱（图片居中裁切铺满）。默认选中浅蓝渐变。
- **R2 何时显示**  
  关掉「每日壁纸」且非无痕时，铺当前选中的背景。Logo 保留。内置壁纸上快捷书签名为深色。  
  打开「每日壁纸」仍用必应图（现有暗色遮罩、浅色字、隐藏 Logo）；菜单里的选择保留，关掉每日壁纸后恢复。  
  无痕不铺壁纸。  
  深色主题下仍显示当前背景，并加一层淡淡的深色遮罩，书签名改为浅色。
- **R3 菜单**  
  左上角主页菜单可切换上述背景。选中立即生效。
- **R4 相册**  
  可从系统相册添加图片，只存在本机。可继续添加，可删除。用户的图居中裁切铺满，并加一层淡淡的暗色，书签名改为浅色。删掉当前正在用的用户图后，回到默认浅蓝渐变。

## 边界

- 不改每日壁纸开关的默认开/关。
- 不上传壁纸。不申请整个存储权限，只用系统选图。
- 晨纸、薄雾、窗纱三张照片不能删除。
- 本轮打 debug 包。

## 验收

- AC-1 关掉每日壁纸后，主页默认是下白上浅蓝的渐变；手机与平板、横竖屏都铺满且不变形。
- AC-2 主页菜单可在六张内置之间切换，选中立即换背景；内置壁纸上 Logo 在、书签名为深色。
- AC-3 可从相册添加一张并立即用作背景（有淡暗色、浅色字）；可删除该图；删当前图后回到浅蓝渐变。
- AC-4 打开每日壁纸仍显示必应图；关掉后回到菜单里选中的那张。无痕主页没有这些壁纸。
- AC-5 组装 debug `巡页1.6.0-beta`。
