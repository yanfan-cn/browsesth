## 4. 范围

1. 全版本外观「表面样式」不再提供「半透明」。
2. API &lt; 35 默认「填充」；API 35+ 仍默认「液态玻璃」。API 33–34 可选填充/液态玻璃；API &lt; 33 仅填充。
3. 顶栏按钮样式由表面样式驱动：填充→`tonal`，液态玻璃→`liquid`；「顶栏与底栏」中隐藏该切换项。
4. 表面为填充时，阅读模式顶栏/底栏使用不透明填充背景（修复临时小说透明栏）。

明确不做：不恢复分散液态玻璃开关；不改抽取/内核。

## 8. 验收

- AC-01：任意 API，外观表面样式选项不含「半透明」。
- AC-02：API &lt; 35 新装/空值解析为填充；API 35+ 为液态玻璃。
- AC-03：切到液态玻璃后顶栏按钮呈液态玻璃；切到填充后呈填充（tonal）；设置里无顶栏按钮样式下拉。
- AC-04：表面为填充时，阅读（含浏览器临时小说）顶栏与底栏可见实色填充背景，非全透明。
- AC-05：表面为液态玻璃且系统支持时，阅读栏仍为玻璃效果。
