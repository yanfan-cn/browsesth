## 2. 确认

- 2026-10-08 复述后确认；「全部关闭」底部居中 icon；液态玻璃透度浅色 0.35 / 深色 0.28
- 红色：否

## 3. 为什么做

液态玻璃模式下 NTP 组件被近不透明实色盖住；标签页顶栏与进出动画生硬；历史/书签 favicon 常空白；书签/下载缺历史同款搜索。

## 4. 范围

1. **NTP 液态玻璃通透度恢复**：液态玻璃下搜索胶囊、顶栏键、快捷书签圆底用低 alpha 着色（浅 0.35 / 深 0.28）；填充模式仍用实色 `surfaceContainerLow`（保留 SPEC-067/069 色阶）。
2. **长按标签计数菜单重设**：主页=新建/关闭全部；底栏=+添加书签；Material Symbols + 无阴影可读浮层。
3. **标签页顶栏**：常规/无痕分段居中、宽=页宽 50%；新建 icon 距边 16dp；「全部关闭」改为底部居中 icon（同返回/新建样式），只关当前分段。
4. **标签页过渡**：点缩略图进网页、进出标签页 → 更跟手、成对过渡、减轻卡顿（约 220–280ms）。
5. **历史/书签 favicon**：与 NTP 快捷书签同候选链 + 字母占位。
6. **书签、下载**：历史同款胶囊搜索框。

明确不做：改分段语义；改下载链路/工具箱/阅读器；采样 AwContents；commit/push。

## 6. 产品规则

- 液态玻璃 + 非无痕：NTP 玻璃控件叠加色 alpha 浅色=0.35、深色=0.28；无痕仍独立深色逻辑。
- 填充表面：NTP 组件底保持 `surfaceContainerLow` 实色（无痕圆底仍深色）。
- 全部关闭：底部居中 icon；仅当前常规/无痕分段。
- favicon：按 NTP 候选依次尝试；全失败显示标题首字母。

## 8. 验收

- AC-01：液态玻璃浅色 NTP，搜索胶囊/顶栏键明显通透（可透出壁纸或背景），非近不透明实色块。
- AC-02：液态玻璃深色 NTP 同 AC-01 通透感；无痕样式不回归。
- AC-03：填充模式下 NTP 组件底仍为 App `surfaceContainerLow` 色阶。
- AC-04：长按主页标签计数 → 新建 / 关闭全部（图标+文案、无阴影浮层）；底栏长按另有添加书签。
- AC-05：标签页分段控件居中且宽约 50%；新建距右缘 16dp。
- AC-06：底部居中「全部关闭」为 icon（非文字大按钮）；点按只关当前分段。
- AC-07：进/出标签页与点缩略图回网页有成对淡入淡出+轻缩放，时长约 220–280ms，无一侧完全无过渡。
- AC-08：历史与书签条目左侧出现站点 favicon 或字母占位（非长期空白圆）。
- AC-09：书签、下载页有与历史同款胶囊搜索框，输入可过滤列表。
