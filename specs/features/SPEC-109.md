| 状态 | Done |

## 做

1. 工具箱按键叠色浅 0.90 / 深 0.92。
2. 长按阅读 FAB：菜单顶部「自动开启阅读模式」开关（开=TriggerMode.AutoDetect，关=Manual）；三项：文本 / 图片 / 图文混合。
3. 文本=小说抽取去图；图片=漫画阅读；图文混合=小说抽取保留正文图。
4. FAB 菜单与标签长按菜单均在底栏上方弹出。
5. 短按 FAB 行为不变。不构建。

## 验收

- AC-01：工具箱按键比此前更不透、文字更清晰
- AC-02：长按 FAB 出菜单；开关可切换自动/手动并持久化
- AC-03：三项分别进入对应阅读路径
- AC-04：标签/FAB 菜单在底栏上方
