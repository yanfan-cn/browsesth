## 3. 本次范围

1. 抽图：短边 &lt; 240、面积过小、极端宽扁横幅、常见 icon URL 模式过滤；候选图 HEAD/`Content-Length` &lt; 8KB 丢弃。
2. 封面：漫画取过滤后最大图；小说取 `og:image`/twitter:image，否则最大图；写入 `coverUrl`。NTP 书架横滑卡片长按封面 → `ChangeCoverSheet`，选中后更新并刷新展示。
3. 漫画加载：提高章内预取并发；保证网页漫画单章预取窗口有效。

明确不做：assemble APK；底栏叠字；SPEC-013 真机验收；整包 Cimoc。

## 4. 验收标准

- [ ] AC-01：样例漫画页抽图结果不含明显 icon/小横幅（相对修前列表更干净）。
- [ ] AC-02：加入书架后书封非空（漫画为正文大图之一；小说优先 og 图）。
- [ ] AC-03：NTP 书架卡片长按封面可打开换封面面板并更换成功。
- [ ] AC-04：漫画翻页时后续图预取并发高于修前（日志或代码常量可证）。
