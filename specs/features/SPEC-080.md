## 3. 范围

1. 标签页（仅平板）：一行 4 列；顶栏「全部关闭」在「+」左侧（关全部标签）；系统返回关闭标签面板回到软件内上一页。
2. 平板标签条右上：标签计数徽章 + 长按菜单（新建/关闭所有/添加书签）；功能栏去掉标签图标。
3. 标签条与功能栏无视觉间隙。
4. 平板设置：二级（右栏）无返回键；一级返回随液态玻璃/填充；左栏列表改 M3/ClickableSettingItem 风格；深色「设置」标题=onSurface。
5. 历史/收藏侧栏嵌手机端 Screen。
6. 工具箱下载改为侧栏，不进全屏路由。

明确不做：手机布局；回退 079 玻璃约束；commit/push。

## 8. 验收

- AC-01：平板标签页一行 4 个；顶栏有全部关闭且可关光所有标签。
- AC-02：标签页打开时系统返回关闭面板，不回桌面。
- AC-03：标签计数在标签条右上；长按有新建/关闭所有/添加书签；功能栏无标签图标。
- AC-04：标签条与地址栏行无间隙。
- AC-05：设置右栏无返回；左栏返回随表面样式；左栏为 M3 列表；深色标题浅色字。
- AC-06：历史/书签侧栏 UI 与手机一致（搜索/favicon 等）。
- AC-07：工具箱下载在侧栏打开，非全屏。
- AC-08：液态玻璃下开标签不回归闪退（079 约束保留）。
