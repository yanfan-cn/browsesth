# SPEC-209：阅读列表顶栏对齐/折叠选择 bug + 净读顶栏与菜单精简

| Spec ID | SPEC-209 |
| 状态 | Implemented（2.0.7-beta 待装机） |
| 基线 | SPEC-198/200/206；操作者确认 2026-10-30 |
| 依据 | 截图四项：菜单贴顶栏、已选文案偏低、折叠进选择叠字、填充顶栏布局与设置多余页签 |

## 做

1. 阅读列表顶栏 ⋮ `RoundDropdownMenu` 相对锚点下移至少 **4dp**。
2. 选择模式「已选 X 本 · 共 Y 本」与顶栏圆钮同一行垂直对齐（作 title，勿作 Flexible 副标题）。
3. 折叠顶栏进选择模式：无叠字/残影；选择文案始终可见且对齐；不再用「折叠时空主标题」导致副标题错位（修正 SPEC-206 折叠空标题在选择态的副作用）。
4. 净读顶栏：填充模式布局与液态玻璃一致（独立圆形按键 + 标题胶囊；不合并为条）。设置→菜单：删除「顶栏布局」整页及选项；取消「底栏布局」页签文字，进入菜单直接显示底栏布局选项。

## 不做

- 不改底栏布局选项内容本身；不改浏览器其它菜单（除非共用 offset 参数默认不影响既有调用）。

## 验收

- [ ] AC-01：阅读列表 ⋮ 菜单上沿距顶栏按键 ≥4dp。
- [ ] AC-02：选择模式「已选…」与关闭/搜索等圆钮垂直居中对齐。
- [ ] AC-03：折叠顶栏后进选择模式无叠字，文案与按键对齐。
- [ ] AC-04：净读填充模式顶栏为独立圆钮布局（同玻璃结构）。
- [ ] AC-05：设置→菜单无顶栏布局页签，直接见底栏布局选项。
- [ ] AC-06：assemble debug 出包。
