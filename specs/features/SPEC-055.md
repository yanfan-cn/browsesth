## 4. 范围

要实现：

1. 主页与浏览底栏标签计数控件由圆角矩形改为正圆；数量仍为准确数字。
2. 进出标签页（含新建后离开）使用短淡入淡出或轻缩放过渡。
3. 标签页顶栏去掉「标签页」字样；中间一体胶囊分段「常规 (n)」「无痕 (m)」；切换只筛选列表；「+」在当前分段下新建；切「无痕」不改变 Cookie/历史隔离。
4. 「全部关闭」只关闭当前分段标签。
5. 平板进入标签页全屏复用手机同一套 UI，不保留平板浏览器顶栏（标签条/地址栏）。

明确不做：无痕隔离行为改造；标签组；平板其它侧栏（书签/历史）重做。

## 6. 产品规则

- 进入标签页时，默认选中与当前活动标签模式一致的分段；无活动标签则选「常规」。
- 主页/底栏圆形数量显示全部标签总数（常规+无痕）。
- 分段括号内数字分别为该模式打开中的标签数。
- 系统不得因切换分段而进入或退出无痕浏览隔离。

## 8. 验收标准

- [ ] AC-01：主页与底栏标签计数外观为正圆，且显示准确数量（含 0、大于 9）。
- [ ] AC-02：标签页顶栏无「标签页」标题，可见「常规 (n)」「无痕 (m)」分段且数量准确。
- [ ] AC-03：切换分段后网格只显示对应模式标签；「+」在无痕分段新建的标签 `incognito=true`，且未因此改变全局无痕隔离开关语义（仅标签属性）。
- [ ] AC-04：「全部关闭」后仅当前分段标签清空，另一分段标签仍在。
- [ ] AC-05：进出标签页有可见短过渡，非硬切。
- [ ] AC-06：平板打开标签页为全屏手机同款 UI，且浏览器顶栏（标签条/地址栏）不可见。
