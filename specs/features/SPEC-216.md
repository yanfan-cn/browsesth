# SPEC-216：净读破图过滤 + 滚动点击区 + 删图片点击菜单 + 翻页动画可切换

| Spec ID | SPEC-216 |
| 状态 | Implemented（待真机） |
| 基线 | SPEC-208/210/212/215；操作者确认 2026-11-01 |
| 依据 | 破图感叹号+尺寸行；手机藏双页入口；滚动专用点击区；删 clickImgWay；翻页动画无法切换 |

## 复述

1. 视频缩略图下感叹号破图不绘制、不占可点；一律过滤正文中 `\d+\*\d+\s*/\s*\d+\*\d+\*\d+\s*\(ext:` 形态行。  
2. 手机端翻页动画右侧取消「平板/横屏双页」入口。  
3. **仅滚动动画**用点击区默认：上三无操作、中三菜单、下三无操作；其它翻页动画仍用原 clickAction*。  
4. 菜单删除「点击图片行为」；仅保留双击预览（默认开）；单击非净视图不进图库。  
5. **Bug**：双页档 2/3 的方向联动 `LaunchedEffect` 依赖 `pageAnim`，用户改动画后被强制打回 → 去掉该依赖，手动切换可保持。

## 做

- 破图：`errorBitmap` 不进净读绘制；失败图尺寸不占位；过滤尺寸调试行。  
- 手机：`GlobalThemePage` 隐藏双页方卡。  
- 滚动专用 9 格 prefs（或运行时解析）；配置页随当前动画读写对应档。  
- 图片点击：UI 移除；逻辑固定双击预览（净视缩略图例外）。  
- `ReadBookRouteScreen` 方向联动 keys 不含 `pageAnim`。

## 不做

- 不改双页四档语义本身；不改平板横屏双页能力。  
- 不恢复五种 clickImgWay。

## 验收

- [ ] AC-01：破图感叹号与 `* / * (ext:` 行不再出现。  
- [ ] AC-02：手机翻页行动画旁无双页入口；平板仍有。  
- [ ] AC-03：滚动时点击区为上无/中菜单/下无；切封面等后为原分区。  
- [ ] AC-04：更多设置无「点击图片行为」；双击图预览；单击普通图无图库。  
- [ ] AC-05：手机/平板均可切换并保持非滚动翻页动画。  
- [ ] AC-06：assemble debug 出包。
