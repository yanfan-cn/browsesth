## 3. 为什么做

主页搜索区与参考图/产品名「巡页」阅读气质不一致；缺少主页模块显隐与壁纸控制；快捷书签卡片过重。

## 4. 本次范围

要实现：双行搜索胶囊；无痕更名；扫码与搜索键态；左上自定义菜单；快捷书签去底+网格+自动图标；平板 55%/一行六；UI 文档同步；assemble。

明确不做：真实 AI；改 applicationId；探索发现卡；重做书架页本身。

## 5. 用户如何使用

1. 打开 NTP：见双行搜索与左上自定义。
2. 输入文字后搜索键变实心，点搜索或键盘 Go 打开。
3. 扫码填入/打开；自定义开关壁纸与模块显隐；快捷书签无卡底，添加后显示站图标。

## 6. 产品规则

- 搜索键：无输入 FILL 0；有输入 FILL 1。
- 「添加」永远在快捷书签网格最后一格。
- 过渡期不得同时组合 NTP 与会话 WebView（既有约束不变）。
- 新 UI 无阴影。
