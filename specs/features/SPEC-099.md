# SPEC-099：工具箱菜单玻璃底 + 按键统一

| Spec ID | SPEC-099 |
| 状态 | Done |

## 用户问题

工具箱仍像实色 Sheet；按键大小不一、间距偏紧、有分割线，与液态玻璃主页不协调。

## 范围

### 做

- 手机 Sheet + 平板侧栏工具箱面板：液态玻璃底，叠色浅 0.35 / 深 0.3（填充模式实色）。
- 按键叠色提高（更不透）；置顶与网格统一高度/图标/字号；圆角仍 24dp。
- 加大按键间距；去掉置顶与网格间分割线。

### 不做

- 不改功能项与排序；不改全局 NTP 叠色常量。

| AC-02 | 同上 | 目视按键 | 比此前更实；尺寸一致 |
| AC-03 | 同上 | 目视布局 | 间距加大；无分割线 |
