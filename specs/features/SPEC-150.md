# SPEC-150 外观设置精简与「净读」命名

状态：已确认（2026-10-20 21:0x 操作者确认：改名仅限产品功能名；液态玻璃仅改描述；订阅只删入口与设置项；构建 Release 包）
日期：2026-10-20
关联：SPEC-056/061（表面样式）、SPEC-144（墨水屏开关）、SPEC-132（视频胶囊）、SPEC-108（版本纪律）

## 背景与需求（操作者 2026-10-20 20:58 指示）

设置 → 外观（ThemeConfigScreen）：

1. **R1** 删除「仍有部分界面未用Compose重构，这些界面会与大部分界面有较大差异。」提示卡及其关闭逻辑。
2. **R2** 「墨水屏显示」默认改为**开**（已显式存“关”的老用户保持关），并从外观页**隐藏**该开关；效果＝「E Ink」主题（theme "4"）在主题列表恒可见。
3. **R3** 删除「订阅」主页面（底部导航标签）及相关设置选项：主导航设置中的订阅开关/图标行、主题包编辑器中的订阅开关。底层订阅源功能代码保留。
4. **R4** 「表面样式」选项上移至「纯黑深色模式」开关正下方；描述删除「统一控制半透明、填充或液态玻璃外观」，改为「安卓13以上才可使用液态玻璃」（现有策略本就强制 <13 仅填充，此次仅改文案）。
5. **R5** 删除「容器设置」整组全部选项（容器背景图、透明度、圆角/边框覆盖、分割线）。仅删 UI 组；ThemeSettings 模型字段与主题包导出契约保留（兼容既有主题包）。

命名（操作者确认范围＝产品功能名，非全 App 通用词）：

6. **R6** 「阅读模式」→「净读模式」；浏览器净读功能面 UI 中「阅读」→「净读」（净读视图、净读列表、自动净读模式、净读书签、小说净读/漫画净读等）；「视频胶囊」→「净视胶囊」。不含：小说阅读器通用词（阅读时长/阅读进度等）、网页净化过滤关键词（WebArticleChromeFilter 的“阅读模式”是站点元素匹配词，**不得改**）。
7. **R7** 以上命名写入产品宪章 `specs/CONSTITUTION.md` §2（由操作者明确指示，AO 代为修改，Log 注明授权）。

8. **R8** 完成后构建 **Release** 包（debug 密钥签名，同 SPEC-148 偏差 3 方案），版本用当前 1.5.4-beta / 196，成功后按 SPEC-108 进位 1.5.5-beta / 197。

## 验收标准

- AC-1 外观页无「仍有部分界面未用Compose重构…」卡片。
- AC-2 外观页无「墨水屏显示」开关；全新安装（无历史偏好）主题列表出现「E Ink」主题。
- AC-3 底部导航无「订阅」页；主导航设置表无订阅行；导航图标管理无订阅行；主题包编辑无订阅开关。
- AC-4 表面样式选项位于纯黑深色模式正下方，描述为「安卓13以上才可使用液态玻璃」。
- AC-5 外观页无「容器设置」组。
- AC-6 浏览器净读入口与提示均显示「净读」（净读 FAB、工具箱净视胶囊、浏览器设置净读模式组）；小说阅读器与净读无关文案不受影响。
- AC-7 `巡页1.5.4-beta.apk`（release，debug 密钥签名）构建成功，版本进位 1.5.5-beta/197。
- AC-8 编译 + 单测不回归；`git diff --check` 干净。
