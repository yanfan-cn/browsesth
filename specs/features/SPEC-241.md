## 3. 为什么做

腾讯系等站点用 P2P/SDK 拉流时，主帧常看不到 `.m3u8`，只看到 `.ts` 分片 → 净视胶囊不出现；进入净视播放器时黑屏无反馈。

## 4. 本次范围

1. 从腾讯风格 `.ts` 分片 URL 反推同目录 `.ts.m3u8` 播放列表并 `publish`（带分片请求头）；单测覆盖。
2. 净视播放器：起播前中央转圈；尽量显示缓冲进度与/或瞬时网速；起播后隐藏，再缓冲再显。
3. debug 出包；真机复验本失败页胶囊可出。

明确不做：不保证纯 MSE 加密、无分片 URL 的站点；不改广告拦截。
