## 现状证据

- 收藏页（网页书签）=`BrowseStore`（SharedPreferences JSON：`Folder(id,name,order)` 单层 + `Entry.folderId`）；书签页（阅读书签）=`ReadingBookmarkOrgStore`（复用 `BrowseStore.Folder` + time→folderId 归属表）。两套存储均单层文件夹。
- `BrowseStore.MAX_BOOKMARKS = 100`——批量导入会被截断，需提升。
- 书签页 UI：`BrowserBookmarksScreen` 两页 pager；文件夹行仅根层显示；删除文件夹无确认（现行为仅上移书签到根）；移动弹窗为平铺单层列表；「+」仅收藏页有，打开「加入收藏」弹窗（`BookmarkEditDialog`）。
- 其他浏览器书签获取通道：手机端浏览器普遍不可直读（私有目录/无提供器），通用可行通道为 Netscape 书签 HTML 文件（桌面端 Chrome/Edge/Firefox 与多数手机浏览器可导出）。

## 范围

1. **多层文件夹（两套存储都做）**
   - `BrowseStore.Folder` 增加 `parentId`（缺省 ""=根；旧数据读取自动补 ""，完全兼容）。
   - 两套存储：`addFolder(name, parentId)`；删除文件夹改为**连带删除**其下全部子文件夹与书签（阅读侧连带清理归属表）；提供子级列表、路径链、子树统计等纯函数（抽 `BookmarkFolderTree` 供两 store 复用并可 JVM 单测）。
2. **书签页 UI 多层化**
   - 两页文件夹行按「父=当前目录」显示，可逐级进入；顶栏返回键改为上一级（非直接退出），系统返回键同语义（BackHandler）。
   - 新建文件夹建在当前目录；「移动到…」弹窗改树形列表（缩进展示全层级，含根目录）。
   - 删除含内容的文件夹先弹确认框（写明将连带删除 X 个子文件夹、Y 条书签）。
3. **导入其他浏览器书签**
   - 解析 Netscape 书签 HTML（jsoup），支持嵌套文件夹、大小写/无引号属性/`<p>` 等导出器差异；`javascript:` 等非 http(s) 链接跳过；空标题回退为网址。
   - 入口：收藏页「+」→「加入收藏」弹窗，标题字样下方一行「导入其他浏览器书签」；点击 → 系统文件选择器 → 读文件（上限 ~8MB）→ 预览（N 条书签 / M 个文件夹）→ 导入。
   - 归属：全部进**收藏**页根目录，按原层级重建文件夹（同名同父复用已存在文件夹）；导入的书签不进书签页。
   - 去重：URL 已存在默认跳过；预览提供「覆盖已存在」选项（覆盖=更新标题并归入新位置）。
   - `MAX_BOOKMARKS` 100 → 1000；超出上限时导入截止并如实提示。
4. **边界**：不做导出；不做手机版 Chrome 直读；不加文件夹移动/重命名新 UI（沿用现有能力面）；书签页阅读书签本体（Room）结构不变。

## 验收

- AC-01：导入 Chrome 桌面导出的 `bookmarks.html`（含多级文件夹）后，收藏页出现完整层级与条目；重复 URL 默认跳过、选覆盖则更新。
- AC-02：收藏页与书签页均可建多层文件夹、把书签移动到任意层级、逐级返回（顶栏返回与系统返回键）。
- AC-03：删除含子文件夹/书签的文件夹弹确认并连带删除；删除后计数与列表一致。
- AC-04：旧数据升级后不丢失、不错位（老文件夹自动变根层）。
- AC-05：解析与导入核心（HTML 解析、文件夹树、导入去重）单测通过；既有相关单测不回归。
- AC-06：真机验收（导入样例文件 + 两页多层操作 + 删除确认）。
