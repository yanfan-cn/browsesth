# SPEC-143 视频播放器体验修复（6 项）

状态：已实施（待装机验证）
日期：2026-10-19
关联：SPEC-132/135/136/137

## 背景

用户实测 1.4.7-beta 播放器，反馈 6 个问题。

## 需求

1. **旋转跟随系统**：系统「自动旋转」关闭时，播放器不得自行横竖屏切换；开启时保持原有重力感应。现状：Activity 硬编码 `SCREEN_ORIENTATION_SENSOR`，无视系统开关。
2. **进度条闪回**：拖动进度条松手后，滑块先闪回原播放位置 1~3 帧再跳到目标位置。原因：`seekTo` 异步生效（100~400ms），250ms 轮询器在此期间上报旧位置。
3. **快进/快退图标**：行为是 ±20s，图标却是 `replay_10` / `forward_10`（显示 10s）。
4. **长按+滑动调倍速失效**：SPEC-136 的「长按 2 倍速，按住左右滑在 1.5×/2×/3× 间切换」失效。根因：`detectTapGestures` 的 `onLongPress` 消费整个手势流，后续 `detectDragGestures` 收不到事件，`GestureMode.Speed` 永远无法触发。
5. **手势浮窗位置**：倍速/音量/亮度浮窗居中显示，应移到顶栏下方；倍速浮窗应显示全部三档（当前档用【】标注），让用户知道可左右滑。
6. **亮度跳变**：窗口亮度为 -1（跟随系统）时回退值硬编码 0.5f，实际屏幕即使只有 10% 亮度，一拖动就跳到 50%。应回退读系统亮度。
7. **多视频方案（问题 6）**：页面内有多个视频时的处理。选**方案 A（选集菜单）**：嗅探 Bus 从单槽扩展为列表（去重、最新在前、上限 20），播放器顶栏加「选集」入口（>1 个视频才显示），点击切换重播。

## 验收

- 系统自动旋转关闭 → 播放器不自动转；开启 → 重力感应生效。
- 拖动进度条松手，滑块停在被拖位置，不闪回。
- 快进/快退图标字形为 20（`forward_20`/`replay_20`，Material Symbols）。
- 长按进 2×，按住左右滑切 1.5×/2×/3×；浮窗显示 `1.5×　【2×】　3×`。
- 所有手势浮窗显示在顶栏下方（statusBar + 62dp）。
- 拖亮度从系统当前亮度起调，不跳 50%。
- 多视频页面播放器顶栏出现「选集」，可切换；切换时释放旧播放器。
