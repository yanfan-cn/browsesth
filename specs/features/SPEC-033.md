## 3. 为什么做

网页搜完键盘不收；滑底栏会进书架；滚动会藏底栏且无开关。用几次后主页点搜索会闪退。

## 4. 本次范围

1. 网页地址栏提交搜索后自动收键盘。
2. 网页中左右滑底栏不切书架/主分页；取消网页底栏按住左右滑切按钮（仍可点按）。
3. 手机默认滚动不藏底栏/顶栏；设置增加开关。
4. 修好主页搜索框提交后闪退。

明确不做：删除底栏；改阅读器底栏；禁止主页滑向书架。

## 5. 产品规则

- 网页地址栏 Go/搜索后必须收起键盘并取消焦点。
- 网页会话期间主界面 HorizontalPager 不可滑向书架。
- 网页底栏四个按钮只响应点按，不响应拖动切换。
- 手机滚动隐藏工具栏默认关；仅设置开启后向下滚动才隐藏顶栏和底栏。
- 主页搜索提交必须打开结果页且不得闪退回桌面。
