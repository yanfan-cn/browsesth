## 3. 为什么做

用户点选屏蔽时常被站点跳转打断；单次确认不便一次屏蔽多处；规则管理挤在浏览器设置同页，不便批量清理。

## 4. 本次范围

要实现：

1. 浏览器设置中「手动屏蔽」更名为「点选屏蔽」，进入独立列表页；页右上角支持跨域名多选删除。
2. 进入点选屏蔽后，浏览器底栏替换为屏蔽栏：关闭 | 设置 | 确认。
3. 点选改为多选；点「确认」才按当前域名批量写入规则；0 项确认则直接退出点选。
4. 点选态强制禁止网页跳转（含链接点击导致的导航）。
5. 点选中进「设置」挂起点选，从设置返回后继续点选。

明确不做：

- 不改广告资源拦截 / 弹窗 / 外链总开关逻辑。
- 不做规则云同步或选择器可视化编辑器。

## 5. 用户如何使用

1. 工具箱点「点选屏蔽」→ 底栏变为关闭/设置/确认，可连续点选页面元素（高亮）。
2. 点「确认」→ 规则按当前域名保存并立即隐藏；点「关闭」或 0 项确认 → 退出点选不保存未确认项。
3. 点「设置」→ 打开点选屏蔽规则页；返回网页后仍可继续点选。
4. 浏览器设置 →「点选屏蔽」→ 独立页查看/跨域名多选删除规则。

## 6. 产品规则

- 当处于点选态时，系统必须拦截主框架导航与外链跳转，不得因点击待屏蔽内容而离开当前页。
- 当用户点选元素时，系统必须加入待确认集合并高亮；再次点同一元素则取消选中。
- 当用户点「确认」且待确认集合非空时，系统必须将全部选择器写入当前域名规则并注入隐藏；然后退出点选态。
- 当用户点「确认」且集合为空时，系统必须直接退出点选态，不弹错误框。
- 当用户点「关闭」或系统返回键处于点选态时，系统必须退出点选并丢弃未确认选中。
- 当用户从点选栏进「设置」时，系统必须保持点选态（挂起）；返回会话后继续可点选。
- 点选屏蔽设置页多选删除必须支持一次勾选不同域名下的规则并批量删除。

## 7. 重要状态与边界

| 情况 | 用户应该看到什么 | 数据或状态如何处理 |
| --- | --- | --- |
| 正常确认 | 元素隐藏，退出点选栏 | 规则写入当前域名 |
| 0 项确认 / 关闭 | 恢复普通底栏 | 不写规则；清待选 |
| 空规则页 | 空状态说明 | 无删除动作 |
| 点选中跳转企图 | 仍停在当前页 | 导航被拦；待选保留 |
| 设置返回 | 仍为点选栏 | 挂起状态恢复 |
