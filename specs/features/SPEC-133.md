## 3. 为什么做

平板工具箱网格被裁切导致功能看似缺失；手机横屏底栏与 NTP 仍按竖屏排布，空间浪费且易贴挖孔边。

## 4. 本次范围

要实现：

1. 平板工具箱展示与可点功能与手机一致（同批置顶项与网格项及行为）。
2. 手机横屏：NTP 主控件区宽度约屏宽 65%（居中）。
3. 手机横屏：主页底栏移到屏幕右侧（竖向可用）。
4. 手机横屏：用系统 inset（状态栏/挖孔/安全区）按当前旋转方向避让贴边；**不得**强制左右各加一档竖屏状态栏等高边距。

明确不做：

- 不改平板 NTP 75%/55% 宽度策略。
- 不新增工具箱功能项。

## 5. 用户如何使用

1. 平板打开工具箱 → 可见并可使用与手机相同的全部工具项。
2. 手机旋转到横屏、在浏览器 NTP → 内容区约 65% 宽；主导航在右侧；挖孔/状态栏一侧有避让。

## 6. 产品规则

- 当平板打开工具箱时，系统必须展示与手机相同的置顶四项与可排序网格项，且点击行为一致（在无网页时允许与现网相同的「请先打开网页」类提示）。
- 当手机为横屏且处于浏览器主页 NTP 时，NTP 主内容列宽度必须约为屏宽 65%。
- 当手机为横屏且显示主页悬浮底栏时，底栏必须位于屏幕右侧区域。
- 当手机为横屏时，系统必须根据当前 WindowInsets（含 displayCutout / statusBars 等）在需要避让的一侧预留空间；竖屏一侧无 inset 时不得无故加边。

## 7. 重要状态与边界

| 情况 | 用户应该看到什么 |
| --- | --- |
| 平板工具箱 | 全套工具项可滚动/完整可见 |
| 手机竖屏 NTP | 保持现有全宽+底栏贴底 |
| 手机横屏 + 挖孔在左 | 左侧避让，右侧可贴近（底栏在右时与底栏协调） |
