# SPEC-218：平板网页长按失效 + 文字选中无法取消

| Spec ID | SPEC-218 |
| 状态 | Implemented（待真机） |
| 基线 | SPEC-073/093/130；操作者确认 2026-11-02 |
| Plan | [`../plans/PLAN-218.md`](../plans/PLAN-218.md) |
| Log | [`../logs/LOG-218.md`](../logs/LOG-218.md) |
| 依据 | 百度等页文字选中浮动条卡住（点空白/滑动无效）；平板纯文字与链接长按经常无菜单 |

## 开工前需求确认

- 已调查：截图为内核/系统文字选中 ActionMode（AI帮写/复制/分享/全选）；链接菜单走 `BrowserContextMenuJs`+Compose 底栏；`AwContentsHostView` 未跟踪/结束 ActionMode；平板上 `contextmenu` 常不触发而落入选区。
- Q1=A+B（点空白、滑动无效）；Q2=C（选中条与链接底栏菜单都常无）；Q3=纯文字+蓝色链接。
- 任务下达者确认：2026-11-02「确认」。
- 红色问题：否。

## 做

1. 文字选中浮动条出现后，**点空白**或**页面滚动**须取消选中并关闭菜单。
2. 平板上纯文字长按能稳定出现选中菜单；蓝色链接长按能稳定出现底栏链接菜单（优先于卡死选区）。
3. 手机一并受益；验收以平板为主。

## 不做

- 阅读器选区；OEM「AI 帮写」定制；SPEC-154 release 闪退 keep 规则。

## 验收

- [ ] AC-01：平板长按纯文字 → 选中浮动条；点空白 → 消失。
- [ ] AC-02：同上选中后滑动页面 → 选中与菜单消失。
- [ ] AC-03：平板长按蓝色链接 → 底栏链接菜单出现（非两者皆无）。
- [x] AC-04：assemble debug 出包 **2.1.9-beta** / code 261。
