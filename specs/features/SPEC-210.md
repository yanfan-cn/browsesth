# SPEC-210：平板净读双页/重进/顶栏空隙 + 标签页顶栏空隙

| Spec ID | SPEC-210 |
| 状态 | Implemented（待真机） |
| 基线 | SPEC-122/130/149/208/209；操作者确认 2026-10-30 |
| 依据 | 横屏仍单页；退出再进「净读视图不可用」；净读/标签页顶栏距状态栏空白；填充标题无底 |

## 做

1. **横屏双页**：方向联动以**实际** `ReadBook.pageAnim()` 为准；清掉网页临时书滚动覆盖后再切滑动；临时书不再强制写死滚动（交配置+方向联动）。
2. **再进净读**：加固 `resolveReaderHost`（Holder 回退/自愈）；避免因 hostRef 空误报「净读视图不可用」。
3. **顶栏空隙**：壳内净读顶栏不再叠加 statusBars（壳已留）；全屏 0、有浏览器顶栏时小间隙。平板标签页在壳内不再二次 statusBars。
4. **填充标题胶囊**：24dp 圆角矩形 + tonal 填充底（手机/平板；与玻璃同布局结构）。

## 不做

- 不改双页四档文案；不改手机独立标签页路由的既有 inset（仅平板壳内嵌入路径去双计）。
