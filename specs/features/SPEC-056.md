## 4. 范围

1. 外观设置提供统一「表面样式」：半透明 / 填充 / 液态玻璃（随系统版本过滤选项）。
2. 低于 Android 13：仅半透明、填充。
3. Android 13/14：三选一，默认半透明。
4. Android 15+：三选一，默认液态玻璃；可改半透明或填充。
5. 全局作用于浏览器壳、悬浮底栏、顶栏液态玻璃、阅读器/漫画菜单等。
6. 隐藏原分散液态玻璃开关（底栏、阅读菜单、漫画菜单等）。

## 8. 验收

- AC-01：外观可见统一表面样式控件，选项随 API 正确过滤。
- AC-02：API 35+ 新装默认液态玻璃；API 33–34 默认半透明；API <33 无液态玻璃选项。
- AC-03：选填充时相关控件为实色/近不透明；选半透明为半透明回退；选液态玻璃且系统支持时为玻璃效果。
- AC-04：原分散液态玻璃开关不可见。
- AC-05：Android 15+ 可将默认液态玻璃改为半透明或填充并立即生效。
