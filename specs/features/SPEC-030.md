# SPEC-030：顶栏加载进度条只在真实导航时显示

## 2. 复述确认

操作者：网页未刷新，顶栏刷新进度条一直在走。请修复。

范围：浏览器会话顶栏线性进度；只在主框架开始加载时出现，主框架结束或进度 100 时消失。iframe/XHR/子资源引起的进度回调不得重新拉起进度条。不改阅读器/RSS。

## 3. 验收

- [ ] AC-01：进入已打开的网页（无新导航）不显示顶栏进度条。
- [ ] AC-02：地址栏打开/刷新有进度；加载完成后进度条消失且不再循环。
- [ ] AC-03：页面停住后 iframe 或动态请求不得让进度条一直走。
