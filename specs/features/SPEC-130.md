# SPEC-130：平板藏栏不卡顿 + 状态栏强制实底

## 确认

1. 平板滚动隐藏后再上滑呼出浏览栏不应明显卡顿。
2. 手机与平板：状态栏区域强制实色背景；网页不得全屏侵占状态栏。
3. 组装。

## AC

- AC-01：平板开「滚动隐藏」：下滑藏栏、上滑呼出，呼出无明显卡顿（无整页闪/大顿）。
- AC-02：藏栏时状态栏仍有实色底，网页内容不顶到状态栏图标下。
- AC-03：手机网页会话同样：状态栏实色底，网页不侵占状态栏。
- AC-04：assemble 成功可装。
