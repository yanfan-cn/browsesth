## 范围

1. 「用户隐私与协议」全局更名为「用户隐私协议」：引导页摘要与节标题、`privacyPolicy.md` 正文标题、设置页 `privacy_policy` 条目、繁体/香港中文文案同步。
2. 引导第一页删除普通字号的小节标签（「用户隐私与协议」「功能介绍」），仅保留 Markdown 渲染的黑体大标题，消除标题重复（手机纵向与平板并排两种布局都改）。
3. 修复 Markdown 有序列表序号偏高：根因是列表序号 `AppText` 落到默认 `bodyMedium` 且与正文（`bodyLarge`）基线不一致；序号样式与首行正文对齐（`MarkdownBlock` 全局生效）。

## 边界

- 不改动引导页流程、页数、主题页内容。
- 不改动 Markdown 渲染其它行为（标题字号、无序列表、代码块等）。
