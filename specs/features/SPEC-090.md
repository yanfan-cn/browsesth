# SPEC-090：「我的」书签 → 浏览器书签列表（含阅读书签）

| Spec ID | SPEC-090 |
| 状态 | Ready |
| 确认 | 2026-10-09「确认。补充：本地阅读/浏览器阅读模式添加的书签也一并显示。」 |

## 范围
1. 「我的」书签入口打开 `MainRouteBrowserBookmarks`（不再开 AllBookmarkActivity）。
2. 浏览器书签列表同时展示 BrowseStore 书签与 Room 阅读书签（本地/浏览器阅读模式添加的）。
3. 点阅读书签打开对应书籍阅读并尽量定位到书签章节位置；可删除。

## 验收
- AC-01：我的→书签进浏览器书签页。
- AC-02：列表含网页书签与阅读书签。
- AC-03：点阅读书签能进入阅读（有书时）。
