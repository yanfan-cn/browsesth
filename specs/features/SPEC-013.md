### 红色问题判定

- 否（收紧误拦规则、UA 去自定后缀、绘制回退策略；不关广告硬条件、不改内核选型）。

## 3. 本次范围

1. 收紧广告 URL 子串规则，避免误拦百度首方/图床等资源；保留已知广告网络域名拦截。
2. User-Agent 去掉自定义 `Browsesth/…` 后缀，使用标准 Chrome Mobile UA。
3. 绘制：允许清除永久 SOFTWARE 锁并重试硬件 DrawFn；失败仍可回退 SOFTWARE；苹果站可注入顶栏 min-height 兜底。
4. 加载：硬件路径优先；AwSettings 开启默认缓存与图片自动加载；减少误拦带来的二次请求失败。

明确不做：底栏叠字布局、地址栏同步、关闭广告拦截总开关默认、改搜索引擎默认。
