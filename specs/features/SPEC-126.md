## 1. 确认

- 六项准确；「我的」图标 `person`；刷新|我的|搜索；阅读键文案「阅读」；胶囊浅灰底+24dp 圆角（参考 Edge「聊天」样式截图）。
- 红色问题：否。

## 2. 范围

1. 工具箱浮动卡片：内容高度、距底 16dp（不纵向拉满）；打开有过渡动画。
2. 顶栏：缩短搜索框；顺序 `后退|前进|刷新|我的|搜索|收藏|历史|阅读列表|工具箱|阅读(最右胶囊)`。
3. 阅读键：图标+「阅读」文字，浅灰填充胶囊，圆角 24dp。
4. 平板禁止手指滑动切换阅读列表/浏览器主页/我的（按钮跳转保留）。
5. 浏览器主页左右留白区可带动纵向滚动。
6. 去掉浏览器主页底部多余空白占位。

明确不做：手机壳；SPEC-124 B2b；换内核。

## 3. AC

- AC-01：工具箱卡片底边距屏幕约 16dp，内部无大块空拉高；打开可见过渡。
- AC-02：顶栏顺序与文案符合上文；阅读为最右胶囊。
- AC-03：点「我的」进入主壳我的页。
- AC-04：平板三页之间滑动无效；点入口仍可跳转。
- AC-05：NTP 左右空白区上下滑可滚主页内容。
- AC-06：NTP 底部无多余占位条/大块留白（允许正常内容底边距 ≤16dp）。
