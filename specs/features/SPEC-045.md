## 3. 范围
- 页面加载完成后识别：若**不是简体中文**（繁体、英、日、韩等），在浏览底栏上方显示询问条。
- 简体中文不显示。
- 点「翻译」：进入阅读模式并开启章节翻译（不整页 DOM 改字）。
- 点「不」：关闭本条；同一地址不再问；换地址再判断。
- 手机：底栏上方。平板：内容区底部（浏览栏附近）。
- 浏览器设置「打开阅读时自动翻译」保留；询问条当场选择优先。

## 4. 不做
- 不在网页内实时整页翻译。
- 不改搜索/净化主路径。

## 5. 验收
- [x] AC-01：简体中文页不出现询问条。
- [x] AC-02：英文或繁体页出现询问条（底栏上方/平板内容底）。
- [x] AC-03：点「翻译」进入阅读且 translationMode 开启。
- [x] AC-04：点「不」后同址不再出现；换址可再出现。
