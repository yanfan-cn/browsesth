- 否：壳层观感与封面展示，不改变产品边界。

## 3. 为什么做

快捷站图标糊/缺、净读封面单调、主页顶底可读性不足、手机横屏内容区偏宽。

## 4. 本次范围

要实现：

1. **默认快捷本地图标**：百度 / B 站 / 热榜 / IT 之家 / 澎湃 / 巡页使用本地高清图；新增默认快捷「巡页」→ `https://share.feijipan.com/u/xcUCqQCUN`。
2. **统一封面**：主页净读列表长按与书架详情长按同一套换封面能力——可选纯色/渐变模板；网页书优先用/可保留网页图；无图时生成配色封面而非灰块。
3. **浏览器主页顶栏与底栏**：仅渐变半透明遮罩（不要真实模糊）；不改网页会话栏。
4. **手机横屏**：仅微调 NTP 内容区宽度比例（向平板观感靠拢），不重做顶栏/壳结构。

明确不做：

- 本期不提交默认站图标位图（等操作者提供）。
- 不做网页会话顶底渐变遮罩。
- 不重做手机横屏信息架构（顶栏收纳、对齐平板双栏等）。

## 5. 用户如何使用

1. 主页净读列表长按封面 → 选配色或网页图 → 列表与详情同步更新。
2. 书架详情长按封面 → 同一套面板。
3. 打开浏览器主页（有壁纸时）→ 顶底可见渐变遮罩，按钮文字更易读。
4. 手机横屏主页 → 内容区略收窄。

## 6. 产品规则

- 配色封面必须可持久化（写入 `customCoverUrl` 或等价字段），重启后仍显示所选配色。
- 网页书有可用 `coverUrl` 时，换封面面板须能一键选回该网页图。
- 新建净读网页书若抽不到图，须写入配色封面，不得长期空白灰块。
- 主页遮罩仅为渐变半透明，不得引入额外真实模糊层。
- 默认快捷本地图标：操作者交图前保持现状（百度本地、其余远程）；交图后按 id 映射替换。

## 7. 重要状态与边界

| 情况 | 用户应该看到什么 |
| --- | --- |
| 无网页图 | 配色封面 |
| 选配色后 | 列表与详情同色 |
| 非主页 Tab | 底栏不强制加本 Spec 的顶区渐变（底栏遮罩仅在浏览器主页上下文增强） |
| 图标未交 | 澎湃等仍可能糊/缺（已知，等素材） |
