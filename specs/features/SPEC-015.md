## 2. 开工前需求确认

- 小说顶栏改为漫画顶栏样式；**仅浏览器临时书**（非整站全局）。
- 设置提供三档阅读触发：**手动**（默认）/ **自动识别并打开** / **站点自动**（常见小说漫画路径启发式）；无痕模式不自动打开。
- 章节内续载：懒加载滚动 + 跟随「下一页」合并进**同一章**，请求上限约 50。
- 目录：`bookUrl` 按系列/目录页稳定；解析邻章/目录链接；支持上一章/下一章与章节列表。
- 任务下达者：2026-10-02「2，三种选项都需要…默认为手动。其他确认」。

### 红色问题判定

- 否（浏览器抽取增强；不恢复书源主路径）。

## 3. 本次范围

1. 浏览器进的小说阅读器顶栏视觉对齐漫画（透明悬浮、标题胶囊、合并操作）。
2. `BrowserConfig` 阅读模式触发三选一 + 自动识别/站点自动接线。
3. 打开阅读前扩展同一章内容（懒加载 + 分页合并，上限 50）。
4. TOC 发现与多章写入；上一章/下一章可切换并按需抽取。

明确不做：全局改所有小说顶栏默认；无痕自动打开；保证全网站点目录 100%；书源规则引擎。

## 4. 验收标准

- [ ] AC-01：浏览器临时小说书打开阅读器后，顶栏观感接近漫画（胶囊标题、悬浮、无整条实心底）。
- [ ] AC-02：设置可见三档触发，默认「手动」；手动时不自动进阅读。
- [ ] AC-03：选「自动识别」时，打开明显小说/漫画页会自动进对应阅读器；无痕不自动。
- [ ] AC-04：选「站点自动」时，URL 命中常见章节路径启发式可自动进；未命中不强制。
- [ ] AC-05：分页章节进阅读后，本章图片/正文明显多于仅首屏 DOM（相对修前）；有上限不卡死。
- [ ] AC-06：能发现邻章时，章节列表多于 1，上一章/下一章可切换并加载内容。
- [ ] AC-07：更新 UI 设计文档 §3.3；assembleAppDebug 成功并给出 APK 路径。
