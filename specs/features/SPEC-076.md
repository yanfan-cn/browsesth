## 2. 确认

- 2026-10-08：确认「液态玻璃模式下点标签闪退」；修法为开标签前临时关底下玻璃，保留 scale+fade
- 红色：否

## 3. 范围

1. 开标签前：`pause`+隐藏 AwContents（沿用 075）+ **临时将浏览器 chrome 液态玻璃降级为填充 fallback**（不改用户全局设置）。
2. 标签层仍用 SPEC-028/075：scale+fade（0.88/420ms），Home Exit/Enter None。
3. 退出标签后：resume AwContents，恢复液态玻璃绘制。
4. 手机 Nav 与平板标签 overlay 同策略。

## 8. 验收

- AC-01：液态玻璃 + 有网页时反复开/关标签不闪退，且有缩小/放大过渡。
- AC-02：退出标签后液态玻璃视觉恢复。
- AC-03：填充模式行为与观感不回归。
