# SPEC-097：NTP 主底栏修复 + 工具箱按键液态玻璃

| Spec ID | SPEC-097 |
| 状态 | Done |
| 基线 | SPEC-096 / 13.3 之后 |
| 依据 | 操作者确认：回主页底栏消失；工具箱去标题 + 按键 24dp 圆角填充/液态玻璃 |

## 用户问题

1. 打开网页后再回浏览器主页（NTP），手机主导航底栏消失，无法切到阅读列表等。
2. 工具箱菜单仍显示「工具箱」标题；按键无统一圆角填充/液态玻璃背景，与全局表面样式不一致。

## 范围

### 做

- 修正「会话活跃」判定：NTP（含 `showHome`）时不得隐藏主底栏。
- 工具箱非编辑态取消「工具箱」字样（手机 Sheet + 平板侧栏）。
- 置顶四项与下方网格每一按键：圆角矩形背景，圆角 24dp；液态玻璃开则玻璃，否则填充。
- 编辑态标题「调整顺序」保留。

### 不做

- 不改工具箱功能项集合、置顶不可排序、半屏高度等 SPEC-070 行为。
- 不恢复标签页底部玻璃 ClearAll 或其它已知危险玻璃路径。

## 产品规则

1. 主底栏仅在浏览器 Home 且**正在显示网页会话**时隐藏；显示 NTP 时主底栏可见。
2. 工具箱非编辑态无「工具箱」标题。
3. 每个工具箱按键背景随全局 `chromeSurfaceStyle`：液态玻璃或填充；圆角 24dp。
