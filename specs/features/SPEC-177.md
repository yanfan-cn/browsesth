# SPEC-177：手机全屏搜索页底栏、搜索记录与横屏宽度

状态：Ready
日期：2026-10-26
关联：SPEC-175（手机主页全屏搜索）

## 开工确认

- 复述：进入手机主页全屏搜索页后隐藏主界面底栏（横屏同样）；未输入时默认只显示最近 5 条搜索记录，可在浏览器设置里开关是否显示；横屏时搜索框与下方列表宽度为屏幕宽的 75%。平板与页内地址栏不动。
- 任务下达者确认：2026-10-26「确认」。
- 红色问题：否。

## 范围

要实现：

- 手机全屏搜索打开期间隐藏主界面底栏；退出后恢复。
- 未输入：剪贴板链接（若有）之后是最近 5 条搜索记录；不再铺浏览历史与收藏。浏览器设置可关闭「显示搜索记录」（默认开）。无痕不展示、不写入搜索记录。
- 已输入：仍按 SPEC-175（引擎联想 + 本机收藏/历史匹配）。
- 手机横屏：搜索框与下方选项宽度为屏幕宽度的 75%。

明确不做：

- 不改平板主页与页内地址栏。
- 不改内核。

## 验收

- [ ] AC-01：全屏搜索打开时主界面底栏不可见（竖屏/横屏）；退出后恢复。
- [ ] AC-02：未输入时最多 5 条搜索记录；关闭设置后不显示；无痕不显示。
- [ ] AC-03：横屏时搜索框与下方列表宽度为屏宽 75%。
