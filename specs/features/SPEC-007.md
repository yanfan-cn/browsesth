## 3. 为什么做

现主页是 example.com 网页壳，与目标 Chrome 风格 NTP 差距大。用户需要可搜索、快捷书签、书架入口与无痕，并统一浅/深视觉。

## 4. 本次范围

要实现：

1. 空主页 NTP：Logo(Browsesth)、搜索框+引擎选择（百度/必应/谷歌/搜狗/抖音/360）、AI 占位、无痕（隔离）、快捷书签（长按编辑+自动图标）、书架横滑封面。
2. 浅色对齐参考图1、深色对齐参考图2；跟随 App 主题，设置中可覆盖「跟随/浅/深」。
3. 打开 URL 后进入现有 `BrowserSessionScreen`；返回可回 NTP。
4. 底栏保留；默认悬浮；Android 15+（API 35）启用液态玻璃。
5. 不做探索发现卡；AI 无真实功能。

明确不做：探索流、AI 能力、浏览中页全面 Chrome 化、Compose 全迁。
