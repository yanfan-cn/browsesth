# SPEC-166：桌面快捷图标与视频播放器

状态：Ready（2026-10-25 复述后回复「确认」）
日期：2026-10-25
关联：SPEC-164/165（桌面 Shortcut）、SPEC-132/136/145/147（播放器与净视胶囊）

## 需求摘要

1. 长按巡页图标：收藏/书签、新建标签页、扫一扫、阅读列表。图标与 App 内同一功能相同，圆角 24dp 底；浅色 `#F6F1EA`，深色 `#121212`，跟随系统浅色/深色。
2. 倍速去掉画面上的「1.3 倍」（实际 1.25）和 2.5 倍。剩下 0.5、0.75、1、1.5、2、3。长按临时档仍是 1.5、2、3。
3. 播放中离开巡页再回来：画面跟着当前进度出现；「重新播放」也能出画面。
4. 右上角菜单增加「加入收藏」（收藏视频所在网页）。五项都带图标：加入收藏、投屏、下载、分辨率、重新播放。
5. 长按倍速条圆角 24dp；当前倍速用浅色/深色填充底。左右滑换档的距离缩短为一半。
6. 播放器里点下载后，右上角显示进度；点它打开下载页。
7. 澎湃新闻按普通视频地址显示净视胶囊。YouTube 能拿到可直接播放的地址时同样显示并可用巡页播放；只有网页锁住的流时不假装能播。网页自带播放器仍可播放、暂停、全屏。

## 验收

- AC-1 四项长按入口可打开对应页面；图标为同功能符号，底色随系统浅/深变化。
- AC-2 倍速列表无 1.25 与 2.5；长按档仍为 1.5 / 2 / 3，滑动约一半距离即可换档；倍速条圆角 24dp，当前档有填充底。
- AC-3 离开再回来后画面继续，进度不丢；重新播放有画面。
- AC-4 菜单五项带图标；加入收藏后该网页出现在收藏/书签。
- AC-5 下载后右上角有进度，点按进入下载页。
- AC-6 澎湃的普通视频地址、YouTube 的可直接播放地址能让净视胶囊出现；识别过程不拦截网页请求。
- AC-7 不用巡页播放器时，网页播放器可播放、暂停、全屏。内核内部无法修复的部分记入 Log，不改内核。
