# SPEC-169：手机竖屏浏览恢复顶栏+底栏

状态：Done（代码已落地；真机未验；未构建）
日期：2026-10-26
关联：SPEC-168（单顶栏）、SPEC-163（长按历史/回顶）、SPEC-011/130（手机浏览栏）

## 开工确认

- 复述：手机竖屏浏览网页时恢复 1.7.0 顶栏（主页、搜索框、刷新）+ 底栏（后退、前进、工具箱、标签数、净读约 48dp），网页为底栏留高；横屏保持 SPEC-168 单顶栏；手机主页、点选屏蔽底栏、提示/下载条/净视胶囊、平板 SPEC-168 不动；不构建 App。
- 任务下达者确认：2026-10-26「确认」
- 确认后变化：无
- 红色问题：否。只改本机手机竖屏浏览栏排列。

## 为什么做

SPEC-168 把手机浏览上下栏合成一条顶栏后，竖屏上搜索框偏窄、操作习惯与 1.7.0 不一致。需要在竖屏改回熟悉的顶栏+底栏，横屏仍用单顶栏。

## 范围

要实现：

- 手机竖屏、正在浏览网页：顶栏为主页、搜索框、刷新；底栏为后退、前进、工具箱、标签数、净读（约 48dp 圆钮）。网页底部为底栏留高（自动隐藏顶栏开启时仍可叠在网页上，与 1.7.0 一致）。
- 手机横屏浏览：保持 SPEC-168 单顶栏（主页→净读），无底部功能条。
- SPEC-163：竖屏时后退/前进长按历史在底栏；刷新长按回顶在顶栏。横屏仍在顶栏对应键上。
- 手机主页布局不变。点选屏蔽仍用底部操作条。提示、下载条、净视胶囊仍贴底。
- 平板 SPEC-168 改动不动。

明确不做：

- 不构建、不安装。
- 不改平板顶栏/主页/设置。
- 不改内核。

## 验收

- [ ] AC-01：手机竖屏打开网页，可见顶栏（主页/搜索/刷新）与底栏（后退/前进/工具箱/标签/净读）；无「整条顶栏塞满」的 SPEC-168 竖屏布局。
- [ ] AC-02：手机横屏打开网页，仍只有单顶栏，无底部功能条。
- [ ] AC-03：竖屏长按后退/前进有历史列表（或空栈 Toast）；长按刷新回顶且不重载。
- [ ] AC-04：手机主页布局与平板 SPEC-168 行为不变；点选屏蔽仍有底部条。
