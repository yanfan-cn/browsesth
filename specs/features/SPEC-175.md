# SPEC-175：手机主页全屏搜索

状态：Ready
日期：2026-10-26
关联：SPEC-058（本机收藏/历史匹配）、SPEC-146（剪贴板链接）

## 开工确认

- 复述：只改手机浏览器主页。点搜索框进入全屏搜索页；未输入时列出最近历史和未出现过的收藏，不联网；输入后先显示当前搜索引擎的联想词，再接本机匹配，文字相同不重复。点联想词即用当前引擎搜索，点历史或收藏打开网页，点右侧箭头只填入文字。无痕不展示本机历史和收藏，但仍会把输入发给搜索引擎。系统返回退出，搜索框从主页位置展开、退出时收回，主页内容淡入淡出。平板主页和正在看网页时的地址栏保持现状。
- 任务下达者确认：2026-10-26「确认」。此前已说明平板保持现状，并要联网联想词。
- 红色问题：否。输入只发给用户当前选中的搜索引擎，不发到巡页的服务器，也不写入本机网络缓存。

## 范围

要实现：

- 手机主页点搜索框进入全屏搜索页，并可用系统返回退出。
- 未输入：最近历史，加上网址还没出现过的收藏；有剪贴板链接时排在第一行。
- 已输入：当前引擎的联想词在前，本机对得上的收藏和历史在后。
- 进入和退出时，搜索框从主页位置移到全屏页顶部再移回，页面淡入淡出。

明确不做：

- 不改平板主页搜索。
- 不改手机或平板正在浏览网页时的地址栏。
- 不把联想词或输入内容发到巡页自己的服务器，也不记入本机网络缓存。
- 主页上的「AI 模式 / 无痕 / 扫码 / 搜索」仍留在主页，不进全屏页。

## 验收

- [ ] AC-01：手机主页点搜索框进入全屏搜索页，键盘弹出；系统返回回到进入前的主页。平板主页仍在原地输入。
- [ ] AC-02：全屏页还没打字时，不请求搜索引擎；列表先是剪贴板链接（若有），再按现有顺序的历史，然后是网址未出现过的收藏。无痕时只有剪贴板链接，没有历史和收藏。
- [ ] AC-03：打字后，联想词在前，本机收藏优先于历史；与联想词文字相同的本机条目不重复。无痕只有联想词。某个引擎没有返回词时，仍显示本机匹配，页面不报错。
- [ ] AC-04：点联想词用当前引擎搜索这几个字；点历史或收藏打开该网址；点箭头只把文字填进搜索框。
- [ ] AC-05：百度、必应、谷歌、搜狗、抖音、360 的联想请求发往各自的地址。响应无法识别时得到空列表，不抛给界面。
