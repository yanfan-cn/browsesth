## 3. 为什么做

许多站点（尤其 HLS）在页内控件弱、难后台、无统一手势。嗅探到可播地址后用原生播放器，可提供全屏、画中画、倍速、字幕、清晰度、后台播与手势，并与页内播放并存（用户主动进入）。

## 4. 本次范围

要实现：

1. **流检测**：从浏览器会话收集可播 URL（至少 HLS；能取到的 mp4/其他直链一并支持），附带可用请求头。
2. **提示条**：检测成功且设置开关开启时，底栏上方显示「用播放器打开」；点击进入原生播放页。
3. **设置开关**：浏览器设置中提供「检测到视频时提示用播放器打开」；关闭后不显示提示条（仍可通过后续若有的其它入口进入则另议；本轮仅提示条入口）。**默认开启**。
4. **播放页能力**：
   - 全屏
   - 系统画中画（PiP）
   - 倍速（控件可选；与手势一致作用于同一播放器）
   - 字幕（有轨可选；无轨诚实降级）
   - 清晰度（多码率/多清晰度可选；单路诚实降级）
   - 后台播放（离开播放页/切 App 可继续；媒体通知可暂停/停止）
5. **手势**（播放画面区域）：
   - **右侧**上下滑动 → 调节系统媒体音量
   - **左侧**上下滑动 → 调节屏幕亮度（仅本播放页窗口亮度）
   - **长按** → 立即 **2.0×** 播放；长按未松手时 **左右滑动** 切换其它倍速；松手后恢复长按前的倍速
   - 倍速变化时视频与音频必须同步正常播放（不得只有画面加速或严重不同步）

明确不做：

- 视频下载、投屏、站点专用破解
- 保证所有加密/鉴权站可嗅探（失败保留页内播 + 不误导提示）
- 重做信息架构为「视频 App」

## 5. 用户如何使用

1. 浏览含可嗅探流的网页；设置中「检测到视频时提示…」为开。
2. 出现底栏上方「用播放器打开」→ 点按进入播放页并开始播放。
3. 使用控件或手势调节音量/亮度/临时倍速；可切字幕/清晰度/倍速；可全屏、进 PiP、切后台继续听看。
4. 从通知停止或关闭播放页结束后台会话。

## 6. 产品规则

- 当检测到新的可播流且开关为开、当前会话前台时，系统必须展示提示条（同一 URL 去重，避免刷屏）。
- 当开关为关时，系统不得自动展示该提示条。
- 当用户点「用播放器打开」时，系统必须打开播放页并用该流地址（及必要头）开始播放。
- 当字幕/清晰度轨不存在时，系统必须禁用或标明不可用，不得崩溃或空选导致黑屏。
- 当用户长按画面时，系统必须立即以 2.0× 播放；左右滑调整倍速档位；松手恢复长按前倍速。
- 当用户在左/右半屏竖滑时，系统必须分别调节亮度/音量，并给出可观察反馈（如临时指示）。
- 当进入后台播时，系统必须显示媒体通知；用户停止后不得继续占音频焦点。
- 系统不得在未获用户点击提示条时强制打断页内播放并跳转播放页。

倍速档位（手势与控件共用建议集）：`0.5 / 0.75 / 1.0 / 1.25 / 1.5 / 2.0 / 2.5 / 3.0`（长按默认落到 2.0，左右滑在相邻档间移动）。

## 7. 重要状态与边界

| 情况 | 用户应该看到什么 | 数据或状态如何处理 |
| --- | --- | --- |
| 检测成功+开关开 | 提示条 | 记住最近流 URL/头 |
| 开关关 | 无提示条 | 可不缓存或静默更新最近流 |
| 播放失败 | 错误说明，可返回网页 | 释放播放器 |
| 无字幕/单清晰度 | 入口禁用或「无」 | 不选无效轨 |
| PiP / 后台 | 小窗或通知续播 | MediaSession 活跃 |
| 长按倍速 | 指示当前倍速 | 松手恢复原速 |
