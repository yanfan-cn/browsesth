## 3. 为什么做

SPEC-015 的 WebView 启发式无法稳定提供完整目录与同章剩余页。Cimoc 用站点 Parser 能做到；用户已从浏览器进入站点，需要的是 Parser 机制而非图源商店。同时未适配站与小说仍需通用启发式兜底。

## 4. 本次范围

要实现：

1. **漫画站点适配层**：移植/改写 Cimoc 集合 A 全部网页 Parser，按 URL/host 匹配；提供详情目录、章节图片列表、Lazy 解析。
2. **浏览器进漫画阅读**：命中适配器时走 TOC + 页槽 + Lazy，写入临时漫画书并打开 Legado 漫画阅读器。
3. **未命中漫画站**：降级现有抽图/续载启发式（可做有限通用增强，不写死新站规则）。
4. **小说通用启发式 1**：推断目录页、同章「下一页」合并、邻章链、常见正文容器加强（不写死小说站点 Parser）。
5. **可选**：从可配置镜像拉取 `sourceBaseUrl.json`，仅更新已知源的 `baseUrl`（不做 B 富规则引擎）。
6. 更新 `docs/产品与开发决策基线.md` 记录本红色批准与「浏览器触发适配器」定位。

明确不做：

- 图源搜索 / 源列表主入口；整包 Cimoc Fresco 阅读器。
- **B** JSON CSS/规则全量引擎（二期）。
- 小说站点硬编码 Parser / 书源主路径。
- 保证全网任意站 100% 目录与续载。
- 修改 `specs/CONSTITUTION.md` 原文（基线记录批准例外即可）。

## 5. 用户如何使用

1. 用户在内置浏览器打开漫画站章节或详情页，触发进入漫画阅读（手动或已有自动策略）。
2. 系统用当前 URL 匹配适配器：命中则请求详情/目录与本章图片页槽；展示加载中。
3. 进入漫画阅读器：可见完整（或接近完整）章节目录；本章可翻完所有页（Lazy 在阅读中补真实图 URL）。
4. 未命中适配器或适配失败：降级启发式抽图；失败可回退网页。
5. 小说页进入阅读视图：在无站点 Parser 下，目录/同章续载相对 SPEC-015 有可观察加强（见 AC）。

## 6. 产品规则

- 当当前 URL 匹配集合 A 某 Parser 的站点过滤规则时，系统必须优先走适配器 TOC + 图片链路，不得仅用首屏 DOM 当作完整章节。
- 当适配器成功解析出 ≥2 章目录时，临时书章节列表必须反映该目录，且上一章/下一章可切换并加载。
- 当 `parseImages` 产出 Lazy 页槽时，阅读过程中滚到/翻到该页必须触发解析并显示图片或明确失败占位，不得静默空白且无反馈。
- 当 URL 未匹配任何 A 适配器时，系统必须降级启发式，不得假装已用 Cimoc 源。
- 系统不得提供「选图源/搜漫画源」作为本 Spec 新增主入口。
- 小说路径不得引入书源规则引擎；仅允许通用启发式。
- `Locality`（本地漫画）不属于网页适配范围，可排除。

### 集合 A 定义（验收边界）

以旁系仓库 `D:\cursor\Cimoc` 中 `SourceManager.getParser` **已注册**且面向网页的 Parser 为准（约 40+，含 IKanman、Dmzj、DM5、CopyMH、Tencent、Manhuatai、Ohmanhua、JMTT、EHentai 等）。实施时在 Plan/Log 附完整类名清单；源失效导致单站失败不否决整包架构 AC，但须在 Log 记录并保留降级。

## 7. 重要状态与边界

| 情况 | 用户应该看到什么 | 数据或状态如何处理 |
| --- | --- | --- |
| 适配命中且成功 | 进漫画阅读器，目录多章或单章完整页槽 | 临时书 + 章内容/页槽缓存 |
| 适配命中但网络/解析失败 | 明确错误或自动降级启发式的提示 | 可回退网页；不写坏书架 |
| 未命中 | 启发式抽图/阅读（与既有行为一致或加强） | 同 SPEC-015 临时书模型 |
| Lazy 单页失败 | 该页失败占位/可重试，其余页可读 | 仅该 ImageUrl 失败态 |
| 小说启发式 | 目录或同章篇幅相对纯首屏有可观察增益（有上限） | 临时小说书 |
