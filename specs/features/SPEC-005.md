## 3. 为什么做

用户反馈滑动已改善，但浏览时屏幕下半出现白色空档，且苹果官网顶栏高度被压缩。需在不回退滑动体验的前提下恢复正常可视区域。

## 4. 本次范围

要实现：

1. 去掉导致底部大块留白的硬编码底边距；网页区域落在顶栏/地址栏与底栏之间的可用高度内。
2. 修正嵌套 Scaffold 的系统 insets，避免与主壳底栏重复预留。
3. 站点顶栏（至少苹果官网）不再明显纵向压扁。
4. 保留 SPEC-004 滑动相关改动（禁 Home Pager 横滑、触摸 disallow intercept、overview 关闭等）。

明确不做：

- 硬件加速绘制路径大改；
- 广告/弹窗/外链逻辑变更；
- 底栏信息架构、阅读视图、漫画；
- Compose 整 App 迁移。

## 5. 用户如何使用

1. 打开 App 进入浏览器首页。
2. 访问苹果官网或其它常见 HTTPS 站。
3. 观察：网页下半无白色空档；站点顶栏高度正常；仍可流畅上下滑动。

## 6. 产品规则

- 浏览器内容区不得在底栏之上再人为垫出大块空白（除非浮动底栏且内容主动延伸到底时由站点自身处理）。
- 嵌在主壳内的浏览器不得重复叠加系统导航栏 insets。
- 不得回退已确认改善的滑动手势处理。
- 主路径仍为 Aloha。
