## 3. 为什么做

用户在网页或巡页播放器看视频时，系统通知栏应能控制播放；离开浏览该页的上下文后不应继续出声或占通知，避免误扰。「听音频」是明确的后台收听入口，予以保留。

## 4. 本次范围

要实现：

1. 网页内视频（或页面媒体）起播 → 立即出现与现有巡页播放器对齐的媒体通知（标题、播/停、±15s；有进度则展示）。
2. 巡页自带播放器起播 → 同样立即出通知（已有则校对「播放即出」、离开不再后台续播）。
3. 离开即停：同标签跳转、切标签/回 NTP、关标签、离开浏览器去其它主 Tab、App 切后台 → 停止网页媒体与巡页视频播放器，并移除通知。
4. 「听音频」例外：离开后仍可后台播放并保留通知。

明确不做：

- 不改嗅探规则、净视胶囊其它键逻辑（除离开停播联动）。
- 不借机重做播放器 UI；不强制关闭用户主动进入的画中画（Home 不再自动进 PiP；切标签等离开事件仍停）。

## 5. 用户如何使用

1. 在网页点播站点自带播放器，或点净视胶囊「播放」进巡页播放器。
2. 起播后下拉通知栏可见媒体通知，可暂停/继续/±15s。
3. 跳转其它网址、切标签、回主页、关标签、滑到「阅读列表/我的」、按 Home：视频停止，通知消失。
4. 仅点「听音频」后离开：可继续听，通知仍在。

## 6. 产品规则

- 网页媒体 `onMediaPlay`（非听音频会话）或巡页播放器开始播放时，必须立即展示媒体通知。
- 离开事件触发时，必须停止网页媒体与巡页**视频**播放，并移除其通知。
- 「听音频」会话在离开事件下不得被强制停止。
- Home/多任务不得再把巡页视频播放器自动送进画中画以续播；用户点胶囊主动 PiP 的路径可保留，但若再发生离开事件（切标签等）仍须停。
- 系统不得在离开后继续播放网页视频或巡页视频（听音频除外）。

## 7. 验收标准

- [ ] AC-01：网页内视频起播后，通知栏立即出现媒体通知（播/停、±15s）。
- [ ] AC-02：巡页自带播放器起播后，通知栏立即出现同等形态通知。
- [ ] AC-03：播放中同标签打开新网址 → 视频停、通知消失。
- [ ] AC-04：播放中切其它标签或回 NTP → 视频停、通知消失。
- [ ] AC-05：播放中关闭当前标签 → 视频停、通知消失。
- [ ] AC-06：播放中切到「阅读列表」或「我的」→ 视频停、通知消失。
- [ ] AC-07：播放中按 Home / 多任务 → 视频停、通知消失（且不再自动进 PiP 续播）。
- [ ] AC-08：「听音频」后执行 AC-03～07 任一离开操作 → 音频仍播、通知仍在，可从通知停止。
