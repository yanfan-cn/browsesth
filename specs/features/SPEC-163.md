# SPEC-163：网页会话后退/前进长按历史 · 刷新长按回顶

状态：已确认（2026-10-25 操作者确认）
日期：2026-10-25
关联：底栏/功能栏 chrome；AwContents `getNavigationHistory` / `goBackOrForward`

## 背景

浏览多页后只能逐步后退/前进；刷新无回顶捷径。需对齐常见浏览器「长按历史列表」与「长按刷新回顶」。

## 需求

- **R1**：长按后退 → 当前标签可后退网页列表（标题优先，否则主机名/URL）；点选跳转；无条目 Toast「没有可后退的页面」。短按仍单步后退。
- **R2**：长按前进 → 对称可前进列表；空则 Toast「没有可前进的页面」。短按仍单步前进。
- **R3**：长按刷新 → `scrollTo(0,0)` 回顶且不刷新；短按仍刷新。
- **R4**：手机底栏后退/前进 + 顶栏刷新；平板功能栏三键同等。数据来自内核导航栈，非全局历史页。

## 边界

- 不改系统返回键长按、NTP。本期不强制组装 APK。

## 验收

- AC-1 有后退栈时长按后退出现可点列表，点选到达对应页。
- AC-2 有前进栈时长按前进同理。
- AC-3 无栈时长按仅 Toast，不弹空菜单。
- AC-4 长按刷新回顶且页面未重载；短按仍刷新。
- AC-5 平板功能栏行为与手机一致。
