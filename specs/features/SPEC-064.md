## 4. 范围

1. 工具箱拆为「保存网页」「下载」。
2. 保存网页：当前页存为 MHTML（`.mht`）到 `Download/XunYeBrowser/`。
3. 「下载」打开下载文件页；网页触发下载与保存网页均入列表；顶栏下搜索；进行中进度 + 暂停/继续。
4. 首次启动确保 `Download/XunYeBrowser/` 存在。
5. 下载/保存进行中系统通知栏常驻进度；完成/失败后移除常驻进度通知。

明确不做：整站爬取；不改广告/阅读抽取。

## 8. 验收

- AC-01：工具箱可见「保存网页」「下载」两项（手机+平板）。
- AC-02：保存网页成功后，`Download/XunYeBrowser/` 出现 `.mht`，列表可见。
- AC-03：点「下载」进入下载文件页；顶栏下有搜索框。
- AC-04：网页触发下载进入同目录与列表，显示进度，可暂停/继续。
- AC-05：进行中通知栏有进度通知；完成后该常驻进度通知消失。
- AC-06：冷启动后 `Download/XunYeBrowser` 目录存在（可创建）。
