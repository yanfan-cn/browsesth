# SPEC-159 设置保持 SlideOverlay 可再进 / 播放器旋转恢复旧行为

状态：已确认（2026-10-21 操作者确认保留 SlideOverlay 并修根因；先前「拿掉 Overlay」方案已否决）
日期：2026-10-21
关联：SPEC-142（设置全量 Overlay）、SPEC-156/157、1.3.8 播放器 `requestedOrientation`

## 背景

1. 设置进子项再回「我的」后无法再进：SlideOverlay 在子页盖住设置时把设置标成退出，子页 pop 后设置仍隐藏，露出「我的」。
2. 播放器旋转：1.5～1.6 画面内旋转放大裁切；1.3.8 整页竖/横切换正常。
3. **产品要求**：设置必须继续走 SlideOverlay（与 1.5 / SPEC-142 一致），不得改回普通 AnimatedContent 滑页。

## 需求

- **R1**：设置根与设置子页保持 `browserSlideOverlayMetadata`（SlideOverlay + 跟手返回）。子页盖住设置时不得把设置标成隐藏；子页返回后设置仍可见；回「我的」后再进设置也可见。
- **R2**：播放器「旋转」恢复 1.3.8：整页竖屏/横屏切换，比例正常。

## 边界

- 不改外链。不实施 SPEC-154。历史/书签等其它 Overlay 页面保持现状。

## 验收

- AC-1 「我的」→设置→任意子项→返回设置列表可见→回「我的」→再进设置可见；手势跟手仍在。
- AC-2 播放器点旋转：整页横竖切换，不拉扁裁切。
- AC-3 debug 组装并装机。
