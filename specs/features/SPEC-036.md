## 3. 为什么做

平板主页点搜索会清空输入却打不开网页。主页左右滑容易误进书架。竖屏侧栏过窄。进入阅读后顶栏消失，无法继续用标签和搜索。平板阅读区已有浏览器顶栏，默认页眉会占空间。

## 4. 本次范围

要实现：

- 平板浏览器主页顶栏输入后点键盘搜索/前往：按输入打开搜索或网址，不只清空框。
- 平板处于浏览器主页（含未打开网页）时，左右滑不能切到书架等主分页；书架仍用顶栏书架按钮。
- 平板竖屏：收藏、历史、工具箱右侧侧栏宽度为屏宽 1/2；横屏保持约 1/3。标签页仍整页。
- 从平板浏览器点「阅读模式」进入小说或漫画阅读时，横竖屏都保留浏览器顶栏（标签条 + 功能条）。
- 平板阅读时，页眉默认档视为隐藏；用户在排版里选「显示」仍显示。手机新排版默认仍为「状态栏显示时隐藏」。

明确不做：

- 不打 APK、不改手机主页左右滑、不改从书架打开书籍的全屏阅读、不改标签页为半屏、不改图标。

## 5. 用户如何使用

1. 平板浏览器主页顶栏输入文字，点键盘搜索：打开对应搜索或网址。
2. 在平板浏览器主页左右滑：页面不切到书架；点书架图标仍进入书架。
3. 竖屏点收藏/历史/工具箱：右侧半屏侧栏；横屏仍为约三分之一。
4. 打开网页后点阅读模式：正文出现在浏览器顶栏下方，顶栏仍在。
5. 返回阅读：关掉阅读叠层，回到原网页，顶栏仍在。
6. 平板阅读正文默认无页眉；手机阅读页眉默认与原来相同。

## 6. 产品规则

- 当平板顶栏提交非空输入时，系统必须用提交瞬间的文字导航，不得因失焦把文字还原成空主页后再提交。
- 当设备为平板且当前主分页是浏览器主页时，系统必须禁用主 Pager 的用户滑动；网页会话期间手机仍禁用滑动（既有规则）。
- 当平板竖屏打开收藏/历史/工具箱时，侧栏宽度必须为屏幕宽度的二分之一；横屏必须约为三分之一。
- 当从平板浏览器进入阅读模式时，系统必须继续显示浏览器顶栏；不得把阅读做成盖住顶栏的独立全屏页。
- 当从书架打开书时，系统必须仍使用现有全屏阅读（无浏览器顶栏）。
- 当平板且页眉模式为默认档（0）时，正文页眉必须隐藏；手机默认档行为不变。
- 系统不得改变手机新排版的页眉默认值。

## 7. 重要状态与边界

| 情况 | 用户应该看到什么 | 数据或状态如何处理 |
| --- | --- | --- |
| 主页搜索成功 | 进入网页会话并加载 | 写入当前标签 URL / 搜索文案 |
| 主页搜索空串 | 不导航 | 不改标签 |
| 阅读中再搜地址 | 关掉阅读叠层并加载新网址 | 阅读会话结束，网页会话继续 |
| 抽取失败 | 提示，仍停在网页 | 不打开阅读叠层 |
| 横竖屏旋转 | 侧栏宽度按方向切换；阅读仍留顶栏 | 阅读叠层保持 |
