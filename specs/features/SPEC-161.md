## 2. 开工前需求确认

- Agent 最终复述：启用无痕后界面外观与非无痕一致；无痕能力保留；按钮保留高亮。
- 任务下达者确认：2026-10-21「确认，按钮保留高亮」。

### 红色问题判定

- 否：仅壳层外观，不改变无痕隐私语义。

## 3. 为什么做

无痕强制深色皮肤、隐藏壁纸，与日常主题割裂。

## 4. 本次范围

要实现：

1. 无痕开启时，浏览器主页颜色、壁纸、文字与控件底色跟随当前主题（与非无痕相同）。
2. 无痕开关按钮在开启时仍高亮（主色底 + 浅色图标/字），关闭时与其它快捷操作一致。

明确不做：

- 不改无痕数据行为（退出清数据、不写历史、资讯不展示等）。
- 不改标签页「常规/无痕」分段切换 UI（非主页换肤问题）。

## 5. 验收标准

- [ ] AC-01：浅色主题下开无痕，主页仍为浅色，壁纸仍显示（若已开启）。
- [ ] AC-02：深色主题下开无痕，主页仍为深色，无额外无痕专属深色皮肤。
- [ ] AC-03：无痕开启时按钮仍高亮可辨；点退出后高亮消失且外观仍跟主题。
- [ ] AC-04：退出无痕仍清数据；资讯在无痕下仍不展示。
