## 3. 为什么做

主页定制菜单文案冗余、关闭生硬；预置壁纸按手机竖屏出图，平板横屏观感差；需要两张科技/赛博风格与三张更有意境的风景命名壁纸，并以更高清晰度覆盖手机与平板。

## 4. 本次范围

要实现：

- 主页左上角菜单去掉「背景」字样（保留缩略图横滑与当前壁纸名）。
- `AnimatedMenuPopup` 增加关闭过渡（约 90ms 淡出 + 缩至约 0.95，对齐 Material Motion）；进入仍约 150ms。
- 图片类内置壁纸改为正方形资源，边长满足手机 Crop 后约 1080P（采用 **1920×1920**：竖屏 Crop 可视约 1080×1920）；`ContentScale.Crop` 不变。三张渐变仍代码绘制，天然适配任意比例。
- 「浅蓝 / 浅绿 / 浅粉」**仅改显示名为** **蓝天 / 绿茵 / 落樱**；仍为下白上色竖向渐变；prefs id 仍为 `grad_*`。
- 原晨纸 / 薄雾 / 窗纱升级为同规格正方形 1080P 级资源。
- 新增 **赛博**、**霓虹** 两张深色科技/赛博朋克壁纸；深色预置上 Logo/快捷书签用浅色字，必要时加淡遮罩保证可读。
- 内置列表共 8 张；默认仍为薄雾（SPEC-223）。
- 打 debug 包。

明确不做：

- 不为蓝天/绿茵/落樱生成风景图；不按横竖屏拆两套 drawable；不改每日壁纸、相册导入、无痕逻辑；不改默认壁纸；不 commit/push。

## 5. 用户如何使用

1. 打开浏览器主页 → 点左上角菜单：无「背景」标题；点空白关闭时有淡出缩放。
2. 横滑切换蓝天/绿茵/落樱/晨纸/薄雾/窗纱/赛博/霓虹；选中立即铺满主页。
3. 手机竖屏与平板横/竖屏均铺满不变形；重要画面在中心安全区。

## 6. 产品规则

- 关闭菜单必须先播退出动画再卸 Popup（不可瞬时消失）。
- 浅色预置（蓝天/绿茵/落樱/晨纸/薄雾/窗纱）：浅色主题下深色 Logo 与深色书签名；深色主题仍加现有淡遮罩。
- 深色预置（赛博/霓虹）：浅色主题下亦用浅色 Logo/书签名（可加淡暗遮罩）。
- 旧偏好 `grad_blue` / `grad_green` / `grad_pink` 仍有效，分别对应蓝天/绿茵/落樱。
