## 2. 范围

要实现：

1. **返回互斥（修 086）**：有效预见性开 → 仅预见性返回动画；关或 API<35 → 仅向右滑出 Pop。消除默认层 scale/fade 叠用导致的掉帧与不跟手。
2. **标签页进出**：在不回归液态玻璃闪退前提下，恢复可感知过渡（优先仅位移、无 fade/scale）。
3. **NTP 悬浮顶/底栏**：顶栏与主页底栏不额外占大量布局高度；内容区收回原 `+70dp` 等大块占位，仅保留避让顶栏控件与底栏可滚到底的必要 inset。
4. **资讯卡片**：源选择入口迁至卡片内右上角；同区加手动刷新；主页自定义菜单保留总开关「资讯信息流」，去掉三源勾选。
5. **资讯图文 + 速度**：条目展示缩略图（有则显示）；内存/短 TTL 缓存；回主页不自动全量重拉。
6. **回页记忆**：打开资讯文章再返回，恢复离开前主页滚动位置；不自动刷新信息流。
7. **标签长按菜单**：弹出位置贴顶栏下方（对齐主页自定义菜单 offset）。

明确不做：

- 不恢复标签底部玻璃「关全部」；不新加资讯平台；不改书源主路径。

## 3. 产品规则

- 有效预见性 = 用户开关 && SDK ≥ 35。
- 有效预见性开：不注册/不使用向右滑出 Pop；仅 PredictivePop（位移，无 scale/fade 叠层）。
- 有效预见性关：仅 Pop 向右滑出；不注册 PredictivePop。
- NavDisplay 全局默认 pop/predictivePop 必须遵守同一互斥，且不得再叠 scaleOut+fade。
- 标签页过渡不得对下层液态玻璃 Home 施加 graphicsLayer（禁止 fade/scale）。
- 资讯：仅手动刷新或源开关变更时重新拉取；缓存命中则即时展示。
- 无图条目仍可点开标题；布局为左文右图或等价图文行。
