- 红色：否。缩略图为本机内存快照，不做 AwContents 液态玻璃采样。

## 4. 范围

- 主页与浏览底栏标签入口：圆角矩形 + 当前数量（含 0、含大于 9 的真实数字）。
- 长按：新建标签页、关闭所有标签页；仅底栏再加添加书签。
- 标签页网格：网页快照；左右滑关闭；底部悬浮「全部关闭」圆角 24dp、距底 16dp。
- 关闭全部 / 关掉最后一个 → 0 个标签，回空主页。
- 进出标签页去掉 420ms 缩放，改为短过渡。

明确不做：平板侧栏重做、标签组、工具箱其它项。

## 8. 验收

- AC-01：主页/底栏见带数字的圆角矩形；10 个标签显示 10。
- AC-02：长按主页仅新建/关全部；底栏另有添加书签（当前页）。
- AC-03：有快照的网页卡显示画面；主页或未拍到为占位。左右滑关闭。
- AC-04：全部关闭后数量为 0，无残留标签。
- AC-05：进出标签页不再使用 420ms 缩放。
