## 2. 开工前需求确认

- 复述四项已确认（2026-11-06）。
- A：仅改**手机浏览** UA；净视/播放端仍可桌面 UA。
- B：平板腾讯浏览 UA 仍桌面。
- C：全屏手机+平板都加；**不跨标签记忆**、不持久化（切标签即退出全屏态）。
- D：全屏优先锁隐浏览栏；退出后再跟「滚动时隐藏浏览栏」。
- 红色问题：否。

## 3. 为什么做

1. 手机打开腾讯新闻却是桌面版布局（导航时 `needsDesktopForVideo` 抬桌面 UA）。
2. 主页资讯流点进文章后，底栏后退在无 WebView 历史时不回 NTP。
3. 「滚动时隐藏浏览栏」上滑回栏卡顿。
4. 需要一键全屏浏览（藏栏）并有明确恢复入口。

## 4. 本次范围

1. 手机默认 Mobile 时，浏览导航**不再**因腾讯系 host 抬桌面 UA；`needsDesktopForVideo` 仅服务播放端。
2. 底栏/组合顶栏「后退」与系统返回一致：`canGoBack` → `goBack`，否则 `onNavigateBack`（回 NTP）；自 NTP 首跳在首帧完成后 `clearHistory`，避免跳转链挡回主页。
3. 滚动藏栏：浏览栏用位移/透明度动画替代会反复进出组合的 AnimatedVisibility（或等价减 jank）；上滑回栏更跟手。
4. 工具箱新增「全屏」（`OpenInFull`）：藏顶+底浏览栏；右下恢复键（`CloseFullscreen`、半透明；距底 54dp、距右 16dp）。状态按当前会话、切标签复位。

明确不做：不改用户手动 UA 开关语义；不承诺腾讯页内播放器在手机 UA 下一定可播（净视路径保留桌面 UA）；不做全屏持久化/跨标签记忆。
