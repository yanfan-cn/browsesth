# SPEC-208：平板净读多标签记忆 + 全屏顶栏 + 横屏双页快捷

| Spec ID | SPEC-208 |
| 状态 | Implemented（2.0.6-beta 待装机） |
| 基线 | SPEC-036/060/095/122/155；操作者确认 2026-10-30 |
| 依据 | 平板壳内净读：顶栏标签不可切；缺全屏藏浏览器顶栏；设置缺双页快捷与方向联动默认 |

## 做

1. **每标签记住净读（仅平板壳内）**  
   每个浏览器标签独立记住是否处于净读、净读类型（小说/漫画）与 bookUrl。顶栏切换标签时展示该标签自己的网页或净读叠层，可在多标签间自由切换；关闭标签清除其净读记忆。进程重启不要求恢复净读叠层。

2. **净读顶栏「全屏」键（仅平板壳内净读）**  
   - 图标 Material Symbol **Open In Full**（退出全屏可用 Close Fullscreen）。  
   - 样式与右上角「更多设置」键一致：液态玻璃 = 独立圆形按键；填充模式 = 单图标、无背景填充。  
   - 点击切换：隐藏/显示浏览器顶栏（标签条 + 功能栏）。全屏时正文顶避让走状态栏 insets（不再按「顶栏下 16dp」）。

3. **更多设置开关**  
   右上角「更多设置」→「屏幕超时」下方新增「全屏显示（隐藏浏览器顶栏）」开关，与顶栏全屏键同一偏好；仅平板壳内净读生效，手机独立净读忽略。

4. **设置：翻页动画正右侧「平板/横屏双页」方卡**  
   主题页翻页行动画项正右侧新增方卡（样式/尺寸同动画速度、边距），图标 **View Headline**；点开四档：全局单页 / 全局双页 / 横屏双页 / 平板·横屏双页。

5. **默认与方向联动**  
   - 默认双页档 =「平板/横屏双页」（含已装用户一次迁移）。  
   - 当双页档为「横屏双页」或「平板/横屏双页」时：竖屏自动翻页动画=滚动（单页）；横屏自动=滑动（双页可生效）。档位改回全局单/双页后不再自动改动画。

## 不做

- 手机独立净读 Activity 的浏览器顶栏全屏；不改漫画阅读器自身双页体系。  
- 不把净读叠层写入标签持久化（冷启动不恢复净读）。  
- 不改「共用布局」语义。

## 验收

- [ ] AC-01：标签 A 进净读 → 切到 B（网页）→ 再切回 A 仍为该页净读。  
- [ ] AC-02：净读中点其他标签可立刻看到目标标签内容（网页或该标签净读）。  
- [ ] AC-03：平板净读顶栏全屏键可藏/显浏览器顶栏；液态玻璃圆形、填充模式无底。  
- [ ] AC-04：更多设置「全屏显示」与顶栏键同步；手机净读无此行为要求。  
- [ ] AC-05：翻页动画右侧有 View Headline 方卡，可选四档双页。  
- [ ] AC-06：默认平板/横屏双页；竖屏滚动单页、横屏滑动双页（该两档下随旋转自动切动画）。  
- [ ] AC-07：assemble debug 出包。
