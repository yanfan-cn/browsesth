# SPEC-207：网页地址栏获焦默认全选（修点击盖选区）

| Spec ID | SPEC-207 |
| 状态 | Implemented（2.0.4-beta 待装机） |
| 基线 | SPEC-146 R1 |
| 依据 | 操作者（2026-10-30）：网页内点地址栏文字未全选 → 改为默认全选；完成后构建 |

## 做

1. 手机网页会话 omnibox、平板功能栏 omnibox：从无焦点到获焦时，显示可编辑网址并**全选**。
2. 修复点击落点覆盖 `TextRange` 的竞态：获焦后下一帧（或必要的两帧）再应用全选。
3. 已聚焦时再次点击中间不强制重全选（仅获焦边沿）。

## 不做

- 不改 NTP 搜索框常态；不改剪贴板候选（SPEC-146 R2）。

## 验收

- AC-01：网页内点地址栏 → 网址全选，可直接输入替换。
- AC-02：手机竖/横、平板功能栏均生效。
- AC-03：assemble debug 出包。
