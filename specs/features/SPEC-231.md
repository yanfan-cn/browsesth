## 范围

1. 删除用户可见文案中的「SPEC-XXX」字样（当前仅「阻止打开其它应用」一处）。
2. `BrowserConfigScreen` 各选项 description 按确认的对照表精简为一句短说明；「User-Agent」标题更名为「浏览器UA标识」（操作者 2026-11-04 补充）。
3. 顺带精简「下载与缓存」页自动清理项说明（SPEC-230 新增文案）。

## 边界

- 只改文案，不改任何行为；代码注释中的 SPEC 引用保留（不显示于 UI）。
- 「自动屏蔽广告」「阻止弹出窗口」「点选屏蔽」等已简短文案不动。

## 验收

- AC-01：浏览器设置页无任何「SPEC-XXX」字样，说明均为一句短文案；真机截图。
- AC-02：编译通过，功能行为无变化（仅字符串改动）。
