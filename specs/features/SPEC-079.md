## 3. 为什么做

078 已对齐 9.1 的 180ms fade，11.1 仍闪。怀疑标签页内悬浮液态玻璃控件（底部 ClearAll TopBarActionButton）与 Nav 淡入同屏采样，加剧 computeTransformImpl 栈溢出。先减标签层玻璃与过渡复杂度。

## 4. 范围

1. **删除**标签页底部居中「全部关闭 / ClearAll」按钮；网格底 padding 收回（不再为底键预留 80dp）。
2. **关全部入口**：保留长按标签计数菜单（SPEC-071）；标签页内不再提供底部/顶栏关全部键。
3. **标签页顶栏**：返回/新建强制 **Tonal（非液态玻璃）**；AppScaffold 对标签页 disableContentSampling=true 且 disableLiquidGlass=true。
4. **导航**：标签路由 Enter/Exit/Pop = None（无 fade/scale）；平板全屏标签同步无过渡。
5. 明确不做：改 NTP/底栏玻璃；改关全部菜单语义；commit/push。

## 6. 产品规则

- 标签页打开期间，页内顶栏按钮不以液态玻璃绘制，且不建立液态玻璃 backdrop。
- 关闭当前分段全部标签：仅通过长按主页/底栏标签计数菜单。

## 8. 验收

- AC-01：液态玻璃 + 有网页时反复开/关标签页不闪退。
- AC-02：标签页底部无清除/全部关闭控件。
- AC-03：标签页进出无可见 fade/scale（瞬时切换）。
- AC-04：长按标签计数仍可「关闭全部」当前分段。
- AC-05：填充模式下开标签不回归闪退。
