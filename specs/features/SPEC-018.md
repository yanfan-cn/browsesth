## 3. 为什么做

平板仍用手机式悬浮底栏与主侧栏，不符合 Chrome 式浏览习惯；启动落在书架偏离浏览器产品定位；NTP 缺每日壁纸氛围。

## 4. 本次范围

要实现：

1. 平板会话壳 Chrome 顶栏布局 + 取消悬浮底栏 + 右 1/3 侧栏（收藏/历史/工具箱）+ 顶栏自动隐藏选项。
2. UA 默认按形态；工具箱切换手机/电脑。
3. 平板 NTP：60% 居中、去右上角三按钮、可选 Bing 每日背景。
4. 冷启动默认浏览器 Home 页；平板 `useRail=false`。
5. 浏览器设置：每日壁纸开关、滚动隐藏顶栏开关。

明确不做：手机 Chrome 顶栏改造；付费/需 Key 壁纸源默认；图源商店。

## 5. 用户如何使用

1. 打开 App → 浏览器 NTP。
2. 平板：顶栏操作导航/搜索/侧栏；无左侧书架导轨、无悬浮底栏。
3. 手机：仍可用悬浮底栏。
4. 设置可开每日 Bing 壁纸与滚动隐藏顶栏。

## 6. 产品规则

- smallestWidthDp≥600 视为平板（与现有 rail auto 口径一致）。
- 平板浏览会话不得显示悬浮底栏。
- 平板主界面不得显示左侧 NavigationRail。
- 冷启动无显式深度链接时，主分页落在 `home`（浏览器）。
- NTP 布局与右上角按钮删除仅平板；手机 NTP 保持原样（可仍有右上角按钮）。
- Bing 壁纸按自然日缓存；失败保留上次或纯色。
