## 3. 为什么做

新用户做完欢迎后看到无用的 example.com 文档页，而不是可搜索的浏览器主页。6.9 安装后第一次能开，退出再开会在启动页停几秒后回到桌面；6.8 无此现象。

## 4. 本次范围

要实现：

1. 保留首次欢迎/隐私流程。
2. 欢迎完成后进入浏览器主页（搜索框与快捷方式），不打开 example.com。
3. 退出后再打开应能进入应用，不得在启动页闪退回桌面。
4. 对照 6.8：启动阶段不再在内核进程刚起来时做 6.9 新增的 Cookie/原生过滤强制关闭；启动日志不再拉起系统 WebView。

明确不做：删除欢迎页；关闭百度 SERP 的 UA/CommandLine 对照（仍保留，但不挡启动）；重做 onboarding 文案。

## 5. 用户如何使用

1. 新安装打开应用 → 欢迎/隐私页（与现在相同）。
2. 完成后 → 浏览器主页，不是文档示例网站。
3. 退出应用后再打开 → 进入浏览器主页（或上次主界面），不闪退。

## 6. 产品规则

- 当用户完成欢迎时，系统必须打开主界面浏览器 Home（NTP），不得导航到 example.com。
- 当用户从桌面图标冷启动且非首次欢迎时，系统必须打开主界面，不得因启动阶段系统 WebView 或内核附加关闭逻辑而闪退。
- 系统不得把 example.com 当作产品首页。
- 书签、历史、用户主动打开的网页不受「去掉示例页」影响。
