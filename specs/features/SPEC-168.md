- 复述：平板主页去掉顶栏下的空带，主页菜单单独浮在左上角。搜索框和净读从 44dp 降到 40dp，整行仍是 54dp。阅读列表（书本图标）挪到「我的」和搜索框之间。各控件间距 8dp。设置页「设置」沉到返回键下方，标题区约 112dp。左侧分类列表在标题下方上下居中。手机浏览网页时顶栏和底栏合成顶上一条：主页、后退、前进、刷新、搜索框、工具箱、标签数、净读；搜索框和净读高 36dp，间距 8dp。手机主页不变。点选屏蔽仍用底部条。

- 确认后变化：手机浏览的搜索框和净读高度由复述中的 40dp 改为 36dp。平板仍是 40dp。
- 红色问题：否。只改本机界面排列。

## 为什么做

平板主页顶栏下面空着一条，只放了一个主页菜单。搜索框和净读偏高。阅读列表离「我的」太远。设置标题和返回键挤在一行，左侧列表贴着顶。手机浏览时上下各有一条栏，控件间距不统一。

## 范围

要实现：

- 平板浏览器主页不再为那条空带留出整行高度。主页菜单浮在页面左上角，点开仍是原来的主页自定义。
- 平板顶栏搜索框和净读高 40dp。顶栏整行仍是 54dp。
- 平板顶栏从左到右：后退、前进、刷新、我的、阅读列表、搜索框、收藏、历史、工具箱、净读。相邻控件间距 8dp。
- 平板设置左栏：「设置」在返回键下方，大标题贴着约 112dp 标题区的下沿。分类列表在标题下面的区域里上下居中。
- 手机打开网页时只有顶上一条栏，顺序：主页、后退、前进、刷新、搜索框、工具箱、标签数、净读。搜索框和净读高 36dp。相邻控件间距 8dp。原来的底部功能条不再出现，网页用回那块高度。
- 手机浏览器主页保持现在的顶栏和内容位置。
- 点选屏蔽时仍使用原来的底部操作条。

明确不做：

- 不构建、不安装。
- 不改手机主页的搜索大卡和图标行。
- 不把平板上的「我的 / 收藏 / 历史 / 阅读列表」加进手机这条栏。
- 不改内核。

## 验收

- [ ] AC-01：平板主页上，顶栏和页面内容之间没有整行空带；主页菜单在左上角，能打开自定义。
- [ ] AC-02：平板顶栏搜索框和净读高 40dp；阅读列表在「我的」和搜索框之间；相邻控件间距 8dp。
- [ ] AC-03：平板设置里「设置」在返回键下方；左侧分类在标题下方上下居中。
- [ ] AC-04：手机浏览网页时只有顶栏，含主页到净读的上述顺序；搜索框和净读高 36dp；间距 8dp；没有底部功能条。主页布局不变。点选屏蔽仍有底部条。
