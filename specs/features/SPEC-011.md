## 3. 为什么做

当前浏览器会话：漫画无法进阅读器、滑动掉帧、进出工具箱子页会刷新网页、顶栏/底栏与 UI 设计不一致、主页阴影与引擎无 logo、加入书架后看不见。一次修复对齐阶段 B 漫画入口与会话壳体验。

## 4. 本次范围

要实现：

1. 蓝钮：自动判断小说/漫画；失败让人选；漫画进完整 Legado 漫画页。
2. 硬件绘制 + 失败自动回退 SOFTWARE；白屏为零。
3. 进出历史/书签/设置不自动刷新网页；仅手动刷新。
4. 取消「更多」；复制链接、点选屏蔽进工具箱；顶栏=返回+地址+刷新。
5. 按 UI 设计优化浏览器页；卡片圆角 24dp（同步改 UI 设计文档）。
6. NTP：去卡片阴影、布局下移 120dp、搜索引擎官方 logo（选择器+下拉）。
7. 确认加入书架后，主页书架横滑与书架页可见。
8. 浏览底栏样式对齐主页悬浮底栏（半透明/圆角/图标）；不对网页做液态玻璃采样。

明确不做：多标签真能力、底栏滚动自动隐藏、设置大重组、隐私/开源页、Banner、整包 Cimoc、书源主路径。

## 5. 用户如何使用

1. 打开网页 → 点蓝钮 → 自动进小说或漫画阅读器；不准时弹出选择。
2. 滑动网页应更跟手；异常时回软件绘制且页面仍可见。
3. 工具箱进历史/书签/设置再返回 → 同一网页、同一滚动位置（不重载）。
4. 工具箱可复制链接、点选屏蔽；顶栏仅刷新。
5. NTP 搜索可选带 logo 的引擎；书架区可见已加书架作品。

## 6. 产品规则

- 漫画必须打开完整 Legado 漫画阅读 UI（非轻量图廊）。
- 抽取失败：Snackbar，留在网页。
- 非手动刷新不得 `loadUrl` 重载当前页。
- 新 UI 无阴影；卡片圆角 24dp。
- 会话底栏可半透明外观，禁止对 Chromium 内容做 haze/layerBackdrop 采样。
- 加入书架须清除 notShelf（或等价），且 NTP/书架查询能看到。
