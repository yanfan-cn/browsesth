## 范围

1. 退出小说/漫画阅读时不再弹出「是否放入书架」，直接退出（未入架临时书仍按现有清理）。
2. 图文混合与漫画：双击图片全屏；全屏左右滑切图、下滑退出、右上角 X 退出；长按转发/保存。
3. 加强网站 UI 文案过滤（扩展 WebArticleChromeFilter + 抽取链路应用）。

## 验收

- AC-01：退出未入架网页书/漫画不出现放入书架对话框。
- AC-02：混排插图双击进全屏，可左右切图、下滑或点 X 退出。
- AC-03：全屏或阅读中长按图片可保存/分享。
- AC-04：漫画模式同样具备 AC-02/03（长按可沿用操作表）。
- AC-05：常见导航行（首页|目录|上一章等）与 header/nav/footer 类壳层不进正文。
