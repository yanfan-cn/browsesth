## 确认

1. **仅**手机 NTP 四键浮动顶栏行高 → **54dp**（`NtpTopBarHeight`）；`NtpContentShiftDown=90dp` 与其它 NTP 组件布局**不变**。
2. 深色壁纸/深色 NTP 时状态栏图标为浅色（可读）。
3. 修 SPEC-127 回归：开资讯后回主页再开任意页空白 → 从 NTP 开页时销毁 park 会话新建加载；返回无页内历史则回 NTP（**不用** `clearHistory`）。
4. 「滚动隐藏浏览栏」：顶栏+底栏同隐；隐藏时取消底栏占位。
5. 平板工具箱：顶栏下方 16dp；**竖屏宽 50% / 横屏宽 40%**（非全宽）；完整功能；内边距 16dp。（2026-10-17 纠偏：勿全宽卡片）
6. 组装 `assembleAppDebug`。

## AC

- AC-01：四键顶栏行高约 54dp；Logo/搜索/资讯卡相对位置与改前同（90dp 下移仍在）。
- AC-02：深色壁纸 NTP 上状态栏图标浅色可读。
- AC-03：A 资讯→回主页→开 B 或任意 URL：非空白；返回到主页（非闪旧篇卡死）。
- AC-04：滚动隐藏开：顶+底同隐，无底栏空白占位；上滚恢复。
- AC-05：平板工具箱在顶栏下 16dp；竖 50%/横 40% 宽；功能完整可见；内边距 16dp。
