# SPEC-092：资讯混排出图 + 默认滚动翻页

| Spec ID | SPEC-092 |
| 状态 | Ready |
| 确认 | 2026-10-09「确认」 |

## 范围
1. 主页资讯进图文混排后图片可加载（补 Referer/UA；必要时放宽懒加载提取）。
2. 小说与图文混排默认翻页为「滚动」；用户可在阅读设置「翻页动画」改默认。
3. 浏览器临时混排书不再强制滑动。

## 验收
- AC-01：常见门户资讯混排正文图可显示（非大面积感叹号）。
- AC-02：新装/默认样式翻页为滚动；临时混排书同。
- AC-03：用户可改全局翻页动画默认。
