## 确认

- 复述：①液态玻璃下工具箱「网页背景」无嵌套玻璃卡；②广告拦截 icon=`ad`；③平板支持液态玻璃；④网页地址栏无阴影；⑤平板顶栏方案 A。
- 填充模式「网页背景」已无底卡观感 → **不改填充路径**。
- 任务下达者：2026-10-31「确认；平板顶栏选A；填充模式下网页背景已经没有底卡，不用修改。」
- 红色：否（仍遵守 SPEC-100/111 安全表；平板工具箱进出禁止 fade）。

## 做

1. **网页背景（仅液态玻璃）**：去掉 `toolboxWebBgSurface` 嵌套玻璃；标题+分段直接落在面板上。填充模式保持现状。
2. **广告拦截**：`Symbols.Block` → Material Symbols `ad`（`Symbols.Ad`）。
3. **平板液态玻璃（热修②）**：平板**顶栏与工具箱暂全部实色**（`tabletFunctionBarUsesLiquidGlass=false`、`tabletToolboxUsesSolidSurfaces=true`）；工具箱进出仍只 slide。手机液态玻璃不变。根因：2.1.3/2.1.4 tombstone DirtyStack 溢出（含①仅 omnibox+净读仍炸）。
4. **地址栏阴影**：手机网页地址栏 `showShadow=false`。
5. （原方案 A / 热修① 已回退）平板顶栏不再上玻璃。

## 不做

- 标签页液态玻璃（SPEC-079）；平板设置 L1 玻璃返回键；改广告拦截逻辑；采样 AwContents；平板顶栏任意液态玻璃（待另开 Spec 安全方案）。
