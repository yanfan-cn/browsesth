## 2. 复述确认

操作者：浏览页底栏液态玻璃参照原 Legado（按住左右滑有小玻璃窗移动）；顶栏返回、地址栏、刷新改为液态玻璃，参照原 Legado。  
**更正（同日）：平板必须保持原样，不使用液态玻璃。**

范围：

- 手机会话底栏四键复用 `FloatingBottomBar` 的 backdrop + 按压拖动指示窗；阅读 FAB 不改交互。
- 手机顶栏：返回、地址栏、刷新为液态玻璃；地址栏不做拖动手势以免抢输入。
- **平板功能条：保持实心底栏/实心地址栏，不加液态玻璃。**
- 禁止对 AwContents 采样（沿用 `disableContentSampling` / 本地 layer backdrop）。
- API&lt;33 半透明回退。

## 3. 验收

- [ ] AC-01：API≥33 手机底栏按住左右滑，可见小玻璃指示窗随手指移动。
- [ ] AC-02：手机顶栏返回 / 地址栏 / 刷新为液态玻璃；地址栏可正常输入。
- [ ] AC-03：平板顶栏/地址栏无液态玻璃，与改前实心样式一致。
- [ ] AC-04：网页不因玻璃采样闪白。
