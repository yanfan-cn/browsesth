## 3. 本次范围

1. 多标签 MVP：新开、切换、关闭；标签页类 Chrome 网格卡片。
2. 历史页：按日期分组、点击打开、长按/删除、清空、可选搜索。
3. 收藏（书签）页：图标+标题+URL 列表、新增/删除/打开。
4. NTP：整体再下移 20dp；右上角三按钮进历史/收藏/标签。
5. 六搜索引擎内置 logo（选择器+下拉）。

明确不做：标签组/拖拽排序、桌面 Chrome 全功能、账号同步、底栏滚动隐藏、设置大重组。
