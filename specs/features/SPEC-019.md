## 3. 为什么做

浏览器 NTP 仍偏 Chrome 灰蓝，会话状态层仍有阴影，书签等页未统一设计 token，与 `docs/UI设计文档.md` 的阅读器气质不一致。

## 4. 本次范围

要实现：

1. 共享浏览器 UI token：主色 `#243B5A`、浅底 `#FCFBF8`、深底 `#121212`；间距/圆角/栏高按设计文档。
2. NTP：色板与 Logo 气质对齐；页面左右边距 16dp；搜索/按钮高度对齐；无阴影；手机/平板分流保留 SPEC-018。
3. 手机会话：顶栏 54dp；悬浮底栏无阴影；阅读圆钮用主色；状态层无 elevation。
4. 平板 Chrome：功能栏高度与圆角等 token 对齐；结构不变。
5. 书签：卡片列表（图标 + 标题 + URL + 删除）；历史/标签页间距与圆角对齐。

明确不做：

- 阅读视图页、设置全文、Splash、整 App 主题迁移。
- 新功能（液态玻璃新实现、多 WebView、广告 SDK）。
- `assemble*` 构建（本轮操作者要求）。

## 5. 用户如何使用

1. 打开浏览器 NTP → 看到纸感浅底（或墨色深底）与 Browsesth Logo，非 Chrome 灰蓝。
2. 打开网页 → 手机顶栏/悬浮底栏、平板双顶栏外观与 token 一致且无阴影。
3. 打开书签 → 卡片式条目；历史/标签视觉一致。

## 6. 产品规则

- 新浏览器原生 UI 不得使用阴影（`elevation` / `shadowElevation` > 0）。
- NTP 浅色背景为 `#FCFBF8`，深色为 `#121212`（无痕可更深区分）。
- 阅读视图入口圆钮与主强调色使用 `#243B5A`（深色模式可用同色或略提亮，但不得改回 Chrome 蓝 `#1A73E8` 作为主 CTA）。
- SPEC-018：手机保留悬浮底栏与 NTP 右上角三按钮；平板无悬浮底栏、NTP 60% 居中、无右上角三按钮——本次不得破坏。
- UI 文案不得出现图源/书源/漫画下载等敏感词。
