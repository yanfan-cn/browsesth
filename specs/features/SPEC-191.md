## 2. 开工前需求确认

- 已调查事实：
  1. 原版 legado-with-MD3 的详情转场与 browsesth 现版**代码相同**（300ms 交叉淡化 + 封面默认 spring sharedBounds + blur(24dp) 背板），但它流畅，因为它的底页（书架）是纯 Compose LazyGrid：无液态玻璃、无 `layerBackdrop` 逐帧采样、无玻璃卡片；转场期间底页重建/重绘是普通成本。
  2. browsesth 退出详情时三套重系统叠加：①封面 sharedBounds 在共享元素 overlay 逐帧重绘；②详情 `blur(24dp)` 实时模糊仍在跑；③主页（悬浮底栏玻璃 `layerBackdrop` 采样整页内容）在返回帧整棵重组，且运动内容每帧被重画进离屏层。卡顿是三者叠加，原版没有第③套。
  3. 退出飞回的直接机制在 `BookInfoScreen` L228-232：进详情落定后摘 key（让底页接住），退出转场一开始（`targetState=PostExit`）key 被**重新挂上** → sharedBounds 重新激活 → 封面飞回。取消飞出 = 退出时不再重挂 key。
- 疑问处理：操作者两条路（取消飞出 / 深挖原版流畅原因）——研究结论是玻璃壳为产品特性无法照抄原版，取消飞出是正确路径；操作者消息本身即指令与确认。
- 操作者确认：2026-10-28 消息直接下达（含「完成后不用构建」）。

### 红色问题判定

- 否：仅动详情退出的动画组成；不改入口、不改数据。**注意**：SPEC-189 §6「退场后封面必须回到触发卡片」的退出 morph 条款由操作者本指令修订（退出不再要求封面飞回；进入 morph 保留）。

## 3. 为什么做

1.8.4 已把阅读器搬出导航栈，主要闪切/掉帧路径已消；剩余最痛的是详情退出——封面飞回叠加玻璃采样与实时模糊。封面飞出是纯装饰性细节，取消它即可把退出降为「整页 300ms 交叉淡化」，去掉共享元素 overlay 这一整层逐帧重绘，是收益/风险比最高的一刀。

## 4. 本次范围

要实现：

1. 详情**退出**：不再重挂封面 sharedCoverKey——无封面飞回，详情页与底页整页 300ms 交叉淡化退出。
2. 详情**进入**：封面飞入保持不变（进详情仍从卡片飞到头图）。
3. 落定后的摘 key 行为保持（防双持有者）。

明确不做：

- 不动详情背景 `blur(24.dp)`（若取消飞出后退出仍掉帧，下一轮再治它——沿用 SPEC-189 AC-06 的排查顺序）。
- 不动主页玻璃层、不动阅读器（SPEC-190 成果）、不动阅读列表页。

## 5. 用户如何使用

1. 进详情：封面仍从卡片飞到头图（不变）。
2. 退出详情：详情页整页淡出、底页淡入，封面随各自页面淡入淡出，不再飞回；转场应明显更顺。

## 6. 产品规则

- 详情退出 = 整页交叉淡化，页面级转场不得再叠加封面飞行。
- 详情进入的封面 morph 保留。
- 封面不得画在液态玻璃离屏层里面（SPEC-189 §6 继续有效）。

## 7. 重要状态与边界

| 情况 | 用户应该看到什么 | 数据/状态处理 |
| --- | --- | --- |
| 退出详情 | 整页淡出，无封面飞回 | 无持久化 |
| 再次进入 | 封面飞入照常（key 重挂只在 enter 侧发生） | 无持久化 |
| 中途快速返回 | 交叉淡化可打断，状态一致 | Compose 转场状态机 |
