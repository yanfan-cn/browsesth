# LOG-185：无封面自动配色封面兜底

日期：2026-10-27

## 背景

- SPEC-162 已有 8 款 GeneratedCover + CoverPaletteStore 随机池；网页正文进阅读已接；
  网页漫画必有图。本地书籍无封面仍走旧默认图 → 操作者再次强调自动用配色封面。

## 实施

- 显示层（`CoilBookCover` 两个入口 `BookCoverImage`/`CoilBookCover`）：path 为空 /
  `DefaultCoverPath` / 本地封面文件已不存在 → `CoverPaletteStore.pickForSeed
  (name ?: author ?: bookUrl)`，种子稳定（同书恒定同款），尊重封面设置页的随机匹配/
  勾选/相册池。
- 导入层（`LocalBook.upBookInfo`）：epub/umd/pdf/mobi 解析后 coverUrl 仍空 → 写入
  `pickForSeed(bookUrl)`（持久化）。
- 在线封面加载失败的旧默认图兜底路径不变。

## 验证

- `:app:compileAppDebugKotlin` + `GeneratedCoverTest` 通过。
- 真机：无封面本地书（如 txt）阅读列表/详情应显示配色封面；有封面书不变。
