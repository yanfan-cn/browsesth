# LOG-150 外观设置精简 + 净读命名统一 + 订阅入口移除 + 构建

关联：SPEC-150、PLAN-150。日期：2026-10-20。状态：已实施，验证通过，待操作者装机复核。

## 复述确认（开工前问询结论）

经聊天框确认 4 项歧义：
1. 「阅读→净读」改名仅限**产品功能命名**；`WebArticleChromeFilter.kt` 站点过滤关键词「阅读模式」、小说阅读器通用词（阅读时长/阅读进度等）不改。
2. 液态玻璃仅改描述文案「安卓13以上才可使用液态玻璃」；`ChromeSurfaceStylePolicy` 强制 <API33 仅填充的逻辑保持不变。
3. 「订阅」页删除：仅移除主入口与相关设置项，底层订阅源功能与偏好键保留（兼容优先）。
4. 构建用 Release 包 + debug.keystore 签名（沿 SPEC-148 偏差 3 方案）。
