# LOG-188：视频播放通知 + 离开即停（听音频例外）

日期：2026-10-27
包：**巡页1.8.0-beta（debug, code 222）** 已组装（与 SPEC-189 同包）
状态：代码完成、编译通过；真机 AC 未验（本轮 `adb devices` 无设备）

## 实施

**A. 网页媒体桥（新增 `BrowserWebMediaBridge.kt`）**
- 持有 `JsEvaluator`（由 `BrowserSessionScreen` 在 `hostRef` 就绪时绑定/解绑）。
- `onPageMediaPlay/Pause/Destroy` 维护 `active/playing/title/durationMs/positionMs`。
- `pauseAll()`：`querySelectorAll('video,audio').forEach(m => m.pause())` —— 离开时停网页播放。
- `play/pause/seekBy/seekTo/refreshStateFromPage`：通知栏动作下发到页面；状态回读用
  `JSON.stringify({p,d,playing})`。

**B. 通知扩展（`BrowserVideoPlaybackService.kt`）**
- 新增 `ACTION_START_PAGE` + `startPage(context, title)`：「网页媒体」模式，无 ExoPlayer，动作走 Web 桥。
- `tickRunnable` 在 page 模式每秒 `refreshStateFromPage()` 后发布状态。
- 通知副标题新增「网页播放中 / 已暂停（网页）」。
- 新增 `isAudioOnlyActive()`（`@Volatile`），`startAudio` 置 true、`start/startPage/stop` 置 false —— 离开守卫据此保留「听音频」。
- page 模式点通知回 App 主界面（不是播放器 Activity）。

**C. 离开守卫（新增 `BrowserVideoLeaveGuard.kt`）**
- `stopExceptAudioListen(context)`：`pauseAll()` 网页媒体 → 结束巡页视频 Activity（若有）→ 非听音频则停服务并 `BrowserVideoPlayerBridge.pause()`。

**D. 引擎层离开信号（新增 `BrowserMediaSessionHooks.kt`）**
- `BrowserTabManager`：`openNewTab(select)`、`switchTo`、`close(活动标签)`、`closeAll`、`clearActiveToNtp` 均发出 `notifyWebContextLeft()`。

**E. 接线**
- `BrowserSessionScreen`：`onMainFrameLoadStarted`（同标签跳转）调守卫；新增 `onPageMediaState` 回调处理网页播放/暂停/销毁 → 起停通知；`DisposableEffect(hostRef)` 绑定 JS evaluator。
- `BrowserAwContentsClient`：`onPageMediaState` 参数接入 `onMediaPlay/onMediaPause/onMediaDestroy`；`shouldPlayBackgroundVideo()` 由 `true` 改 `false`（SPEC-166 的「后台可继续播」被 SPEC-188 取代）。
- `MainScreen`：`onBrowserHome` 变 false（离开浏览器去阅读列表/我的）即调守卫。
- `App`：`BrowserMediaSessionHooks.onWebContextLeft` + `LifecycleHelp.appVisible` 收集（App 全部不可见 = 切后台）→ 守卫。
- `BrowserVideoPlayerActivity`：删除 Home 自动进 PiP 的 `onUserLeaveHint` 逻辑；`onStop` 非 PiP 时暂停并 `finish()`（不再后台续播）；新增 `activeInstance` + `finishIfShowingVideo()` 供守卫关闭。
- `BrowserVideoPlayerBridge`：`play/pause/isPlaying/positionMs/durationMs/seekBy/seekTo` 全部在无 native player 时回退到 Web 桥；新增 `hasNativeVideo()`。

## 未验证 / 已知风险

- **真机 AC-01～08 全部未验**。需重点看：
  1. 网页播放器起播是否**立即**出通知（Chromium `onMediaPlay` 时机）；YouTube 等站是否触发。
  2. 通知栏播停/±15s 对网页播放器是否真的生效（`document.querySelector('video')` 在多视频页面可能选错元素）。
  3. `shouldPlayBackgroundVideo=false` 是否会导致**正常前台**播放被误停（Chromium 该回调语义需真机确认；若误停必须回滚为 true 并改由守卫显式 pause）。
  4. 听音频例外：切标签/回主页后音频是否仍在、通知是否仍在。
  5. 巡页播放器按 Home 后是否为「停止 + 通知消失」（已删自动 PiP）。
- 快速连按胶囊「播放」→「听音频」等组合下 `audioOnlyActive` 标记可能短暂不一致。
- 网页内多路同时播放时只会控一路。
