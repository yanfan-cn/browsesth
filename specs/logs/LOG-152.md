# LOG-152 视频下载 403 / 平板播放器与主页四处修复 / 播放器状态栏跟随

关联：SPEC-152、PLAN-152。日期：2026-10-20。状态：已实施，编译+单测+构建+签名通过，AC-1~AC-5 待装机复核。

## 问题与根因（操作者装机 1.5.5-beta 后反馈 6 项，歧义已确认）

1. **视频下载全部 HTTP 403**（重试后必现）：`downloadLoop` 算了 `eff*` 兜底却仍用原始参数设连接头；`resume()` 传 null → 重试请求零请求头 → 防盗链 403。
2. **平板播放器「旋转」无效**：原实现切 `requestedOrientation`，平板方向策略下被忽略。
3. **横屏播竖屏视频截图变形/不完整**：`refreshQualities` 未处理 `format.rotationDegrees`（竖拍编码 1920×1080+90° 误记横屏比例）；换视频 `videoSize` 不复位。
4. **收藏/书签「添加至主页」重启才出现**：NTP `shortcuts` 为 remember 一次性快照，覆盖层返回不重读 store。
5. **主页一行 6 个最右空一格**：`rowGap` 恰好整除，dp 取整亚像素溢出使第 6 个 chip 换行。
6. **播放器状态栏**：隐藏控制层时状态栏残留；显示时状态栏区域透明。

## 实施

1. **R1 下载 403**（`browser/engine/`）：
   - `BrowserDownloadModels.kt`：`BrowserDownloadItem` 加 `requestHeadersJson: String? = null`；
   - `BrowserDownloadStore.kt`：读写 `requestHeaders` 字段（持久化）；
   - `BrowserDownloadHelper.kt`：headers 非空时 `JSONObject` 序列化传入 `enqueueFile/enqueueHls`；
   - `BrowserDownloadRepository.kt`：`enqueueFile/enqueueHls` 加 `requestHeadersJson` 参数写入 item；`downloadLoop` 连接头统一 `applyRequestHeaders(conn, effUserAgent, effCookie, effReferer, effExtraHeaders)`；新增 `applyRequestHeaders`（保留 UA/Cookie/Referer/Range/Host/Content-Length 键，eff 值覆盖）与 `parseExtraHeaders`（非法 JSON 返回空）；`hlsLoop` 加 `extraHeaders` 参数，master/media/分片请求全部走 eff 头；Diag146 日志改记 `effReferer`。
2. **R2 旋转画面**（`ui/browser/video/BrowserVideoPlayerScreen.kt`）：新增 `videoRotation` 状态；`toggleOrientation()` 改为 `videoRotation = (videoRotation + 90) % 360`；换视频 `LaunchedEffect(offer.url)` 复位 `videoRotation=0; videoSize=null`；AndroidView 改 swapped-bounds `layout{}`（90/270 时以交换宽高测量居中）+ `graphicsLayer rotationZ`。系统方向策略（applyRotationPolicy）保留。
3. **R3 截图比例**（同文件 `refreshQualities`）：按 `format.rotationDegrees % 180` 换算显示宽高；无有效尺寸时 `videoSize = null`（不裁剪）。
4. **R4 主页响应式刷新**：`BrowserShortcutStore` companion 加 `version = MutableStateFlow(0L)`，`saveAll` 末尾递增；`BrowserNtpScreen.kt` `collectAsState()` 监听版本重载 `shortcuts`。
5. **R5 网格余量**（`BrowserNtpScreen.kt`）：`rowGap = ((maxWidth - iconSize×6)/5 - 2.dp).coerceAtLeast(0.dp)`。
6. **R6 状态栏跟随**（`BrowserVideoPlayerScreen.kt`）：`DisposableEffect(showControls, inPipMode, insetsView)` 用 `WindowCompat.getInsetsController` 隐/显状态栏（`BEHAVIOR_SHOW_TRANSIENT_BARS_BY_SWIPE`）；`DisposableEffect(Unit)` onDispose 恢复；顶栏 `.background(Black 0.45f)` 先于 `.statusBarsPadding()`，底栏背景同理盖到导航栏底下。
7. **平板「我的」返回回主页**（不在 SPEC 立项范围，操作者原话第 2 条，随本 SPEC 落地）：
   - `MainScreen.kt`：签名加 `backStack: MutableList<NavKey>? = null`、`onRegisterRootTabBack: ((() -> Boolean)?) -> Unit`；原 SPEC-060 BackHandler 扩展为书架/我的等根标签返回切回主页；新增 `DisposableEffect(destinations, homePageIndex)` 向 Activity 注册拦截器（当前页 ≠ 主页标签时 `animateScrollToPage(homePageIndex)` 返回 true），离组注销；
   - `MainNavGraph.kt`：`mainEntryProvider` 透传两参数至 `entry<MainRouteHome>` 的 MainScreen；
   - `MainActivity.kt`：`rootTabBackHandler` remember 状态；`mainEntryProvider(onRegisterRootTabBack = { rootTabBackHandler = it })`；Activity 级 BackHandler 在 `backStack.size <= 1` 且拦截器非空时启用，先走拦截器、未拦截再 `MainNavigator.navigateBack`（预测性返回开/关两种设置下均回主页而非退出）。
