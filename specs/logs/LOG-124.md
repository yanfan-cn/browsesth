## 2026-10-15 12:00–12:20：Phase A2 复核 + B1/B2 实施

- **B1 缩略图异步 PixelCopy**（`AwContentsHostView.capturePreviewAsync` + `BrowserSessionHolder.captureActiveThumbnail` 异步落库 + 低分辨率软绘降级）装机 1.2.1-beta 验证：拍照巨型帧消失；back→首帧 17–46ms；attach 0–110ms；restore 0–1ms；缩略图 1080x1950→360x650 正常；无降级路径触发。但用户复测体感全部无改善 → 转入 A2 复核。
- **A2 证据**：framestats 退出窗口仍有 100–364ms 帧（draw(record)=84–208ms + input→traversals=47–57ms）；JIT 每次退出重编 `BrowserNtpScreen$lambda$96$0`（40+ 捕获参数、16MB 编译分配）；录屏（45s，ffmpeg 拼帧分析）+ 用户实报证实进入先闪 NTP 约 0.5–1s 再进网页。
- **根因修订**：进入 = `offer(url)+onNavigateBack()` → Home 重挂载先组合 NTP、`LaunchedEffect(pendingOpen)` 异步消费才开会话（双重组合 + 桥接跳变）；退出 = `clearActiveToNtp()` 立即 `showHome=true` → 240ms 滑出动画期间组合 NTP → 巨帧吃掉动画。详见 PLAN-124 §5。
- **B2a 实施**：`MainNavGraph` 历史/书签 `onOpenUrl` 改同步 `openUrlInActive(url)` 后 `onNavigateBack()`；`BrowserBookmarksScreen` newTab 分支去冗余 `offer`（避免同 URL 二次 load）。效果待复测。
- **B2b 实施**：`BrowserNtpSessionSwitch` pop 分支先滑出、等 `isIdle` 再原地组合 NTP。**用户复测：退出瞬间白屏、然后才回主页——不可接受，需返工**（下次候选：错峰 2~3 帧而非等滑出完成 / NTP 常驻组合垫底 / 滑出期间垫已组合内容）。
