# LOG-146 — 地址栏/剪贴板/滑层扩面/播放器下载与重播

## 对应

- SPEC：`specs/features/SPEC-146.md`
- PLAN：`specs/plans/PLAN-146.md`

## 实际改动

### R1 地址栏全选（TextFieldValue 化）
- `BrowserSessionScreen.kt`：`address` String→`TextFieldValue` 全链替换（init、syncIdleAddress、openSuggest/openArchive/navigateToAddress/18 处 `ifBlank`/6 处 `?: address` 回退读取均改 `.text`）；omnibox `onFocusChanged` focus gained 时以 `TextFieldValue(editUrl, TextRange(0, len))` 设置实现全选。
- 平板 `BrowserHomeTabScreen.kt`：`address` String→`TextFieldValue`；focus gained 同样全选；新增 `idleTabletAddress(tab)` 统一 idle 取值。
- `TabletBrowserChrome.kt`：`TabletBrowserShell`/`TabletFunctionBar` 参数改 `TextFieldValue`；FunctionBar omnibox 加「搜索或输入网址」placeholder。

### R2 剪贴板链接候选
- 新增 `browser/engine/BrowserClipboardUrl.kt`：读首条 clip，trim、≤2048、无空白/换行、http(s) 前缀、`Uri.parse` host 非空才返回；纯函数 `parse` 供测试。
- `BrowserOmniboxSuggestPanel.kt` 扩参 `clipboardUrl`/`onClipboardSelect`：候选栏首行「剪贴板链接」+ Link 图标。
- 三个入口接线：手机 NTP 搜索框（`BrowserNtpScreen.kt` focus gained 读取、失焦清除、点击 `onOpenUrl`）、手机会话 omnibox（`openClipboardUrl`→`loadExternalUrl`）、平板 Shell（`BrowserHomeTabScreen` focus 时读取并传参，点击 `onOpenUrl`）。
- 隐私口径：仅焦点内读取（Android 12+ 系统提示 / 13+ 允许粘贴对话框），本地检测展示，不上传不持久化。

### R3 平板回主页地址栏清空
- `BrowserHomeTabScreen`：idle 取值统一走 `idleTabletAddress`——`showHome=true`（NTP 态）返回空 `TextFieldValue("")`（显示 placeholder），网页态返回 `tabDisplayTitle`；初始 remember、两个 LaunchedEffect、`onPageMeta` 均改走该函数；提交/失焦路径同步。

### R4 滑层扩面
- `MainNavGraph.kt` 23 个 entry 加 `browserSlideOverlayMetadata(onBack=onNavigateBack)`：书源管理/编辑/调试、RSS 源管理/编辑/调试、导入本地/远程、缓存管理、下载缓存管理、RSS 收藏、订阅规则、阅读记录、阅读记录总览、高亮规则、AI 助手、人物详情/关系/列表、知识列表/详情、事件列表/详情。
- 例外保持：阅读器/漫画/webView 会话/书籍详情/搜索/探索/听书弹层未动。

### R5 播放器下载（HLS 分片合并）
- 新增 `browser/engine/BrowserHlsPlaylist.kt`：master 选取最高 BANDWIDTH 变体；media 解析 EXTINF 分片 + `EXT-X-MAP` init 置首；相对 URL 基于 playlist URL 解析（非 http(s) 结果丢弃）；`isFmp4`=有 MAP 或 .mp4/.m4s 分片 → `.mp4` 否则 `.ts`。
- `BrowserDownloadRepository.kt`：新增 `enqueueHls`（mimeType=application/vnd.apple.mpegurl，默认名 `title.ts`）与 `hlsLoop`（playlist 探测→改扩展名→逐段 GET append 写 `.partial`→分片间/读循环内响应暂停→均值×分片数估 totalBytes→完成 rename COMPLETED）；`downloadLoop` 对 HLS item 分流；请求带 UA/Cookie/Referer。
- `BrowserDownloadModels.kt`/`BrowserDownloadStore.kt`：新增持久化字段 `requestUserAgent/requestCookie/requestReferer`（org.json 读写同步，旧数据缺键 optString 兼容）；`resume` 经 item 字段回退取请求头（顺带修复 FILE 下载恢复丢失 UA/Cookie 的既有问题）。
- `BrowserDownloadHelper.enqueue` 扩参 `headers`；url 含 `.m3u8` 或 mime 含 mpegurl → 走 `enqueueHls`。
- `BrowserVideoPlayerScreen.kt` 下载菜单传 `headers = currentOffer.headers`。

### R6 重新播放
- `BrowserVideoPlayerScreen.replayFromStart()`：先 `runCatching { vv.restart() }`（ExoMedia 在 ENDED/IDLE 态内部 seekTo(0)+setPlayWhenReady+forcePrepare+prepare；字节码核实 5.2.0），失败回退 `seekTo(0)+start()`；`Diag146` 日志记录 restarted 结果。
