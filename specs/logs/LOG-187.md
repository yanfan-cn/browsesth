# LOG-187：桌面 Shortcut 不生效根因与修复

日期：2026-10-27

## 根因（实锤）

- 操作者已装 1.7.8 仍显示旧三项（最后阅读/朗读/阅读列表）→ 排除"包未装机"，定位到运行时发布失败。
- `MainIntent.createLauncherIntent` 的 Intent **无 action**；`buildNewTab`/`buildBookshelf`
  只 putExtra 未补 action。`ShortcutManager` 要求 shortcut intent 必须带 action →
  `setDynamicShortcuts` 整批校验抛 `IllegalArgumentException` → 被 `MainActivity`
  `runCatching` 吞掉（仅 Log.e）。**每次发布都失败** → 桌面动态列表永远是旧三项。
- 工作区旧实现（四项 + 图标设计）本身符合操作者要求，无需重做。

## 实施

- `buildNewTab` / `buildBookshelf` intent 补 `action = Intent.ACTION_VIEW`。

## 验证

- `:app:compileAppDebugKotlin` 通过。
- 真机：装机 → 打开 App 一次 → 长按图标应显示四项；Honor 启动器若仍缓存旧图标，卸载重装一次。
