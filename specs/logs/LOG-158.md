# LOG-158 主页预置壁纸 / 菜单切换 / 相册添加

关联：SPEC-158、PLAN-158。日期：2026-10-21。状态：debug 已组装。真机未验。

## 实施

1. 晨纸 / 薄雾 / 窗纱拷入 `res/drawable-nodpi/`（`ntp_wall_morning.jpg`、`ntp_wall_mist.jpg`、`ntp_wall_linen.jpg`）。三张渐变用 `Brush.verticalGradient`（上 `#B7D6F2` / `#C9E6D2` / `#F6D5DE`，下白）。
2. `NtpWallpaperStore` + `BrowserChromePrefs.ntpWallpaperId`（默认 `grad_blue`）/ `ntpUserWallpaperIds`。相册图经 `PickVisualMedia` 拷入 `filesDir/ntp_wallpapers/`，长边压到 1920，按 EXIF 转正。删除当前用户图后回到浅蓝渐变。
3. `BrowserNtpScreen`：非无痕且每日壁纸关闭时铺选中背景（图片居中裁切，渐变铺满）。必应壁纸遮罩 0.35；用户图 0.32；深色主题在预置上再盖 0.28（用户图深色主题 0.40）。有遮罩或深色主题时书签名与状态栏图标为浅色。任一张壁纸可见时打开液态玻璃采样层。
4. 左上角主页菜单「每日壁纸」下增加「背景」横滑：六张内置、用户图（右上角 × 删除）、末位「+」从相册添加。
5. 本包同时带上此前未出包的 SPEC-157（播放器旋转、设置子页后再进）。
