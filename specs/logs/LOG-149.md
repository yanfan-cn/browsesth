# LOG-149 阅读视图不可用修复 + 提取加载胶囊改版

关联：SPEC-149、PLAN-149。日期：2026-10-20。

## 复现确认

- 操作者补充（开工前问询）：**手机端**点阅读 FAB **立即**弹「阅读视图不可用」、无加载弹窗 → 判定为 `openReaderView` 的 `hostRef == null` 分支（页面正常显示、Holder 活跃宿主仍在），非提取失败路径。

## 实施

1. `BrowserSessionHolder.kt`：新增只读查询 `activeHostFor(key)` / `activeClientFor(key)`（仅同 sessionKey 活跃槽位返回，只读无副作用）。
2. `BrowserSessionScreen.kt`：
   - 新增局部 `resolveReaderHost()`：`hostRef` 优先，空则 Holder 回退并回写 `hostRef/clientRef` 自愈，命中时打 `Diag149` 日志；
   - `openReaderView` / `openNovelReader` / `openMangaReader` 改用该解析；Holder 无匹配活跃会话时维持原提示（真实无宿主场景不掩盖）；
   - 提取加载态：删除全屏黑 28% 遮罩 + 屏幕正中卡片，替换为 `ReaderLoadingCapsule`（40dp 胶囊：18dp 进度圈 + 「正在打开阅读视图…」+ 36dp 取消键；胶囊本体 `clickable {}` 吞点击防透传）；宽度 = 屏宽 × 40%；手机 `BottomCenter`，bottom = `floatingBottomPad + phoneChromeBarHeight(48dp) + 16dp`；平板（tabletEmbedded）`TopCenter`，top = `statusBars + 40dp(标签条) + TopBarHeight(54dp) + 16dp`。
   - `import android.util.Log` 新增；被删卡片的 `Card/CardDefaults/RoundedCornerShape/Spacer/TextButton` 等 import 确认仍被其余代码使用（23 处），未清理。
3. `WebViewRouteScreen.kt`：新增 `onOpenReader/onOpenMangaReader` 参数（默认空实现，不破坏既有调用）并传入 `BrowserSessionScreen`。
4. `MainNavGraph.kt`：`MainRouteWebView` entry 传入阅读回调 → `MainRouteReadBook / MainRouteReadManga`（`inBookshelf = true`，与主浏览器一致）。
