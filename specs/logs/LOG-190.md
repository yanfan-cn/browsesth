## 实施

### A. R4 摘除 + 详情恢复原版 300ms

- 删 `ui/main/FadeCoverSceneStrategy.kt`；MainActivity sceneStrategies 移除注册。
- `MainRouteBookInfo` metadata 恢复 300ms 交叉淡化三键（`NavMotion.bookInfoFadeIn/Out`，对齐原版 legado-with-MD3 MainNavGraph L1129-1142）。
- 删 `NavMotion.ReaderEntranceWaitMs`、`ReaderPageFadeMs`、`coverBoundsTransform`；`ReadBookController` 分页批次的入场等待与 `MangaReaderRouteScreen` 的入场等待一并删除（`readerEntranceSettled` 机制本身保留——Activity 宿主下无 AnimatedContent，`?: true` 立即放行）。
- 删 `ui/main/ReaderSharedBounds.kt`（唯一消费者是已删除的阅读器转场）。

### B. 阅读器独立 Activity（照原版架构）

原版范本（fork 内现成代码）：`ReadMangaActivity : BaseComposeActivity` 宿主 Compose 阅读器、`BookInfoActivity` 的 `MainActivity.createXxxIntent` 跳转模式、`ReadBookController` "可宿主于任意 Activity" 的设计。

- **新建 `ui/book/read/ReadBookActivity`**：宿主 `ReadBookRouteScreen`（页面零改动）。
  - Intent 参数复用 MainIntent 既有 extras（bookUrl/readAloud/inBookshelf/chapterChanged）。
  - 原导航 entry 的整段接线（PrivateReadGate、resume/pause 生命周期观察、onStartContentLoadFinish→朗读、effectsReady/collectorReady 门）逐条搬入；`controller.onClose` 不再设置（默认 `activity.finish()`）。
  - 按键/滚轮分发从 MainActivity 抄入（`dispatchKeyEvent`/`onGenericMotionEvent`/`onKeyDown/onKeyUp`）。
  - 生命周期注册 `ReaderForegroundTracker`（替代原「栈顶是否阅读器」判据，供播放弹层「经典控制」目标判定）。
- **`ReadMangaActivity` 重写为 `MangaReaderRouteScreen` 薄宿主**（原宿主直用 `MangaReaderScreen`，与主路径分叉；现统一走 RouteScreen 单一宿主路径）：
  - `MangaReaderRouteScreen` 解除 `LocalActivity.current as MainActivity` 硬耦合 → `AppCompatActivity` + 新接口 `MangaReaderKeyHost`（MainActivity 实现，保平板内嵌阅读的音量键翻页）。
  - 删共享元素三参（morph 已放弃）；目录弹层 `ReaderBookSheetRoute` 保留在 Activity 内。
  - 书籍信息跳转走 fork 原版模式：`StartActivityContract(BookInfoActivity::class)`，删除书结果 `READER_RESULT_DELETED` → finish。
- **MainIntent**：`createReadBookIntent`/`createReadMangaIntent` 改指向两个阅读器 Activity（NEW_TASK|SINGLE_TOP + singleTask launchMode 复用实例）；`createReadBookMediaControlIntent` 同步（去 CLEAR_TOP/home-parent）；新增二级目的地工厂 `createSearchContentIntent`/`createBookVoiceCastingIntent`/`createCloudTtsEnginesIntent`/`createTtsCacheIntent`（launcher 组件 + start route，NEW_TASK|SINGLE_TOP——Main 不在栈顶时确定性新建实例承载单路由，返回即回阅读器）。
- **入口迁移**（原 `onNavigateToRoute(MainRouteReadBook/ReadManga)` → `startActivity`）：WebView 阅读入口、浏览器会话页（书城/网页书）、书架书目、书签页、书籍详情、播放弹层「经典控制」；`BaseReadAloudService` 通知意图经重定向后的工厂自动改道。
- **删路由**：`MainRouteReadBook`/`MainRouteReadManga` 及 ROUTE_READ_BOOK/ROUTE_READ_MANGA 常量从 MainNavKey/MainNavGraph（两个 entry 共 202 行）/MainNavigator（阅读器预取、替换、栈判定、start-route 映射）全部移除；MainActivity 删 `restoredReadBookRoute`/`activeReadBookRoute`/保存态阅读路由恢复（阅读器恢复由其自身 saved state + intent 承担）。
- **「启动直接进阅读器」**（defaultToRead）：改为 MainActivity 启动后 `LaunchedEffect` 拉起 ReadBookActivity（一次性 guard）。
- **平板不动**：`TabletEmbeddedReaderHost`（SPEC-036 壳内内嵌阅读）保持原样——它不经 NavDisplay，无闪切问题；MainActivity 保留 `activeReadBookInputHandler`/`activeMangaKeyHandler`/`hasActiveReadBookRoute` 供其使用。
- **manifest**：注册 `ReadBookActivity`（singleTask、含 orientation configChanges 与 MainActivity 同）；ReadMangaActivity 已有声明沿用。
