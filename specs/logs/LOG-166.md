# LOG-166

开始：2026-10-25。确认：「确认」。

## 实施

1. `ShortCuts`：四项入口不变。图标按 `SymbolIcon` 的字体轴绘制在圆角矩形上（108dp 槽位上的 24dp 圆角）。浅色底 `#F6F1EA`、深色底 `#121212`，读系统夜间模式。`MainActivity.onConfigurationChanged` 后重注册。绘制失败不再从 ContentProvider 杀进程（仍在首帧之后、`runCatching` 里）。
2. 倍速去掉 1.25 与 2.5。长按换档距离改为屏宽的 1/10。倍速条圆角 24dp，当前档浅色 `#F6F1EA` / 深色 `#121212`。
3. 离开播放器再回来（含画中画展开）会按离开时的进度重建播放器。根因是 ExoMedia 在画面 Surface 销毁时卸掉监听，进度还在走，seek 也绑不回新画面。「重新播放」同样重建，从开头播。
4. 更多菜单五项带图标。加入收藏写入来源网页。
5. 下载成功后右上角卡片显示进度，点按打开下载页。
6. 资源请求只观察不拦截：m3u8 / mp4 / webm / mkv / mpd，以及 YouTube `videoplayback`（丢掉音频和分片）。同一影片保留更可能能播的地址（渐进 18/22 优先）。`<video>` 的 http 地址也会上报。
7. 网页全屏改挂到窗口上，不再套一层 Dialog。`shouldPlayBackgroundVideo()` 改为 true。未改内核。
