# LOG-145 — 视频播放器九项优化

## 对应

- SPEC：`specs/features/SPEC-145.md`
- PLAN：`specs/plans/PLAN-145.md`

## 实际改动

### R1 ±20s 图标（`BrowserVideoPlayerScreen.kt`）

- Material Symbols 官方字体无 `replay_20`/`forward_20` ligature，按用户拍板改用无数字 `replay`/`forward`，行为仍为 ±20 秒。

### R2 右上角更多菜单（`BrowserVideoPlayerScreen.kt`）

- 顶栏新增 `more_vert` 键 + DropdownMenu，菜单项：投屏（原 DLNA 逻辑）、下载（原 enqueue 逻辑）、分辨率（关 more 开 quality 菜单）、重新播放（`seekTo(0)` + 播放）。
- 原顶栏独立投屏/下载/旋转三键删除。`castSymbol` 声明一并删除（菜单为纯文本项，无图标）。

### R3 分辨率信息与选档（`BrowserVideoPlayerScreen.kt`）

- 时间行（进度条上方）改为 Row：左侧「自动 / xxxP」文本（点击开档位菜单）+ Spacer(weight) + 右侧时长文本。
- `refreshQualities()`：`OnPrepared` 后从 `videoView.availableTracks[RendererType.VIDEO]` 提取 `height>0` 档位，`distinctBy height` 降序。
- `selectQuality()`：null=自动→`clearSelectedTracks(VIDEO)`；否则 `setTrack(VIDEO, groupIndex, trackIndex)`；切换前记 `resumeAt=currentPosition`，切换后回跳并恢复播放，Toast 反馈。
- 单档（MP4）时菜单只显示禁用项「当前视频仅一种清晰度」（用户拍板）。
- 文件底部新增 `data class VideoQualityOption(height, groupIndex, trackIndex)`。

### R4 右下角截图键 → 画中画（`BrowserVideoPlayerScreen.kt` + `BrowserVideoPlayerActivity.kt`）

- 底栏最后一个 IconButton 换为 PIP：`picture_in_picture_alt` 图标，`onClick = { activity.enterPipMode() }`；`enterPipMode()` 由 private 改 internal。
- 截图功能移至 R5 侧栏。

### R5 右侧中部侧栏（`BrowserVideoPlayerScreen.kt`）

- `Alignment.CenterEnd` + `padding(end = 24.dp)`，Column spacedBy 12dp：截图（`photo_camera`，原 `captureToPictures` 逻辑）、旋转（原 toggleOrientation 逻辑）。
- 两键均 IconButton 48dp + `background(Color.Black.copy(alpha=0.5f), CircleShape)`，纵向排列。
- 原顶栏旋转键已删（R2）。

### R6 迷你胶囊视频列表（`BrowserSessionScreen.kt`）

- `BrowserSessionScreen` 增加 `playlistOffers by BrowserVideoOfferBus.offers.collectAsStateWithLifecycle()`。
- `VideoPlayerPromptCapsule` 扩参 `showPlaylist / playlist / onPlayOffer`；`playlist.size > 1` 时在关闭键前显示 `playlist_play` 键，DropdownMenu 宽度 = `capsuleWidth`（与胶囊同宽），条目为标题（空则 host，单行省略）。
- 手机（fillMaxWidth 调用点）与平板（widthFraction=0.45 调用点）两处均接线：`onPlayOffer` 先 `BrowserVideoPlaybackService.stop(context)` 再启动 `BrowserVideoPlayerActivity`。

### R7 播放器内选集菜单加宽（`BrowserVideoPlayerScreen.kt`）

- DropdownMenu 固定 `Modifier.width(300.dp)`（原约 200dp 隐式 wrap），条目文本 fillMaxWidth。**偏差**：300dp ≈ 原宽度约 1.5 倍的近似实现，非严格动态计算 1.5×。

### R8 列表重复条目修复（`BrowserVideoOffer.kt`）

- 根因：`onMediaPlay` 与 `onHlsDetected` 双路径对同一视频发布 offer，URL 细节差异（query 顺序/fragment/空白）导致精确去重失效。
- 修复：`publish()` 前先 `normalizeVideoKey(url)`（trim → 去 `#` fragment → query 参数排序）再查重；命中去重时输出 dedupe-hit 日志。
- 新增 `internal fun normalizeVideoKey(url: String): String`。

### R9 网页自带播放器失效排查

- `BrowserAwContentsClient.kt`：`onMediaPlay`、`onMediaError`（原空实现）、`onVideoEnterFullscreen/ExitFullscreen/onEnterFullscreen/onExitFullscreen`（原空实现）加 `Diag146` 日志；注释记录 AwContents HTML5 全屏走 `onShowCustomView` 路径，先观察日志不接线。
- 代码级未发现拦截/篡改媒体播放的主动逻辑；需装机复测 `Diag146` 输出定位真实失败点。若内核层（Chromium WebView 媒体管线）无解，按红线跟进，不承诺根治。
