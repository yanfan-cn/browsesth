## 实现要点

- Flavor：`aloha`（默认，Aloha）+ `systemWv`（系统 WebView）。**不能**再叫 `app`：模块名 `:app` + flavor `app` 时 AGP 不接入 `src/app`。
- Aloha 源：`src/aloha/java/.../browser/engine/` + `alohaImplementation(aloha AAR)`。
- systemWv 源：`src/systemWv/java/...` 同名宿主（`AwContentsHostView` 包 `WebView`、`BrowserAwContentsClient`、`AlohaBrowserCompose`、bootstrap/DrawMode/KernelCompat/DiagProbe/Privacy/Cookie/Incognito）。
- 公共：`BrowserJsCallback` / `BrowserCustomViewCallback` / `BrowserCookieStore`；`AwContentsHostViewExt.evalJs` 在 main。
- Cronet：`X509Util` 改为按名反射，避免 systemWv 缺 Aloha 类。
- 组装任务：`assembleAloha*` / `assembleSystemWv*`（原 `assembleApp*` 更名）。

## systemWv 已知降级（AC-04）

1. **无 Aloha/Bromium 内核**：无 DrawFn、无内核级广告开关 / command-line switches（`BrowserKernelCompat` 空实现）。
2. **广告拦截**：仅 URL 规则 `shouldInterceptRequest` + 页面侧 shield JS；弱于 Aloha 资源管线。
3. **无痕**：无独立 `AwBrowserContext`；清 Cookie/WebStorage 近似，会话隔离弱于 Aloha。
4. **Client Hints / UA metadata**：无 `BrowserUaHints` 映射。
5. **媒体**：无 Bromium `onMediaPlay/Pause` 原生钩子；靠 JS `VIDEO_HOOK` + 资源嗅探。
6. **厂商 WebView 差异**：Force Dark / Safe Browsing / 第三方 Cookie 依 WebView 版本；不保证与 Aloha 一致。
7. **Cronet**：无 Aloha 内嵌实现时走现有 OkHttp 回退。
