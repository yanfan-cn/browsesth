## 研究结论（为什么原版流畅）

- 原版 legado-with-MD3 详情转场代码与 browsesth 现版一致（300ms 交叉淡化 + 封面默认 spring sharedBounds + blur(24dp)），流畅差异在环境：
  1. 原版底页是纯 Compose LazyGrid 书架，无液态玻璃、无 `layerBackdrop` 逐帧采样；转场期底页重建/重绘是普通成本。
  2. browsesth 退出详情时三套重系统叠加：封面 sharedBounds overlay 逐帧重绘 + 详情 `blur(24dp)` 实时模糊 + 主页（悬浮底栏玻璃采样整页内容）返回帧整棵重组且每帧重画离屏层。原版没有第三套。
  3. 玻璃壳是 browsesth 产品特性，不能整体照抄原版 → 采纳操作者方案：退出取消封面飞出。

## 实施

- `BookInfoScreen.kt`：
  - 新增 `val isExiting = transition?.targetState == EnterExitState.PostExit`。
  - 传给 `BookInfoScreenContent` 的 key：`takeIf { !sharedTransitionFinished && !isExiting }`——退出开始不再重挂 key，sharedBounds 不激活 → 整页 300ms 交叉淡化退出，无封面飞回。
  - 进入侧不变：enter 期间 targetState=Visible，key 正常挂上 → 封面飞入保留；落定摘 key 行为不变。
- 单点改动，回退 = 条件改回 `takeIf { !sharedTransitionFinished }`。
