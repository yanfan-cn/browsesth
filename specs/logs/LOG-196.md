# LOG-196：顶栏控件对齐 + 图标能力统一 + 标签页底部全部关闭（SPEC-196）

日期：2026-10-28
包：**巡页1.9.0-beta**（debug, code 232）已组装并装真机；version.properties 进位 **1.9.1 / 233**
状态：真机 AC-01～04、AC-06 已验；AC-05（平板顶栏）待平板验证

## 操作者反馈与决策链

1. 收藏/书签顶栏切换控件与其他控件高度不一致；切到书签时控件变宽，要求强制宽度不变。
2. 历史、收藏、快捷书签保持同等获取网站图标的能力。
3. 标签页新增底部全部关闭键（Material Symbols Close、仅 icon、底部居中、距底 32dp、配色同返回/新建标签页、中靠下阴影）；完成后构建 app 并 adb 真机测试。
4. 确认：底部键**仅手机**（平板不加）；平板顶栏 CloseAll 图标改 `Symbols.Close` 且与新建标签页间距 ≥4dp；图标统一 = 历史/收藏/链接菜单补上按域名匹配的内置高清图标（远程链已同链，不动）；底部键 48dp。

## 根因与实施

1. **高度**：`BookmarksModeSegmentedControl` 28dp → 36dp（对齐 TopBarSeriesIconButtonSize 与标签页分段控件）。
2. **变宽根因**：切换控件 `weight(1f)`；书签页无加号（SPEC-121）→ 右侧少 36dp+4dp 间距被控件吃掉。修法：`!showAddFavorite` 时在排序与新建文件夹之间补 `Spacer(36.dp)`（复刻加号槽），两页布局逐像素一致。
3. **图标统一**：`BrowserShortcutStore` 新增 `localIconResForHost(host)`（域名/子域匹配六个内置图标：baidu/bilibili/rebang.open2hub/ithome/thepaper/feijipan）；`BrowserShortcut.localIconRes()` 改走 host 匹配（默认书签行为不变）；`SiteFaviconIcon` 先查内置图标再走远程候选链——历史/收藏/链接长按菜单与快捷书签能力对齐。
4. **标签页**：平板顶栏 `ClearAll`→`Close`、右侧 Row 加 `spacedBy(4.dp)`；手机内容区底部居中 48dp 圆钮（`shadow(6dp, CircleShape, spotColor 黑 0.35)` 中靠下投影 + `surfaceContainerLow` 底 + `onSurface` Close 图标，`navigationBarsPadding`+32dp），`tabs.isNotEmpty()` 才显示，点击 `BrowserTabManager.closeAll()`（常规+无痕全关）。
