## 实施事实

1. **纯函数层**：新文件 `browser/engine/BookmarkFolderTree.kt`——`childrenOf`/`pathOf`/`descendantIds` + `normalizedParentId`（孤儿/自指/父链成环一律归根；环防护用 visited 集，首版 hops 计数对「父链走进别的环」漏判，已修正）。
2. **BrowseStore 多层**：`Folder` 增 `parentId`（JSON 键 `parentId`，旧文件缺省 ""=根）；`childFolders`/`folderPath`；`addFolder(name, parentId="")`（父不存在回落根）；`removeFolder` 改**连带删除**子树文件夹与书签；新增 `folderCascadeStats`（确认框用）；`MAX_BOOKMARKS` 100→1000；新增 `updateBookmarkToFolder`（导入覆盖：更新标题+移入文件夹）与 `importSink()`（同名同父复用文件夹、existingUrls 快照随导入更新、capacityLeft 按剩余容量）。
3. **ReadingBookmarkOrgStore 多层**：同 `parentId` 读写；`addFolder(name, parentId="")`；`removeFolder` 连带删子树 + membership 归属子树的 time 全部清空（阅读书签本体不删）；`folderCascadeStats`。
4. **书签页 UI**（`BrowserBookmarksScreen.kt`）：
   - 两页文件夹行按「父=当前目录」显示（原仅根层显示全量）；
   - 顶栏返回与 `BackHandler` 逐级返回上一层（原直接跳根）；页切换仍重置到根；
   - 删除文件夹：确认框（「将删除 X 个子文件夹、Y 条书签，且不可恢复」）→ 连带删除；
   - 新建文件夹建在当前目录；
   - 「移动到…」弹窗：根目录 + 全层级缩进树形列表（替代平铺单层）。
5. **导入**：新文件 `browser/engine/BrowserBookmarkHtmlImport.kt`——jsoup 解析 Netscape HTML（兼容大小写/无引号属性/`<p>`/子 `dl` 为兄弟或 dt 子节点两种排布；非 http(s) 跳过；空标题回退网址；重复 URL 原始保留、去重在导入层）+ `importTree`（同名同父复用文件夹、默认跳过已存在、可选覆盖、容量耗尽 truncated 如实回报）。
   - jsoup 实测（诊断用临时测试，已删）：`<dl>` 会嵌进未闭合的 `<dt>` 内，兄弟/嵌套两种排布都需接住。
6. **收藏页接入**：`BookmarkEditDialog` 增 `showImportEntry`（仅「加入收藏」态）——标题字样下方一行「导入其他浏览器书签」（UploadFile 图标 + primary 色）；点击关弹窗 → `OpenDocument(*/*)` → 读文件（>8MB 拒绝）→ UTF-8 解码 → 解析 → 预览框（N 条书签 / M 个文件夹 + 「覆盖已存在」勾选）→ IO 导入 → toast（已导入/跳过重复/覆盖/截断）→ reload。
   - 导入目标 = 收藏页当前所在目录（根目录时即收藏根）；不在书签页产生任何条目。
7. **平板底栏回归修复**：见 LOG-235「回归与热修」——MainScreen 调用处回退，仅 MainActivity 生效。
