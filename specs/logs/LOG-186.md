# LOG-186：PDF→漫画阅读器「重试本章失败页面」修复

日期：2026-10-27

## 现象与推断

- 1.7.8 打开 PDF（漫画阅读器）：章节 1/1 正常，页面图加载失败出现重试页。
- 链路 `pdf-page://N → CoverInterceptor → CoverFetcher → PdfFile.getImage`。
- 薄弱点：拦截器对 `pdf-page://` 仍走 `AnalyzeUrl` 规则解析；`PdfFile.readPdf()` 不捕获
  异常、全链路静默——设备端真实根因不可观测。

## 实施

- `CoverInterceptor`：`pdf-page://` 直接 `chain.proceed()`（跳过 AnalyzeUrl 与封面缓存改写）。
- `PdfFile.readPdf`：try/catch，失败关半开 fd、置空 renderer、`AppLog` 记录（含 bookUrl 与
  异常类型）；content resolver 返回 null 也记日志。`getImage` 渲染异常同样记 AppLog。
- pageCount 失败返回 0 → 上层报 content_empty（不再裸抛）。

## 验证

- `:app:compileAppDebugKotlin` 通过。
- 真机：重开该 PDF；若仍失败，App 内日志页 / logcat 查 `PDF open failed` /
  `PDF page render failed` 定位（权限 vs 渲染）。
