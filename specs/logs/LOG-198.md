## 掉帧排查新证据（trace3 + trace4 复核）

- 突发帧 = fling 起步一帧内组合+测量 6–8 个 BookItem（`AndroidOwner:measureAndLayout` 44–78ms、`shelf.bookItem` marker 6–8 次、伴随 keepAroundItems / AsyncImagePainter.onRemembered / JIT code cache 锁竞争）。
- **排除**：玻璃抑制门（glass.suppress/release 零时长 marker 未出现在突发帧窗口）、Scaffold 折叠 padding 重测（shelfScaffoldPadding marker 未出现）。

## 实施

1. `BookshelfScreen`：item 提取 `itemContent: (Boolean, Modifier) -> Unit`；`canReorderBooks=false` 直接渲染，不再包 `ReorderableItem`（编辑态保留拖拽 handle 与 haptics，`longPressDraggableHandle` 属 ReorderableItem 作用域，随分支内移）。
2. 涟漪 24dp：`ripple()` 在本版本无 shape 参数 → 改 `clip(RoundedCornerShape(24.dp))` 于 clickable 前。落点：`TopBarButton` 合并路径 Box（原无 clip 的矩形涟漪）、`PhoneWebChromeIcon`（底栏键 44dp 矩形涟漪）、NTP `ShortcutChip`/`AddShortcutChip`（整格矩形涟漪）。`TopBarButton` 定义共享 `ControlRippleShape`。M3 `IconButton`/已有 clip 的键（NtpActionChip 16dp、NtpGlassIcon 圆形）不动。**注意**：中途曾用 PowerShell 批量替换致 `TopBarButton.kt` 中文注释乱码（GBK 误读），已 `git checkout` 恢复后用编辑工具重做——教训：**本机批量文本替换禁用 PowerShell 无编码读写**。
3. 菜单动画：新增 `ui/widget/components/menu/AnimatedMenuPopup.kt`（Popup + AnimatedVisibility：进入 fade 150ms LinearOutSlowIn + scale 0.92→1 自锚点角 `MenuPopupAlignment`；消失即时与 DropdownMenu 一致）。迁移六处：`NtpCustomizePanel`（BelowStart）、`NtpNewsSourceMenu`（AboveEnd）、`BrowserNavHistoryMenu`（DropdownMenu→AnimatedMenuPopup，新增 alignEnd 参数）、`BrowserTabCountMenu`（Above/BelowEnd）、`BrowserReaderModeMenu`（Above/BelowEnd）——底栏标签页/阅读模式长按菜单与平板 chrome 同款组件随迁移生效。
