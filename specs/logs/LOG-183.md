## 实施

**A. 书架/主页 → 书籍详情过渡重设计**
- `NavMotion.kt`：`BookInfoFadeMs(180)` → `BookInfoMorphMs(300)` + `BookInfoExitMs(200)`；
  新增 Material emphasized 曲线（Decelerate 0.05,0.7,0.1,1 / Accelerate 0.3,0,0.8,0.15）与
  shared-axis 四 helper：push=右 1/8 滑入+淡入 / 旧页淡出+0.98 缩；pop=反向（详情右滑淡出、
  下层 0.98→1 淡入）。predictive pop 同 pop。
- `MainNavGraph`：`MainRouteBookInfo` 三个 TransitionKey 改用上述 helper。
- `CoilBookCover`：封面 morph 时长改 `BookInfoMorphMs`（300ms，与页面 enter 对齐）。
- `BookInfoScreen`：分阶段呈现——进过渡未结束（`sharedTransitionFinished=false`）时
  `BookInfoBackdrop`（大图/模糊）与正文 item（动作行/角色/相关书/简介）不挂载，仅渲
  染名面 shared element + 头部；过渡结束整体就位（治首帧重活掉帧）。

**B. 浏览器主页「净读列表」卡**
- 更名 3 处：卡标题、空态文案、自定义行 → 「阅读列表（卡）」。
- 卡 Surface 加 `pointerInput{awaitEachGesture}`：down→上报 true，up/cancel→false；
  `MainScreen.ntpShelfCardTouchActive` 并入 `pagerUserScrollEnabled(..., ntpCardTouchActive)`
  → 触点在卡内期间外层主 Pager 禁横滑（卡外不受影响）。
- 主页卡封面打通 shared element：`onOpenBook` 路由改传
  `bookCoverSharedElementKey(bookUrl)`；`CoilBookCover` 挂 sharedBounds，scopes 经
  `MainScreen → BrowserHomeTabScreen →(Phone/Tablet)BrowserNtpScreen` 下传
  （Main 入口 `LocalNavAnimatedContentScope`，与书架页同法）。
