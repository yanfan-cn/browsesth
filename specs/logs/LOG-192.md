# LOG-192：全局流畅度专项 R1（玻璃运动降级 + 设置独立 Activity）

日期：2026-10-28
包：**巡页1.8.5-beta**（debug, code 227）已组装；version.properties 进位 1.8.6 / 228
状态：编译与 ui.main 单测通过；真机 AC-01～06 未验

## 操作者反馈与决策链

1. 1.8.4 真机：整体明显改善，但①阅读列表滑动明显掉帧；②网页→工具箱→浏览器设置退出卡顿无动画；③我的→设置退出卡顿无动画；④其他页面掉帧不跟手；⑤液态玻璃模式更严重。要求参照原版 legado 整体修复。
2. 操作者修正：填充模式也卡（玻璃不是唯一原因）；"底页重"只是浏览器主页的问题。
3. 确认：接受运动期间玻璃降级为纯色 fallback；一次性做完阶段 1-3。

## 研究结论

- 转场动画参数已与原版一致（SPEC-162 设置 Shared Axis 即逐字照抄）——差距在渲染成本：
  1. 液态玻璃逐帧采样（约 35 处玻璃）：底栏/顶栏每帧把运动内容重画进离屏层再 blur。
  2. 填充模式列表掉帧：封面解码、顶栏 scrollBehavior 折叠逐帧重组等（本轮只做低风险项，其余留给真机 Perfetto 定位）。
  3. 设置退出"无动画"：NavDisplay 场景切换拆掉主壳重组，重建帧无内容——与阅读器闪切同根，解法同 190（搬 Activity）。

## 实施

### A. GlassMotionGate（ui/theme/GlassMotionGate.kt 新文件）

- `suppressed` 全局组合状态 + `ScrollGlassSuppressor`（ScrollState/LazyListState/LazyGridState 三重载）+ `NavTransitionGlassSuppressor`（触发后抑制 700ms ≥ 最长转场）。
- `ChromeSurfaceStylePolicy.isLiquidGlassActive` 增加 `&& !GlassMotionGate.suppressed` ——单点接线，8 个调用点全部自动降级（readiness 门保持在各工厂原位，未动启动行为）。
- 接线滚动源：`FastScrollLazyColumn`/`FastScrollLazyVerticalGrid` 内置 suppressor（覆盖书架全部分组网格/搜索网格及其余快滚列表）+ BrowserNtpScreen 的 ntpScrollState。
- MainActivity：导航栈变化 → NavTransitionGlassSuppressor（size to 栈顶）。SettingsActivity 同。

### B. 设置族搬独立 SettingsActivity（ui/config/SettingsActivity.kt 新文件）

- 宿主 21 个 entry：Settings（含平板 TabletSettingsScreen 双栏分支）、SettingsBrowser、BrowserPrivacy、BrowserPickBlock、BrowserClearData、SettingsOther/Read/Cover/CoverAlbums/Theme/ThemeManage/CustomTheme/Backup/Ai/AiSummary/AiPrompt/AiProviderEdit/AiModelEdit、DownloadCache、Translation、Private（PrivateVerifyGate）。
- 自有 NavDisplay + 本地栈；转场照抄 SPEC-162 的 Shared Axis push/pop/predictive；`navigateBack = 栈内弹出否则 finish`；singleTask + onNewIntent 重落 start route。
- 初始路由复用 `MainNavigator.resolveStartRoute`（新增 ROUTE_SETTINGS_BROWSER/THEME_MANAGE/BROWSER_PRIVACY/BROWSER_PICK_BLOCK/BROWSER_CLEAR_DATA 五个常量与映射）。
- `MainIntent.createSettingsIntent(context, startRoute)`；`createIntent(configTag)`（磁贴）整体改指 SettingsActivity。
- 调用点迁移：我的→设置、平板浏览器设置、书架备份设置、History→清除数据、BookInfo→私密设置、ReadBookActivity→私密设置、BrowserSessionScreen 经 MainRouteRequestBus 的 PickBlock（MainActivity 消费者改道路由族→SettingsActivity）。
- 删除：MainNavGraph 设置族 entry（219 行）、MainNavigator 的设置分支/`isSettingsSubPage`/`route !is MainRouteSettings` 特例（AiChat 分支改为 Home 语境）；设置路由在 MainNavigator 收到时为 no-op（测试锁定）。
- About 留在 Main（它用 `BrowserTabManager.openUrlInActive` 直开浏览器标签，跨 Activity 语义不成立）。

### C. 列表渲染减负

- 核查结论：书架/主页卡封面有固定尺寸约束，Coil 3 按约束解析解码尺寸，无全尺寸解码路径；本轮不做无把握改动（避免盲改）。填充模式残余掉帧留待阶段 4 真机 Perfetto。
